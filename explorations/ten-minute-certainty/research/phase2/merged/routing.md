# routing: merged levers and skeptic verdicts

### Verdict (both seats reconciled)

Both seats agree that routing does not hold the PR critical path above 10 minutes. The long bodies (Test Integration, Property Laws, Lint Policy) belong to other areas, so routing's value is runner-minutes and trust. Inside a lane, package-grain selection already happens: Turbo --affected is task-aware (lint selected 1 task, test/check 14 on b80e110). The measurable waste is at job grain, where empty Test Unit and Lint shards boot checkout, install and setup for 64-105 s each. Opus measured 742 s and 513 s of empty shards per run on two single-package PRs. That makes the empty-partition gate before setup (ROUT-01, Opus VR-1a merged with Astra VR-1) the top lever. It stays low risk only in Opus's form, where the gate reuses the lane's existing selection function. Astra's high-risk rating is correct for any narrowing beyond Turbo, and the merged lever excludes that narrowing. Both seats independently found soundness holes in the docs-only regex widened by #2935 and #2999. Opus confirmed a missed knowledge:semantic-delta/refs-check red on a packet-markdown-only head; those gates exist only in policyGitDeltaTasks, which docs-only PRs now never run. Opus also found that repo-cli's goals-ops-typecheck test and lint:opaque-roundtrips read goals/*/ops. Astra found that eyecite and law-practice-server tests read a frozen JSON fixture under goals/. I verified it is not in the root test task's Turbo inputs, and CoverageScope.ts:70 marks goals/ as noop. The hole therefore reaches code PRs and test caches, not just the regex. These repairs (ROUT-02, ROUT-03) come before any further skip widening and carry negative savings, which both seats accepted. On the job-name mapping contradiction, I resolved it in Astra's favour from source. Corpus job names carry the caller prefix ('Heavy / Test Integration'), and RouteCensus strips the ' (partition)' suffix, so #3005's 'Heavy / Test Integration (p)' maps. Opus's VR-5 slice 1 shrinks to a conservation test. Astra ranked VR-4 (narrower check prerequisites) third. Opus rejected it on measured evidence (57/58 builds HIT, hosted Check 60 s), and Astra's own savings figure is ~0, so it is kept as ROUT-10 at high risk and ranks only fourth because every other positive lever is small. Corpus refresh, per-package outcomes and the classifier differential (ROUT-05..07) save nothing directly but gate every future refinement. Routing alone cannot certify the 10-minute p95. Neither seat measured post-#3005/#3007 makespans.
