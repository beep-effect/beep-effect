# peripheral-local: merged levers and skeptic verdicts

### Verdict (both seats reconciled)

Both seats agree that this area cannot move ruling 1's push-to-every-required-context-green p95. Every lever here is off the PR critical path or outside that metric. Neither seat credits the 20-minute review window, sleeping monitors or quarantine residue as runner compute. The largest hosted runner-minute lever, from Opus only, is folding the non-required 3-minute Fallow Advisory Envelopes job into an existing non-required ubuntu job. That saves about 75-80 s of checkout plus Setup monorepo CI per non-docs PR run, roughly 550-1,800 runner-min/week at the brief's 76-245 runs/day, with zero critical-path change. Astra's top lever, the duplicate changeset-graph in Repo Sanity, is real: CiLane.ts:1742 runs `beep quality changeset-graph` explicitly, then `audit:github repo-sanity` runs githubCheckRepoSanityLanes, which includes repo-sanity:changeset-graph again (GithubChecks.ts:577). It is worth only a few seconds per run, so it ranks as a cheap waste removal, not a headline. Both seats call the detached `yeet monitor --until-ready` fleet the largest real background load, and source settles Astra's caveat. The three live monitors in the beep-effect2 lane all carry prNumber 3007, so duplicates are confirmed per PR, not just per checkout. Singleton-per-PR plus state-aware cadence cuts an estimated 13,000+10,000 CPU-s/week and 130-200k REST calls/week, but credits no target minutes. The retention defect is source-confirmed: isRetainedCheckoutResidueName('yeet') is false (ResidueReap.ts:1745-1787, Worktree.service.ts:1004-1030). That deletes every retired lane's attempt journals and explains Opus's '26 GB residue, 3 journals' finding. Together with T3 lanes and remote hosts missing from economics, it means the 'local verify/publish under 10 min' target cannot be proven fleet-wide yet. That is a measurement soundness hole, not waste. Astra's #2 (within-attempt Fallow audit reuse) and #3 (typos on staged files) are kept but rank low. The Fallow reuse earns zero credit until a parity ledger exists. The typos change saves about 0 commit wall because hooks run in parallel and typos measured 631 ms mean (Opus). Opus's merged-preview retirement is split out and held: Astra correctly notes that MergedPreview.ts is a distinct semantic merged-tree proof, so removing it is a capability or proof-depth change for the operator, not efficiency. The review-window anchor change (diff-preserving merge-main) and the instrumentation-catalog splice are Opus-only. The first needs an operator ruling because it amends the mergeable definition. For the second, source shows that declarations are a repo-wide join (Observability.service.ts:255-265), so a splice must keep the full declaration load and re-harvest owners whenever a declaration file changes.
