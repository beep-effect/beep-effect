# peripheral-hosted: merged levers and skeptic verdicts

### Verdict (both seats reconciled)

Both seats agree that this area is mainly about runner-minutes. It is not a latency lever: every peripheral job finishes in under about 3 minutes and runs beside the long poles. The exception is Heavy Admission. check.yml `heavy` has `needs: [admission]`, so admission's full workspace install (a median 49 s of a 74 s job, for a 2 s decision) sits on the path to every `Heavy / *` required context. That makes PERI-01 the only lever here that moves required-path p95, by about 0.8 min derived. Astra credited zero critical-path minutes everywhere until paired runs exist; source confirms the dependency, so the credit is kept as derived. Most of the compute waste is setup that dwarfs the work: the duplicate Shadcn Lint job (39 s install for a 4.4 s oxlint walk), installs used only to dispatch PR Size, Security, SAST, Nix and Rerun Runner Loss, and checkouts paid by lanes that then skip on a step-level path gate. At the brief's volume (about 76-245 PR runs a day, roughly 1,100 a week, plus about 470 main pushes) the levers together remove roughly 5-7k hosted runner-minutes a week. Opus's 9-10k figure used the 7-day API total of 2,059, which includes the roughly 42% cancelled runs. Astra's 410/week non-cancelled scenario is too low against the brief. One soundness hole was confirmed in source. CiOperational.service.ts:180-203 deliberately reads CiOperational.patterns.json from the PR head checkout, so a PR that widens the `docs` pattern classifies itself as docs_only, and admission then skip-satisfies every Heavy required context. PERI-10 closes it by reading from the base ref. PERI-10 is also a prerequisite for putting more decisions on the pinned binary (PERI-01, PERI-03, PERI-04, PERI-06). Source also shows that neither `Shadcn Lint` nor `Heavy / Lint Policy` is in standards/branch-protection-contexts.json. Retiring the duplicate therefore does not weaken the required gate, and folding lint:shadcn into Repo Sanity, which is required, strengthens it. Vercel costs no GitHub minutes, and Opus measured 77% rate-limited statuses. A closure-scoped ignoreCommand mostly restores a real preview signal, so it is ranked as trust/measurement. All seats' top-3 levers are retained: Opus L1-1/L1-2/L1-3 were split into PERI-01/02/03/06/08/10/11, and Astra L1-01/02/03 map to PERI-02/06/07. Nothing here reduces proof depth: every scan, required context and main-push full run stays.
