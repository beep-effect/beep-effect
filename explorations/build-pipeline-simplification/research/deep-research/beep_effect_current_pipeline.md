## Q5. What is the `tsc` binary, does build emit use tsgo, and what build timings are known?

### Takeaway
`node_modules/.bin/tsc` is `@typescript/native` (TypeScript 7.0.2 Go) with its binary replaced by `effect-tsgo 0.47.2` in the root `prepare` script, and `tsgo` is a shim that execs the same Effect artifact; so `beep:build` emit runs the Effect-patched TS7 compiler with ~130 Effect diagnostics as errors. Known timings: warm `bun run build` 131/131 in 24 s; cold `turbo run build --filter=@beep/repo-cli...` 33 tasks in 6.7 s; a single observed local `build` feedback lane 139 s; local full pre-push proof mean 1022 s (17 min); hosted PR makespan p50 12.2 min; hosted Build lane has a 40-min timeout and is non-required.

### Cited Findings
- "`beep:build` (`tsc -p`), `beep:check` (`tsgo -p tsconfig.check.json`), docgen's example compile, and every `lint:tsgo-rules` run therefore use the same Effect compiler with Effect diagnostics."
