# In-repo capability inventory for the LeJeune Bolt agentic demo

**Inventory date:** 2026-08-25
**Method:** local source inspection only; no network access, tenant login, service startup, build, or live test was performed.
**Scope:** `beep-effect10` plus the local external checkout at `~/YeeBois/dev/trustgraph/ts`.

The brief is a one-week lunch demo for a bolt distributor that sits between buyers and manufacturers and uses Microsoft Office as its system of record. The desired story is office-data ingestion into a fastener knowledge graph and agent memory, followed by source-backed assistance for quoting, specification, and ordering with human approval (`explorations/lejeune-bolt-agentic-demo/CAPTURE.md:12-14`, `explorations/lejeune-bolt-agentic-demo/CAPTURE.md:26-37`, `explorations/lejeune-bolt-agentic-demo/CAPTURE.md:57-77`).

## Executive verdict

The reusable substrate is real: read-only Microsoft Graph access, multiple document extractors, span-grounded structured extraction, RDF/ontology/SHACL tooling, evidence and provenance models, model-provider adapters, MCP infrastructure, and an existing legal-practice bundle pattern all have substantive implementations. The relevant entry points are enumerated below.

The product path is not assembled. There is no LeJeune/fastener ontology, supplier-price connector, seller-order connector, production agent-memory/context-graph module, interactive order-approval flow, or lab deployment stack in the searched sources. The two in-repo lab apps are shells, while the external TrustGraph TypeScript workbench is substantially more developed but still has documented parity gaps and no currently verified deployment (`apps/labs/trustgraph-workbench/src/App.tsx:1-7`, `apps/labs/semantica/src/canary/Command.ts:63-97`, `~/YeeBois/dev/trustgraph/ts/docs/parity/00-gap-matrix.md:68-74`).

A credible one-week demo is therefore a bounded prototype: ingest authorized sample mail/documents or a prepared local export; parse quotes into a small fastener ontology; answer source-backed questions; search a local supplier/price snapshot; and generate a proposed order that stops at a visible human-approval gate. Live seller-system order placement is not supportable from the inventoried code because no connector was found; representing it as operational would be misleading.
