# L1 Decision Brief — Cursor CLI Headless Surface

Orchestrator brief from `L1b-cli-surface.md`. Tags: **CONFIRMED** (cursor.com/docs or 2+ sources), **SINGLE-SOURCE**, **INFERENCE**.

## 1. Headless lane recipe v2

**Baseline (D13 skeleton):**
```bash
cursor-agent -p --trust --force --sandbox enabled --model <id> --output-format stream-json </dev/null
```

**Recipe v2 — write/implement (volume lane):**
```bash
export CURSOR_API_KEY=…   # or `agent login` once; do not pass --api-key on argv (ps leakage)

timeout 15m \
  cursor-agent -p \
    --trust \
    --force \
    --sandbox enabled \
    --workspace /abs/path/to/beep-effect \
    --model 'composer-2.5' \
    --output-format stream-json \
    -- "Implement <bounded change>. Do not run git. Do not commit, push, or edit .git/. You may read files and run tests. Stop after the diff is in the worktree." \
    </dev/null
```

Capture: `> /tmp/cursor-lane.ndjson 2> /tmp/cursor-lane.err`. Success = exit 0 **and** a line with `type=="result" && subtype=="success"`. Missing result + nonzero = failure. **CONFIRMED** — https://cursor.com/docs/cli/headless, https://cursor.com/docs/cli/reference/output-format

**Read-only research variant:** same as above but add `--mode=ask` and **drop `--force`**. **CONFIRMED** — https://cursor.com/docs/cli/using, https://cursor.com/docs/cli/reference/parameters

## 2. stream-json event schema

- **Format:** NDJSON, one JSON object per line; `--output-format` only works with `--print`; default is `text`. **CONFIRMED** — https://cursor.com/docs/cli/reference/parameters, https://cursor.com/docs/cli/reference/output-format
- **Session ID:** constant for the run; appears on `system/init`, `user`, `assistant`, `tool_call`, and terminal `result`. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format
- **Thinking events suppressed** in print mode; consumers should ignore unknown fields. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format

**Event types:**

| Event | Key fields |
|---|---|
| `system` / `init` | `apiKeySource`, `cwd`, `session_id`, `model`, `permissionMode`; `tools`/`mcp_servers` may be added later. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format |
| `user` | `message.role=user`, `message.content[].text`, `session_id`. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format |
| `assistant` | `message.content[].text`, `session_id`; without `--stream-partial-output`, complete messages between tool calls. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format |
| `tool_call` / `started` | `call_id`, typed `readToolCall`/`writeToolCall` or generic `function.name`/`function.arguments`, `session_id`. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format |
| `tool_call` / `completed` | Same + `result.success` (read: `content`, `totalLines`; write: `path`, `linesCreated`, `fileSize`). **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format |
| `result` / `success` | `is_error=false`, `duration_ms`, `duration_api_ms`, aggregated `result` text, `session_id`, optional `request_id`. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format |

**Tool calls / results:** started events carry args; completed events carry results. Write args include `path`, `fileText`, `toolCallId`. Generic shell/other tools use `tool_call.function`. **CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/docs/cli/headless

**Final text:** prefer terminal `result.result` (concatenates assistant segments without separators). **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format

**Usage / tokens:** no usage/token-count fields documented on CLI result object (Feb 2026 changelog claimed per-turn totals; live output-format page omits them). **CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/changelog

**Exit codes:** no published exit-code table; treat 0 = success, any nonzero = failure (auth, quota, tool, crash). **CONFIRMED** — https://cursor.com/docs/cli/headless, https://cursor.com/docs/cli/reference/authentication

**Quota exhaustion:** surfaces as nonzero exit + stderr; stream-json may terminate without a `result` event; exact quota string unpublished. Changelog: classified server failures including rate limits display the actual server message. Auth page documents only `"Not authenticated"`. SDK has `RateLimitError` with `is_retryable`/`retry_after`. Operator on-demand disabled → included-pool exhaustion is hard stop. **CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/changelog, https://cursor.com/docs/cli/reference/authentication, https://cursor.com/docs/sdk/python, https://cursor.com/docs/models-and-pricing

**Wrapper rule:** fail on exit nonzero **or** missing `type=="result" && subtype=="success"`. **CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/docs/cli/headless

## 3. jq extraction cookbook

Assume log file `run.ndjson`. Ignore unknown fields.

```bash
# session id + init metadata
jq -r 'select(.type=="system" and .subtype=="init")
  | "session=\(.session_id) model=\(.model) key=\(.apiKeySource) perm=\(.permissionMode) cwd=\(.cwd)"' run.ndjson

# final assistant text (prefer over concatenating assistant events)
jq -r 'select(.type=="result" and .subtype=="success") | .result' run.ndjson

# commands run (generic function-form tools incl. shell)
jq -c 'select(.type=="tool_call" and .tool_call.function)
  | {subtype, call_id, name: .tool_call.function.name, arguments: .tool_call.function.arguments}' run.ndjson

# D13-style command extraction (also try nested "command" keys)
jq -c 'select(.type=="tool_call") | .. | objects | select(has("command")) | {command}' run.ndjson

# files written (completed)
jq -c 'select(.type=="tool_call" and .subtype=="completed" and .tool_call.writeToolCall)
  | {call_id, path: .tool_call.writeToolCall.result.success.path,
     lines: .tool_call.writeToolCall.result.success.linesCreated,
     bytes: .tool_call.writeToolCall.result.success.fileSize}' run.ndjson

# write payloads (started — includes fileText)
jq -r 'select(.type=="tool_call" and .subtype=="started" and .tool_call.writeToolCall)
  | .tool_call.writeToolCall.args | "\(.path)\n\(.fileText)"' run.ndjson

# success check + session_id from result
jq -r 'select(.type=="result") | "subtype=\(.subtype) err=\(.is_error) session=\(.session_id) req=\(.request_id // "")"' run.ndjson
```

**CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/docs/cli/headless

## 4. `--sandbox enabled` semantics

- **Flag:** `--sandbox enabled|disabled` sets sandbox mode. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/parameters
- **INFERENCE:** `--sandbox enabled` turns on sandbox policy from `sandbox.json` + built-ins; `--sandbox disabled` ≈ `insecure_none`/allowlist mode (matches `agent sandbox disable`). **INFERENCE** — https://cursor.com/docs/reference/sandbox, https://cursor.com/docs/cli/reference/parameters
- **`sandbox.json` layers:** user `~/.cursor/sandbox.json`, repo `<ws>/.cursor/sandbox.json` (repo wins); then team-admin, then built-in (cannot be relaxed). **SINGLE-SOURCE** — https://cursor.com/docs/reference/sandbox
- **Types:** `workspace_readwrite` (default), `workspace_readonly`, `insecure_none`. Extra r/w and r/o path lists; `/tmp` writable unless `disableTmpWrite`. **SINGLE-SOURCE** — https://cursor.com/docs/reference/sandbox
- **Network:** `networkPolicy.default` = `deny` (default); allow/deny exact domains, `*.example.com`, CIDR. Private/loopback/link-local/cloud-metadata always blocked even if `default: allow` (10/8, 172.16/12, 192.168/16, 127/8, 169.254.169.254, ::1, fe80::/10, fc00::/7). **SINGLE-SOURCE** — https://cursor.com/docs/reference/sandbox
- **Protected paths (always write-blocked):** `.cursor/*.json`, `.cursor/**/*.json`, `.cursor/.workspace-trusted`, `.claude/*.json`, `.vscode/**`, `.git/hooks/**`, `.git/config`, `.git/info/attributes`, `.cursorignore`. Writable `.cursor` dirs: `rules/`, `commands/`, `worktrees/`, `skills/`, `agents/`. **SINGLE-SOURCE** — https://cursor.com/docs/reference/sandbox
- **Git binary is not blocked;** protected git metadata paths are. `git fetch`/`push` need network allow. **CONFIRMED** — https://cursor.com/docs/reference/sandbox, https://cursor.com/changelog
- **Linux gotcha:** process remapped to UID 0 inside user namespace; use `CURSOR_ORIG_UID`/`CURSOR_ORIG_GID`. **SINGLE-SOURCE** — https://cursor.com/docs/agent/security/run-modes

**Permissions allow/deny** (user `~/.cursor/cli-config.json`; project `<project>/.cursor/cli.json`; deny overrides allow):

| Kind | Syntax | Notes |
|---|---|---|
| Shell | `Shell(commandBase)` | First token; `Shell(git)` allows subcommands; optional `Shell(curl:*)` |
| Read | `Read(pathOrGlob)` | Relative = workspace-scoped |
| Write | `Write(pathOrGlob)` | |
| Web | `WebFetch(domainOrPattern)` | No allow → each fetch prompts |
| MCP | `Mcp(server:tool)` | e.g. `Mcp(datadog:*)` |

**CONFIRMED** — https://cursor.com/docs/cli/reference/permissions, https://cursor.com/docs/cli/reference/configuration

**`--force` vs `--auto-review`:**
- `--force`/`--yolo`: "Force allow commands unless explicitly denied"; without it, proposed changes are not applied in print mode. CLI analogue of Run Everything; deny still wins. **CONFIRMED** — https://cursor.com/docs/cli/reference/parameters, https://cursor.com/docs/cli/headless, https://cursor.com/docs/agent/security/run-modes
- `--auto-review`: not on published parameters page; changelog: safety classifier (Haiku/GPT mini), not a permission bypass. SDK `local.autoReview: true` denies blocked calls in headless rather than prompting. **CONFIRMED** — https://cursor.com/changelog, https://cursor.com/docs/sdk/typescript

## 7. Known headless pitfalls

- **Workspace trust prompt** without `--trust` (or `--force` per changelog Jan 2026) hangs unattended runs. **CONFIRMED** — https://cursor.com/docs/cli/reference/parameters, https://cursor.com/changelog
- **Open stdin pipe** used to hang `-p` (fixed Feb 2026); still pass `</dev/null>`. Piped stdin also infers print mode/output-format. **CONFIRMED** — https://cursor.com/changelog, https://cursor.com/docs/cli/reference/output-format
- **No CLI auto-timeout** on agent-spawned bash; `tail -f`/watch scripts hang the agent. Wrap with host `timeout`. **SINGLE-SOURCE** — https://x.com/steipete/status/1954594876743389444
- **Subagents:** single-turn `-p` waits for delegated subagents before exiting (Aug 2026); stuck Explore subagent holds process. **SINGLE-SOURCE** — https://cursor.com/changelog
- **Sudo/YubiKey prompts** hang headless; deny `Shell(sudo)`/`Shell(pkexec)`. **SINGLE-SOURCE** — https://cursor.com/changelog
- **Without `--force`**, changes are only proposed, not applied. **SINGLE-SOURCE** — https://cursor.com/docs/cli/headless
- **`--sandbox enabled` + default network deny** breaks npm, git remotes, 1Password SSH socket unless allowlisted. **CONFIRMED** — https://cursor.com/docs/reference/sandbox, https://cursor.com/docs/agent/security/run-modes
- **`--force` does not override `deny`.** **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/permissions
- **Linux sandbox UID 0** inside namespace — use `$CURSOR_ORIG_UID` for Docker `--user`. **SINGLE-SOURCE** — https://cursor.com/docs/agent/security/run-modes
- **Default `--output-format` is `text`**, not stream-json. **CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/docs/cli/reference/parameters
- **No usage fields** on CLI stream-json result (docs/changelog mismatch); do not bill from CLI events. **CONFIRMED** — https://cursor.com/docs/cli/reference/output-format, https://cursor.com/changelog
- **`result` text** concatenates assistant segments without separators. **SINGLE-SOURCE** — https://cursor.com/docs/cli/reference/output-format
- **Grok Bot weekly is a third meter** — does not transfer quota to Cursor CLI. **SINGLE-SOURCE** — https://x.com/grok/status/2100073210888819194
- **Unbounded `-p --force` loops** can drain a month of included usage in a day. **SINGLE-SOURCE** — https://x.com/jintageal/status/2099399646238101711
- **Fast variants stay active in `-p`**; Composer 2.5 Fast is 6× in/out. **CONFIRMED** — https://cursor.com/changelog, https://cursor.com/docs/models-and-pricing
- **CI GHA example** omits `--trust`/`--force`/`--sandbox`; **`.cursor/environment.json` is Cloud-Agent-only** (local `-p` will not run `install`). **SINGLE-SOURCE** — https://cursor.com/docs/cli/github-actions, https://cursor.com/docs/cloud-agent/setup
