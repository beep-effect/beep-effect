## 1. How Ultra meters the two buckets

- **Unit:** API-list-price dollars computed from tokens (input / cache write / cache read / output per 1M); model choice affects burn rate; Auto bills at routed model's list price. **CONFIRMED** — https://cursor.com/docs/models-and-pricing, https://cursor.com/help/models-and-usage/usage-limits
- **Cursor Models bucket:** Composer 2.5, Cursor Grok 4.6, Cursor Grok 4.5 (incl. Fast variants). **CONFIRMED** — https://cursor.com/help/models-and-usage/usage-limits, https://cursor.com/docs/models-and-pricing
- **Other Models bucket:** third-party models at provider API prices (Claude, GPT, Kimi, GLM, Gemini, etc.). **CONFIRMED** — https://cursor.com/help/models-and-usage/usage-limits, https://cursor.com/docs/models-and-pricing
- **Ultra Other Models allowance:** ~**$400/mo** API-list-price (staff: "20×" = $20 × 20, not $200 × 20). Auto/Composer is a separate unpublished grant. **SINGLE-SOURCE** — https://forum.cursor.com/t/how-much-usage-is-available-on-the-200-subscription/163309
- **Cursor Models allowance:** dollar size unpublished; permanently **2×** first-party (Auto, Composer 2.5, Cursor Grok 4.5); does **not** double the $400 Other pool. **SINGLE-SOURCE** — https://forum.cursor.com/t/now-available-2x-included-usage-your-plan-now-includes-2x-usage-for-all-cursor-models-composer-2-5-and-cursor-grok-4-5/166007/4
- **Grok 4.6 in doubled first-party pool:** not named in 2× announcement (launched 2026-08-12). **INFERENCE** — https://forum.cursor.com/t/now-available-2x-included-usage-your-plan-now-includes-2x-usage-for-all-cursor-models-composer-2-5-and-cursor-grok-4-5/166007/4
- **Spill order:** third-party drains **only** Other Models; Cursor models drain Cursor Models **first**, then **spill into Other Models** and can zero both bars. Other Models **never** drains Cursor Models. **SINGLE-SOURCE** — https://forum.cursor.com/t/possible-bug-in-cursor-token-statistics-other-models-disabled-after-grok-quota-exhausted/169032/5
- **At 100% with on-demand disabled:** hard stop; requests never downgraded in quality or speed; error string **`Total usage limit reached`** (user-reported). **CONFIRMED** — https://cursor.com/help/account-and-billing/overages, https://cursor.com/docs/models-and-pricing, https://forum.cursor.com/t/included-usage-exhausted-why-did-composer-2-5-fast-stop-being-available-for-free/170709
- **Reset cadence:** monthly with billing cycle; unused does not roll over; operator reset **Oct 11**. **CONFIRMED** — https://cursor.com/help/models-and-usage/usage-limits
- **Grok Bot bucket:** third weekly meter on Cursor account; stops when weekly included exhausted if on-demand off; does **not** drain Cursor Models / Other Models; irrelevant to headless `cursor-agent`. **CONFIRMED** — https://cursor.com/help/grok-bot/plans, https://cursor.com/help/models-and-usage/usage-limits

### Headless "Cursor usage available?" rule (report verdict)

1. Codex weekly >5% → native Astra; skip Cursor.
2. Run `cursor-agent -p --trust --force --sandbox enabled --model <id> --output-format stream-json` with `</dev/null`.
3. **Unavailable** when stream/JSON/stderr contains **`Total usage limit reached`** (or quota-exhausted / included-usage / on-demand-disabled wording), or non-zero exit + no assistant message.
4. On-demand disabled → hard stop; no Auto fallback.
5. Stop Cursor-bucket volume before Cursor Models 100% if Other must stay reserved (spill zeros Other).
6. Ignore Grok Bot weekly %.
7. **Official individual usage API: NOT FOUND.** Do not scrape unofficial endpoints in public beep-effect.

## 5. ZDR and privacy mode implications

- **Most Cursor models:** ZDR agreements — providers don't store I/O or train on data. **CONFIRMED** — https://cursor.com/docs/models/claude-fable-5-1, https://cursor.com/data-use
- **Fable 5 / 5.1 = NO ZDR:** Anthropic stores I/O ~30 days for harm prevention **regardless of Privacy Mode**; not for training. **CONFIRMED** — https://cursor.com/docs/models/claude-fable-5-1
- **Privacy Mode on + Fable:** admin must approve Anthropic Data Retention Policy or Fable requests fail; guardrail hits auto-route to Opus (ZDR). **CONFIRMED** — https://cursor.com/docs/models/claude-fable-5-1
- **Privacy Mode:** code never used for training by Cursor or providers; does **not** keep inference on-box; public repo treated same as private. **CONFIRMED** — https://cursor.com/data-use, https://cursor.com/docs/enterprise/privacy-and-data-governance
- **Beep-effect:** public repo — not a training leak; still ships prompt+code off-box. Enable Privacy Mode. **Do not use Cursor Fable 5.1** for ZDR-required lanes. **CONFIRMED** — https://cursor.com/data-use, https://cursor.com/docs/models/claude-fable-5-1

## 6. Recommended 3-tier seat map
