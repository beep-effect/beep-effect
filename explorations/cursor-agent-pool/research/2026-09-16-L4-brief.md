## 1. Headless `cursor-agent -p` recipe deltas vs baseline

### Flags to add or consider

- **`--stream-partial-output`** — incremental text deltas; only valid with `-p` + `stream-json`; consolidated assistant messages **duplicate text** (ignore flushes with `model_call_id` or lacking `timestamp_ms`). CONFIRMED https://cursor.com/docs/cli/headless https://cursor.com/docs/cli/reference/output-format https://x.com/codedibia/status/2072358774757556499
- **`--workspace <path>`** — explicit repo root; pairs with `--worktree` for isolation. CONFIRMED https://cursor.com/docs/cli/reference/parameters https://github.com/SinanTufekci/agent-intern/blob/main/cursor_bridge.py
- **`--resume <chatId>` / `create-chat` first** — persistent sessions across iterations; agent-intern scans `~/.cursor/chats/*/meta.json` after restart. SINGLE-SOURCE https://github.com/SinanTufekci/agent-intern/blob/main/cursor_bridge.py
- **`--model composer-2.5` explicitly** — Fast variant is product default and 6× input price; confirm id via `--list-models`. INFERENCE https://cursor.com/docs/models/cursor-composer-2-5 https://cursor.com/docs/models
- **`--approve-mcps`** — auto-approve MCP servers (Ralph loops). CONFIRMED https://github.com/taberoajorge/ralph
- **`--plugin-dir <path>`** — inject local plugin manifests (repeatable). CONFIRMED https://cursor.com/docs/cli/reference/parameters https://github.com/awslabs/cli-agent-orchestrator/blob/main/docs/cursor-cli.md
- **Hard `timeout` (e.g. 20m)** — Ralph default ceiling for volume jobs. SINGLE-SOURCE https://github.com/danielsinewe/ralph-cursor
- **`--debug`** — diagnose hangs; staff workaround. CONFIRMED https://forum.cursor.com/t/cursor-agent-p-print-headless-mode-hangs-indefinitely-and-never-returns/150246

### Flags to omit or avoid

- **`--plan` / `--mode plan`** — CI runs 5–6 min, exit 0, **no output**; do not use in volume lane. CONFIRMED https://forum.cursor.com/t/cursor-agent-print-doesnt-exit-after-completing/150296
- **`--sandbox disabled`** — escape hatch when preflight EPERM or empty-success; agent-intern "full access" variant. INFERENCE https://github.com/SinanTufekci/agent-intern/blob/main/cursor_bridge.py https://forum.cursor.com/t/agent-cli-linux-sandbox-preflight-fails-unshare-eperm-unless-run-under-strace-apparmor-restrict-unprivileged-userns-1/160039
- **Omitting `-p` and `--trust`** — CAO interactive tmux REPL pattern; not for volume Bash lane. SINGLE-SOURCE https://github.com/awslabs/cli-agent-orchestrator/blob/main/docs/cursor-cli.md
- **`--output-format json`** instead of `stream-json` — bmalph pattern; loses incremental tool events. CONFIRMED https://github.com/LarsCowe/bmalph

### Baseline validation

- D13 baseline shape (`-p --trust --force --sandbox enabled --output-format stream-json </dev/null`) matches official docs + agent-intern + Ralph + Hermes + forum CI. CONFIRMED https://cursor.com/docs/cli/headless https://github.com/SinanTufekci/agent-intern/blob/main/cursor_bridge.py https://github.com/taberoajorge/ralph https://github.com/StrawCoding/hermes-cursor-agent
- **`--force` required with `--sandbox enabled`** — without it, sandboxable cmds auto-run but others are **silently denied**. CONFIRMED https://forum.cursor.com/t/disable-permissions-ask-in-sandbox/157243
- **File changes not applied without `--force`/`--yolo`**. CONFIRMED https://cursor.com/docs/cli/headless
- **`--add-dir` / `--auto-review`** — on 2026.09.10-fd3934a help but not on parameters page; version-skew risk. SINGLE-SOURCE https://cursor.com/docs/cli/reference/parameters

### Pitfalls

- **Precompute `git diff` into prompt** — asking agent to `git diff` itself causes silent failure or hang; inline diff succeeded (~86 KB, ~54s). CONFIRMED https://forum.cursor.com/t/cursor-agent-print-doesnt-exit-after-completing/150296
- **`</dev/null`** — disable stdin; standard in wild integrations. CONFIRMED https://github.com/SinanTufekci/agent-intern/blob/main/cursor_bridge.py
- **Linux sandbox EPERM** — `unshare` AppArmor `userns`; or `uid_map` EPERM; or mount-count 1000; or exit 0 with empty output. CONFIRMED https://forum.cursor.com/t/agent-cli-linux-sandbox-preflight-fails-unshare-eperm-unless-run-under-strace-apparmor-restrict-unprivileged-userns-1/160039 https://forum.cursor.com/t/cursor-cli-not-updating-sandboxing-doesnt-work/152649 https://forum.cursor.com/t/gpt-5-2-sandbox-issues/147855 https://forum.cursor.com/t/linux-sandbox-error-failed-to-apply-sandbox-io-error-step-4-7-mount-denies-failed-mount-count-limit-reached-1000/150926
- **Two integration dialects** — one-shot NDJSON (`-p stream-json`) vs persistent ACP (`agent acp` JSON-RPC). CONFIRMED https://cursor.com/docs/cli/acp https://x.com/nearygy/status/2077603830645293062

### Exit / quota error signatures

- **No documented usage, rate-limit, or structured error events in stream-json** — failures = nonzero exit + stderr + no valid JSON. CONFIRMED https://cursor.com/docs/cli/reference/output-format
- **Hang / no-exit / silent-zero-output class** — recurring 2026 CLI issue; staff "fixed in latest" then July regression. CONFIRMED https://forum.cursor.com/t/cursor-agent-p-print-headless-mode-hangs-indefinitely-and-never-returns/150246 https://forum.cursor.com/t/cursor-agent-print-doesnt-exit-after-completing/150296 https://forum.cursor.com/t/cursor-agent-p-hangs-with-zero-output-on-2026-07-01-41b2de7-macos-intel-all-output-formats-even-trivial-prompts/164841
- **Zero bytes stdout/stderr** — macOS Intel `2026.07.01-41b2de7`; workarounds: disable HTTP/2, drop VPN, set `HTTPS_PROXY`/`HTTP_PROXY`, wrap `timeout`. CONFIRMED https://forum.cursor.com/t/cursor-agent-p-hangs-with-zero-output-on-2026-07-01-41b2de7-macos-intel-all-output-formats-even-trivial-prompts/164841
- **Answer printed, process never exits** — Linux; trivial prompts 36–55s when fixed. CONFIRMED https://forum.cursor.com/t/cursor-agent-print-doesnt-exit-after-completing/150296
- **Rate-limit → `DEFER` backoff** — lockstride Ralph; rotate context at 150k tokens. SINGLE-SOURCE https://github.com/lockstride/ralph-wiggum-plugin
- **Model exhausted → retry once with `auto`** — Hermes-cursor-agent only public in-process fallback. SINGLE-SOURCE https://github.com/StrawCoding/hermes-cursor-agent
- **Parser recipe** — JSONL; prefer terminal `result` text; fallback last `assistant`; keep `session_id` for `--resume`. SINGLE-SOURCE https://github.com/SinanTufekci/agent-intern/blob/main/cursor_bridge.py https://cursor.com/docs/cli/reference/output-format

- **Supported alternatives:** Cursor CLI (`cursor-agent`), Agent SDK/headless, public Cloud Agents API — use agent harness, not raw model. CONFIRMED https://forum.cursor.com/t/does-using-oh-my-pi-s-cursor-provider-or-an-openai-compatible-proxy-to-the-same-endpoints-violate-cursor-s-tos/167778

- **Still burns Cursor inference quota** — only keeps checkout/build cache local. INFERENCE https://cursor.com/docs/cloud-agent/self-hosted
