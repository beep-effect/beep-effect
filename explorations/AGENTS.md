# Explorations — Agent Guide

The repo's fuzzy front end: exploration packets crystallize ideas into
`goals/` packets. The `/explore` skill is the operating procedure;
[`README.md`](./README.md) is the convention authority (stages, statuses,
manifest schema, graduation contract). In-repo inventory: ripgrep + package
barrels via the `repo-symbol-discovery` skill.

- Orient in order: `<slug>/ops/manifest.json` → `<slug>/README.md` → only the
  artifacts the current stage needs.
- Close the loop before ending any session: update the manifest, rewrite the
  packet README's Next Open Question, append a dated Trail line, sync
  `ATLAS.md` on any stage/status change.
