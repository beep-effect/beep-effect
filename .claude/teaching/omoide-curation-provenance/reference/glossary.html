Glossary

The words the registration contract uses, in the sense the software uses them. Source: docs/curation/source-registration.md.

TermMeaning here
manifestThe JSON file the operator writes listing 1–100 exact files (path + SHA-256) plus the statements below. Registration reads only those files, never a directory.
operatorThe trusted local human running the CLI inside the container (Benjamin). Not an HTTP caller, not an agent.
attestationA statement the operator signs off on and the software stores verbatim with the manifest digest. Recorded, not verified.
ancestryPer file: where this exact byte sequence came from, as far as the operator knows.
original_captureAncestry kind with no declared parents: this is the earliest form of the file the operator holds.
non_generative_derivativeAncestry kind that requires parent hashes and a complete chain; a resize/crop/re-encode of a file you can name.
unknown / generative / incomplete / cyclicRefused ancestry. Unknown means "I can't say"; generative means an AI model produced or edited it.
rights_to_curateBoolean attestation that the operator has the right to curate this selection for training. It is his claim, not a licence check.
subject_identity_attestedBoolean attestation that the declared subject_id is who the operator says it is. Not face-verified.
evidence_referenceA pointer (path, record id, op:// reference) to where the supporting evidence lives. Never the evidence itself.
capture groupPhotos from the same session; the same group may not straddle train/validation/test splits.
trust boundaryThe line between what software checks (hashes, volume identity, schema) and what only the operator can vouch for (ancestry, rights, identity).
