# Your files in Box: one page

Box is now where the firm's documents live. On your PC it is the **Box**
folder in File Explorer. Anything you put there is saved to Box and backed up
automatically; nothing else is needed.

## Where things go

Every client has a folder. Inside it, every matter has a folder named with
its docket family number (client number, a dot, family number) and, where
known, its title. Every matter folder has the same numbered
subfolders:

| Folder | What goes in it |
| --- | --- |
| `00 Engagement and Administration` | Engagement letter, conflict check, powers of attorney on file |
| `01 Intake and Invention Disclosure` | What the client first sent: disclosure, notes, sketches |
| `02 Prior Art and Search` | Search reports, references, IDS materials |
| `03 Drafting` | Specification, claims, and drawing drafts |
| `04 Filing and Formalities` | As-filed papers, declarations, assignments, filing receipts |
| `05 USPTO Correspondence` | `01 Incoming` for what the Office sends, `02 Outgoing` for what you file |
| `06 Prosecution` | Responses, amendments, interview notes, appeal papers |
| `07 Issuance and Post-Grant` | Allowance, issue fee, the patent, maintenance fees |
| `08 Foreign and PCT` | One subfolder per foreign or PCT counterpart |
| `09 Billing Records` | Invoices and payment records for the matter |
| `90 Client Exchange` | The only folder you share with the client (see below) |
| `99 Closed Matter Records` | The closing letter and final file when the matter ends |

A file sitting loose in the matter folder, outside the numbered subfolders,
has not been sorted yet. Drag it where it belongs when you next touch it.

To file something: save it or drag it into the right subfolder. To file an
email attachment: in Outlook choose **Save As** and pick the matter subfolder
under **Box**.

## How to find a matter

- **You know the client**: Box → client folder → matter folder.
- **You know the docket number or a few words**: click the Box icon by the
  clock and type in the search box. Box searches file names, folder names,
  and the words inside Word and PDF documents. Typing a docket number finds
  the matter folder and every document that mentions it.
- **You remember roughly when**: in a matter folder, click the
  **Date modified** column to sort.

Client folders are named by client number for now (`Client 12345`). Tell us
the client's name and the folder is renamed. Docket files whose client we
could not confirm wait in `03 Historical Files To Be Filed`, under
`Dockets To Be Confirmed`, laid out by docket number.

Older files that could not be matched to a matter are in
`03 Historical Files To Be Filed`, laid out the way they were on the old
drive. Search covers them too. When you find one you need, drag it into its
matter.

## How to share with a client

Use the matter's `90 Client Exchange` folder and nothing else. The rest of
the matter folder stays private to the firm.

- **Send documents to the client**: put a copy in `02 To Client`. Right-click
  the file or folder → **Share** → **Copy Shared Link**. In the window that
  opens, set access to **People with the link**, turn on a **password** and
  an **expiration date**, then paste the link into your email. Send the
  password separately.
- **Get documents from the client**: open Box in the browser, go to
  `01 From Client`, choose **File Request**, and email the client the link it
  gives you. The client uploads without needing a Box account, and the files
  land in that folder.
- **Signatures**: put the document in `03 For Signature`.
- **Invoices for the client**: `04 Invoices`.

Do not use **Invite People** to add a client to a folder. Adding outside
people as collaborators can add a charge to the firm's Box plan. Use links as
above. If a client truly needs ongoing access, ask first.

## A few rules that prevent trouble

- Work on documents where they are, in the Box folder. Do not copy a matter
  to the desktop, edit there, and copy it back.
- Do not rename or move the numbered subfolders. Add your own subfolders
  inside them if you need more.
- Deleting in Box deletes for everyone. If you delete by mistake, the file
  can be restored from Trash in Box on the web.
- New client or new matter: ask for the folders to be created. They are made
  from a template so every matter looks the same.

Something missing, in the wrong place, or not opening: say so. The old drives
are untouched, so nothing has been lost.
