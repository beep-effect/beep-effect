# Reflection — codex-security-findings-2026-07-08 (2026-07-14, codex)

## Summary

The retained deliverable is the triage and remediation of the July 8 security
batch, PR 338 merge evidence, and exact closure ledger for 30 remediated
findings. Closeout revealed that the scanner had already done the correct final
state transition once those issues were no longer detected.

## Tooling experience

- **Worked:** The exact 30-ID allowlist and refreshed open view proved a zero
  packet-applicable open count without touching newer findings.
- **Didn't:** A later closed-archive audit timed out, and the authenticated shell
  stopped rendering the findings panes after reconnection.
- **Frustrating:** Manual closure language could have tempted an unnecessary
  reopen merely to replace accurate scanner provenance.
- **Wished existed:** A stable export that joins packet finding IDs to current
  open/closed status without browser rendering dependence.

## Implementation improvement opportunities

- Preserve `Fixed (scanner auto-close; issue no longer detected)` as the exact
  reason when that is what the service recorded.
- Keep later scanner batches outside the packet even when they share the same
  repository dashboard.

## Goal & prompt critique

The closeout contract should explicitly allow scanner auto-close as success and
require allowlist matching before manual actions. That would remove ambiguity
about reopening archived records and protect unrelated newer findings.

## TODOs worth codifying

- Require exact ID allowlists for dashboard mutation workflows.
- Treat one captured conclusive refresh as valid when a repeat is blocked by
  browser rendering failure.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Never mutate findings outside the packet allowlist — the
  nine visible opens belonged to newer work.
- **MEDIUM — Best practice:** Retain scanner provenance — no-longer-detected is
  the expected post-remediation closure signal.
- **LOW — Consideration:** Avoid redundant browser loops — repeated proof adds
  little once exact IDs and a conclusive live count are recorded.
