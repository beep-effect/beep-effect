# Reflection — semantica-canary (2026-09-02, codex)

## Summary

The goal minted the headless Semantica lab, ran C0 through C2, and retained
checksum-controlled live/replay evidence for every stage. It parked when the
first C0 contract failed, re-entered through a bounded evidence-quote
candidate, and finished with five dated family verdicts. The C2 pass now sends
the two queued successor questions back to the exploration at `decompose`.

## Tooling experience

- **Worked:** Schema-decoded reports, content-addressed provider replay, and
  `SHA256SUMS` made the final evidence audit mechanical. The breaker record in
  PR #853 and the decompose decision in PR #856 kept a failed C0 probe from
  turning into an unbounded candidate search. PRs #923, #932, #934, and #938
  then left a stage-by-stage evidence chain.
- **Didn't:** Gitleaks classified deterministic evidence digests as generic
  API keys, which split allowlist work into PRs #935 and #939. Agent-local
  `op whoami` also misdescribed the operation-scoped authorization that the
  existing `op://` wrapper could obtain. P5 Yeet could not start its lanes
  because the managed session mounted the linked Git metadata read-only.
- **Frustrating:** The C0 full-W1 run emitted no per-document progress while
  live work took 1,906,490 ms and replay took 580,206 ms. Concurrent unowned
  edits in the original C1 checkout then made an otherwise focused proof
  unsuitable for publication.
- **Wished existed:** A single closeout command should verify checksum
  manifests, hash unlisted evidence, compare report pairs, and compare the
  archived values with dated decision prose.

## Implementation improvement opportunities

- Add non-digest progress events for parse, provider wait, grounding, ledger,
  projection, and evaluation. They would make a long run observable without
  changing `EvalReport` identity or exposing provider text.
- Keep workload-sized child-process inputs in schema-decoded files. The C2
  crash probe's first argv transport reached `E2BIG`; the final bounded-file
  protocol is the right pattern for later storage and reasoning spikes.
- Extend `c2/SHA256SUMS` to cover `crash-identity.log`, then make the closeout
  check fail if any regular artifact in a stage directory lacks an entry.
- Compare decision metrics with the final archived report before closing. The
  C2 verdict is valid, but the merged archive lagged its dated prose by one
  unpushed commit, and the prose carried Tier-L figures from an earlier probe.

## Goal & prompt critique

The original `GOAL.md` made P5 a short instruction: reflect, archive evidence,
and flip state. Replace it with: "Verify each stage's checksum manifest,
compare every live/replay report pair byte-for-byte, inventory unlisted files,
and reconcile archived values with dated decision claims before reflection."
It should also say that an external atlas lane may supply separate evidence;
the closeout agent must neither infer nor claim that write.

## TODOs worth codifying

- Add `beep goals evidence-audit <slug>` with complete-directory checksum and
  report-pair checks.
- Add a generated Gitleaks classification for known public digest fields in
  schema-validated evidence reports.
- Add checkout ownership to the pre-proof checklist for any run that can
  outlive an interactive edit loop.
- Put the exact output-suppressed `op run` preflight in hosted-canary guidance;
  never bridge agent authorization with copied session variables.
- Add a pinned-base Yeet mode for managed linked worktrees. It must preserve
  the full lane set while avoiding fetch and detached-worktree writes.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Rerun semantic proof after a grounding-contract edit.
  The first C0 reports were deterministic, but PR #853 showed that their
  repeated-surface anchors were semantically unsafe.
- **MEDIUM — Best practice:** Keep result identity separate from run telemetry.
  The byte-identical reports and distinct sidecars proved replay without
  pretending live and offline timing should match.
- **LOW — Consideration:** Reopen queued successors at `decompose`. A C2 pass
  makes the storage and reasoning questions eligible; it does not justify
  scaffolding either packet before its bounded spike is shaped.
