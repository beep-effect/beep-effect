## Authority resolution procedure

First identify whether a statement describes observed behavior, governing
doctrine, historical evidence, upstream state, or an illustration. Select the
authority appropriate to that claim. When code disagrees with binding doctrine,
record both sources and route an implementation fix unless an explicit
superseding decision changes the rule. When authorities genuinely conflict,
stop only the dependent repair and present the concrete conflict.

Age, a model's confidence, and the number of agreeing documents do not establish
authority. Repetition may be a shared stale source. Historical accuracy and
present-day usefulness receive separate determinations.
