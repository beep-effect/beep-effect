## Public Summary

A direct local TCP client can forge the allowed proxy login and access the service through its filesystem authority. Loopback and owner-only JSONL permissions do not authenticate that client.

## Captured-baseline Analysis

Cloud validation establishes the source-to-sink path and a cross-UID transport prerequisite, with no full hub exploit run. Captured baseline source has only the login check. Scoped regression proof is recorded below.

Validation, Evidence, and Attack-path analysis were read from the authenticated
Cloud detail on 2026-10-20. The private capture is ignored under
`raw/CSF-001-cloud-detail.txt`; signed artifact links are omitted.
This is source analysis, not a passing runtime proof. Baseline: `8086a42233`.

## Implemented Remediation

Require a configured Redacted bearer credential on every request before trusting the allowed login; compare credentials in constant time. Update the unit and client provisioning instructions. Forged-login and wrong-token regressions are authored.
