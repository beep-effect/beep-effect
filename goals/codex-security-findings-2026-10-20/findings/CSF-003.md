## Implemented Remediation

Inventory and validate every ZIP name before inflation, retaining the 20 MiB source
and 512-entry bounds. Inflate only Mammoth-consumed XML and relationship parts in
1,024-byte compressed chunks, charging actual selected output against at most
8 MiB and the operation byte allowance. Ignore media, themes, settings and font
tables without creating their inflaters. Bound XML events by
`max(1, min(1000000, floor(effectiveXmlBytes / 8)))`, retain depth 128, and reject
DTDs. Resolve main and five related XML families with Mammoth-compatible lookup,
including custom and extensionless targets; select only the first existing target
for each of six fixed relationship types. Rebuild a stored ZIP from validated
consumed entries before Mammoth reads it. Preserve UTF-8/BOM handling and ZIP
alias rejection. See `research/docx-review-proof.md` for round-two compatibility
controls and qualification. Final remediation merged in PR #1930; the current
closure receipt above records the exact Cloud identity revalidation.
