## Implemented Remediation

Discover at most 128 combined raw container candidates before header-window decoding or candidate object parsing, bounding cumulative window scanning to 8 MiB and candidate parses to 128. Overflow returns structural facts with `containerDiscovery: "limit-reached"`; it does not fail inspection or reuse the inflate-specific `streamCheck` status. Global stream completeness requires both statuses to be `complete`. Header number widths are bounded to prevent regex suffix retries on long digit runs.

Round-one review correctly identified that throwing on the 129th raw marker rejected valid loaded PDFs containing harmless marker text. The additive schema field defaults to `complete` for existing constructors/serialized payloads; `encrypted` explicitly identifies skipped discovery. The bounded fallback avoids relying on a new parser cursor/rewind protocol or removing the resource budget.
