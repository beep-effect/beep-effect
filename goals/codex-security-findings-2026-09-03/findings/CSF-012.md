# CSF-012: Unbounded photo reports allow memory\-exhaustion denial of service

- Severity: Informational
- Codex ID: `ee6b279568bc8191aab576d4c1ea9783`
- Source commit: `bfb20e7688fa1aa655f84f614e861e71afbf646b`
- Owner: local photo-face worker and repo CLI boundary
- Status: remediated; repository proof in progress

## Public Summary

Photo matching discovered and retained unbounded image, face, diagnostic, and
JSON collections across Python and TypeScript. Large directory trees or model
output could exhaust worker or parent memory.

## Current-HEAD Validation

- Verdict: confirmed at the packet's initial HEAD.
- Disposition: `remediate`.
- Lane: `L6-photo-bounds`.
- Owner: local photo-face worker and repo CLI boundary.
- Rationale: neither protocol schemas nor discovery/execution paths shared an
  enforceable size contract.

## Remediation

Status: implemented. Worker protocol v3 echoes exact limits: 256 references,
10,000 candidates, 32 faces per image, 65,536 reported faces, 64 MiB JSON, and
1 MiB diagnostics. Discovery stops at limit plus one, schemas cap retained
arrays, aggregate evidence is checked, and errors instruct callers to split
batches. Parent-side directory enumeration streams only through the first
excess entry before sorting, and the JSON byte ceiling includes its framing
newline. The public report and CLI contract remain v2.
