# CSF-007: Predictable /tmp root permits cross\-user scheduler denial

- Severity: Informational
- Codex ID: `84c1f9753c888191a7d8a94ac8d55f03`
- Source commit: `1692d75ff2e50cd8e5d2ece213bbc4624bf7cddd`
- Owner: repo CLI runtime root
- Status: remediated in PR #949; repository and hosted proof complete; Codex
  finding closed as `Already fixed`.

## Public Summary

The scheduler runtime root used a predictable shared temporary path. Another
local user could pre-create path components and deny or redirect runtime state.

## Current-HEAD Validation

- Verdict: confirmed at the packet's initial HEAD.
- Disposition: `remediate`.
- Lane: `L1-filesystem-safety`.
- Owner: repo CLI runtime root.
- Rationale: the POSIX default lived under the shared temporary namespace even
  though the state is user-private and persistent for a run.

## Remediation

Status: implemented. POSIX runtime state now defaults to the canonical
user-owned home path `.beep/runtime`; Windows retains its equivalent user-local
home location. Existing canonicalization and ownership checks remain active.

- `packages/tooling/tool/cli/src/internal/repo-run/RuntimeRoot.ts`
- `packages/tooling/tool/cli/test/runtime-root.test.ts`
