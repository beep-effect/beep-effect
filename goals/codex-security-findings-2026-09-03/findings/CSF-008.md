# CSF-008: Unbounded claim ranges exhaust memory during normalization

- Severity: Informational
- Codex ID: `af1409097bf48191b4481ecd0b9e90d6`
- Source commit: `f1383148c6c4873badd9a4c9f4cf9baa83c9601a`
- Owner: patent-document normalization
- Status: remediated; repository proof in progress

## Public Summary

Patent claim normalization expanded textual parent ranges before checking that
they referred to valid prior claims. A very large range could allocate
attacker-controlled memory synchronously.

## Current-HEAD Validation

- Verdict: confirmed at the packet's initial HEAD.
- Disposition: `remediate`.
- Lane: `L2-bounded-parsing`.
- Owner: patent-document normalization.
- Rationale: `Array.range` ran before ordering, prior-claim, and cardinality
  validation.

## Remediation

Status: implemented. Range endpoints must be ordered, strictly precede the
current claim, and contain at most 1,024 parents before expansion occurs.

Changed files:

- `packages/law-practice/domain/src/values/PatentDocument/PatentDocument.normalizer.ts`
- `packages/law-practice/domain/test/PatentDocument.test.ts`
