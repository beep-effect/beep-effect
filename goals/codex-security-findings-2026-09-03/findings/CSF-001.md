# CSF-001: Dangling worktree cleanup can delete uncommitted source

- Severity: Informational
- Codex ID: `033be00d8a588191b81f6e3d5246ac8a`
- Source commit: `c8e7408034351fecda38a915ac170d99a7dc329c`
- Owner: repo CLI runtime cleanup
- Status: remediated; repository proof in progress

## Public Summary

The dangling-worktree janitor treated small extra files as disposable content
and recursively removed the entire candidate directory. A stale-looking stub
could therefore contain uncommitted source and still be deleted.

## Current-HEAD Validation

- Verdict: confirmed at the packet's initial HEAD.
- Disposition: `remediate`.
- Lane: `L1-filesystem-safety`.
- Owner: repo CLI runtime cleanup.
- Rationale: classification inspected byte totals rather than requiring the
  exact single regular `.git` file shape, and apply used recursive deletion.

## Remediation

Status: implemented. Classification now requires exactly one non-symlink
regular `.git` file no larger than 4 KiB. Apply rechecks shape, age, and live
process references, removes only `.git`, and uses atomic non-recursive `rmdir`;
any raced or pre-existing content survives.

- `packages/tooling/tool/cli/test/tmpfs-reap.test.ts`
