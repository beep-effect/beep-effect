# CSF-005: Quadratic HTML checks enable SafeDocument RPC denial of service

- Severity: Informational
- Codex ID: `65579c81b8708191b6120fafce470a09`
- Source commit: `09ad07d1fceca4e0f595dcdd7a56f422bde0ba3e`
- Owner: Markdown and HTML modeling
- Status: remediated in PR #949; repository and hosted proof complete; Codex
  finding closed as `Already fixed`.

## Public Summary

Safe Markdown documents could drive quadratic HTML conformance work because
element checks repeatedly searched ancestor and table collections. The public
safe-document boundary also accepted an unbounded node count.

## Current-HEAD Validation

- Verdict: confirmed at the packet's initial HEAD.
- Disposition: `remediate`.
- Lane: `L2-bounded-parsing`.
- Owner: Markdown and HTML modeling.
- Rationale: repeated whole-tree/ancestor scans compounded on attacker-sized
  trees and no global schema boundary limited work.

## Remediation

Status: implemented. HTML traversal carries the enclosing table path directly,
removing repeated ancestry/table scans. SafeDocument validation iteratively
counts nodes and rejects documents above 10,000 before HTML projection. The
counter stops enqueueing a wide node's children as soon as the ceiling is
provably exceeded, so the rejection path does not duplicate the remaining AST.

Changed files:

- `.impeccable/config.json`
- `packages/foundation/modeling/html/src/Html.conformance.ts`
- `packages/foundation/modeling/md/src/Md.safe.ts`
- `packages/foundation/modeling/md/test/Md.test.ts`

## Verification

- `bunx vitest run packages/foundation/modeling/md/test/Md.test.ts` — passed.
- Boundary regressions accept exactly 10,000 nodes and reject 10,001.
- A wide-child regression makes the first child beyond the required decision
  point unreadable and proves the counter never accesses it.
- The scoped Impeccable suppression covers three literal diagnostic strings
  containing an image tag; they are not rendered markup.
