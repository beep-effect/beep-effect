# CSF-009: Mutable proof prototypes allow citation forgery

- Severity: Informational
- Codex ID: `b027eb838a648191b339e4c1550417da`
- Source commit: `6947e1c495f4b354950d541953c87d418e1a455d`
- Owner: provenance modeling
- Status: remediated; repository proof in progress

## Public Summary

Verified citation values inherited mutable prototype getters. Replacing a
getter after verification could change the anchor used for later receipts while
the value continued to pass the verified-value guard.

## Current-HEAD Validation

- Verdict: confirmed at the packet's initial HEAD.
- Disposition: `remediate`.
- Lane: `L3-provenance-capabilities`.
- Owner: provenance modeling.
- Rationale: verification authority and payload retrieval both depended on
  caller-mutable prototype state.

## Remediation

Status: implemented with CSF-003. Issued values are frozen, their prototypes and
constructors are frozen, guards use private `WeakMap` membership, and receipt
conversion reads private snapshots rather than public getters.

Changed files:

- `packages/foundation/modeling/provenance/src/VerifiedTextAnchor.ts`
- `packages/foundation/modeling/provenance/test/VerifiedTextAnchor.test.ts`
