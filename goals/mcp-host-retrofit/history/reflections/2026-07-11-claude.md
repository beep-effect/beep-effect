# Reflection — mcp-host-retrofit (2026-07-11, claude)

## Summary

Retroactive closeout. The retrofit itself shipped on 2026-07-01: both hosts
(`nlp-mcp`, `m365-mcp`) adopted `@beep/mcp-kit`'s new `sanitizedToolkit`
export (the empirically-proven fix for the span leak, since
`McpServer.toolkit`'s dispatch closure offers no post-registration wrap
seam), 17 `StreamingToolkit` + 11 `M365Tools` tools gained
`annotateFourHints`, tier-gate was recorded not-applicable per the P0
finding, and the kit README consumer table was updated — all verified green
in P2 and merged directly to `main` via `8dbd778313` (pre-PR-ruleset). The
work was done; only the paperwork drifted. Verdict: goal achieved, closeout
ten days late.

## Tooling experience

- **Worked:** The packet's own record was strong — PLAN.md's phase table
  captured the P0 empirical finding (why wrapping `Layer.launch` fails, why
  a new kit export was the only viable seam) in enough detail that a
  reconciler ten days later could verify everything against `main` with a
  couple of `rg`/`git show` calls.
- **Didn't:** Nothing forced the manifest flip when the branch merged.
  P3/P4 sat "pending" while the deliverables were live on `main`.
- **Wished existed:** A goals doctor/index command that diffs manifest
  phase claims against git reality (see findings).

## Implementation improvement opportunities

## Goal & prompt critique

The SPEC/PLAN were precise and the not-applicable tier-gate handling was
exemplary (recorded, not invented). The one gap: the completionGate's
hard `requiresPullRequest` wording had no escape hatch for the
direct-to-main merge that actually happened, leaving P3 formally

## Lessons (confidence-tiered)

- **HIGH — Critical:** Flip manifest phases in the same commit/session as
  the merge that discharges them; paperwork decoupled from landing is
  paperwork that drifts.
- **MEDIUM — Best practice:** Completion gates should name their
  equivalent-evidence path so process changes (like the PR-only ruleset
  arriving 2026-07-06) don't strand already-merged goals.
- **LOW — Consideration:** When a P0 finding defers work out of scope,
  re-surface it explicitly at closeout so it survives the packet.
