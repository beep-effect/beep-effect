# Reflection — one-round-loop (2026-07-14, codex)

## Summary

The retained P0/P1 outcome shipped a CLI-owned local CI replay and a fixed-seed
property-law lane with a rotating nightly breadth sweep. The evidence supports
closing that outcome while explicitly deferring the medium and stretch tiers.

## Tooling experience

- **Worked:** Same-SHA shadow runs, deliberately broken parity fixtures, the
  packet dogfood ledger, and fixed-seed property replay produced concrete
  evidence instead of inferred parity.
- **Didn't:** A locally green property lane initially used different random
  inputs from CI, so it could not predict the hosted verdict.
- **Frustrating:** One wide dependency edit exposed structural gates across
  multiple pushes even though each gate was available locally.
- **Wished existed:** A pre-push warning that recognizes broad package
  dependency edits and insists on one complete local battery before publish.

## Implementation improvement opportunities

- Keep the PR property lane deterministic and the nightly lane exploratory.
- If the CI-bottleneck trigger fires, prioritize the P2 items from measured
  causes rather than automatically reopening every deferred item.

## Goal & prompt critique

The original Definition of Done made P2, P3, and the ruleset flip part of the
same closure gate as the thesis-bearing P0/P1 work. A revised goal should label
P0/P1 as the minimum outcome and make later tiers conditional on measured CI
round-trip pressure from the start.

## TODOs worth codifying

- Track median PR CI round-trips as the reopening signal for this packet.
- Preserve the rule that exclusions narrow inputs or invariants; they must not
  hide failures by lowering run counts.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Use identical fixed seeds for local and PR property
  lanes — verdict parity requires identical inputs as well as identical commands.
- **MEDIUM — Best practice:** Run a full battery after wide dependency edits —
  sequential pushes turn locally available gates into avoidable CI rounds.
- **LOW — Consideration:** Reopen deferred tooling only from measured pressure —
  valuable follow-ons should not delay closure of a proven retained outcome.
