# CSF-006: Empty folded quote causes infinite anchor search

- Severity: Informational
- Codex ID: `0bdf89a067648191b422fe675dd0780a`
- Source commit: `2977c32e2524f4fe9966d9dcf561041aafe8f51e`
- Owner: Semantica gold quote anchoring
- Status: remediated; focused regression proof green

## Public Summary

A quote consisting only of discretionary PDF hyphenation folded to an empty
string. Searching for that value produced a non-advancing occurrence stream.

## Current-HEAD Validation

Confirmed on the current head before remediation. The exact search rejected
the nonempty raw quote, then the whitespace-folded fallback searched for an
empty value indefinitely.

## Remediation

Both empty raw quotes and quotes that become empty after folding now return no
anchor before occurrence search.

- `apps/labs/semantica/test/Gold.test.ts`
