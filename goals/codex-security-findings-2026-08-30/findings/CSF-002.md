# CSF-002: Auditor executes repository\-supplied adapters on the host

- Severity: Medium
- Codex ID: `84e157bd2ccc8191831738dfd18514fb`
- Source commit: `3506c59de3fba951e1a25237ddd89101bd7cedce`
- Owner: ontology foundational auditor adapter execution
- Status: remediated; focused regression proof green

## Public Summary

The Observe stage executed an adapter stored inside the repository being
audited with the host Python environment and ambient filesystem and network
access.

## Current-HEAD Validation

Confirmed on the current head before remediation. A preexisting adapter at the
documented repository path ran before validator checks could establish trust.

## Remediation

Adapters must now be authored or audited in a user-owned protected directory
outside the target repository. A dedicated runner rejects unsafe paths and
uses bubblewrap to expose the repository read-only, one output directory
writable, no network, a scrubbed environment, and bounded resources. Missing
isolation support fails closed.
