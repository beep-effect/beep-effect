# CSF-001: Page\-controlled validation hook enables host command execution

- Severity: Medium
- Codex ID: `4cd67192c1088191a93381516271f51e`
- Source commit: `80d16e50c8c3ed2d80bcd0d8afd0773d23869f20`
- Owner: Impeccable live copy-edit host boundary
- Status: remediated; focused regression proof green

## Public Summary

The browser-visible session token authorized a route that could launch a local
coding agent and mutate repository files. The same path ran an optional
repository-defined package script through a shell after edits.

## Current-HEAD Validation

Confirmed reachable on the current head before remediation. A page carrying
the injected token could invoke the host-capable route, and the post-apply
check read its command from repository-controlled `package.json` content.

## Remediation

A separate operator-only capability, never injected into the inspected page,
is now required before the commit route can launch an agent or mutate files.
Repository-defined validation commands were removed from both the prompt and
the post-apply execution path.
