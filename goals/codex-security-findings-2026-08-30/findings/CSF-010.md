# CSF-010: Cloud bootstrap executes a mutable remote installer

- Severity: Informational
- Codex ID: `e9660bfcc3e88191973971212b8131f0`
- Source commit: `fa420919d3154a5f6ab21c64012c7cb5c16a670a`
- Owner: Cursor cloud Bun bootstrap
- Status: remediated; focused regression proof green

## Public Summary

Cloud bootstrap piped the mutable installer served by `bun.sh` directly into a
shell, despite the repository already carrying an exact Bun version and
archive digest.

## Current-HEAD Validation

Confirmed on the current head before remediation. HTTPS authenticated the
current endpoint but did not bind the executed installer bytes to the repo.

## Remediation

Bootstrap downloads the exact immutable release archive, verifies it against
`.bun-linux-x64.sha256`, and installs the binary only after verification.

Changed files:

- `.cursor/install.sh`
- `packages/tooling/tool/cli/test/runners-bake.test.ts`

## Verification

- `bash -n .cursor/install.sh`
- The bootstrap security regression proves the mutable installer is absent and
  checksum verification precedes installation.
