# CSF-005: Unanchored GPG status check permits forged op binary

- Severity: Informational
- Codex ID: `022c47c20a1c81918bf8772c0581f88e`
- Source commit: `2c0c8eb04699341b02890602a39b9caf522ac101`
- Owner: Cursor cloud bootstrap signature verification
- Status: remediated; focused regression proof green

## Public Summary

The cloud bootstrap searched GnuPG output for the pinned `VALIDSIG` text
without anchoring it to a machine-readable status record.

## Current-HEAD Validation

Confirmed on the current head before remediation. Attacker-controlled identity
text could satisfy the loose substring check while a different key signed the
binary.

## Remediation

The verification pipeline now requires an exact, line-anchored GnuPG status
record for the pinned fingerprint. Bootstrap work directories are allocated
under a private cache root and allocation failure exits before any download or
root-derived path can be used.

Changed files:

- `.cursor/install.sh`
- `packages/tooling/tool/cli/test/runners-bake.test.ts`

## Verification

- `bash -n .cursor/install.sh`
- The bootstrap security regression checks the anchored status expression and
  behaviorally proves a failed `mktemp` cannot reach `curl`.
