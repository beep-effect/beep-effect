# CSF-007: Raw event digesting enables stack\-exhaustion denial of service

- Severity: Informational
- Codex ID: `5167e0476d4c8191bad46d2e7d96d96f`
- Source commit: `80c5693d2a6bb7c25163d392839f1dfc80e1cf97`
- Owner: repo-cli packet event store
- Status: remediated; focused regression proof green

## Public Summary

The packet event reader computed identity by recursively canonicalizing the
full untrusted JSON value, including schema-unknown nested data.

## Current-HEAD Validation

Confirmed on the current head before remediation. A valid event with a deeply
nested unknown member could exhaust the JavaScript stack before the advisory
read path converted it to a chain issue.

## Remediation

The store now computes identity from the decoded `PacketEvent`. Unknown input
keys are discarded by the schema before the canonical encoder sees them.

Changed files:

- `packages/tooling/tool/cli/src/commands/Goals/PacketCore/PacketEventStore.ts`
- `packages/tooling/tool/cli/test/goals-packet-core.test.ts`

## Verification

- The packet-core suite passes a valid event carrying a 20,000-level unknown
  array without stack exhaustion.
- `@beep/repo-cli` package verification.
