# CSF-009: Unpinned CDN script can steal credentials entered in docs UI

- Severity: Informational
- Codex ID: `995a450483d48191938dfeef27a75564`
- Source commit: `09bd930bbc173f2846b54585f60254a5ecbdfa44`
- Owner: API docs committed-spec Scalar UI
- Status: remediated; focused regression proof green

## Public Summary

Committed-spec documentation pages loaded an unversioned third-party Scalar
script from a public CDN in the same UI where users can enter API credentials.

## Current-HEAD Validation

Confirmed on the current head before remediation. Contract-generated docs
already used bundled Scalar code; only the committed-spec path was exposed.

## Remediation

The existing Effect runtime already embeds Scalar `1.43.5` for
`HttpApiScalar.layer`. The committed-spec route now serves that installed
bundle from the app origin, and its pages receive a content security policy
that only permits same-origin scripts. No new package enters the dependency
graph.

Changed files:

- `apps/labs/api-docs/DESIGN.md`
- `apps/labs/api-docs/src/Docs.routes.ts`
- `apps/labs/api-docs/test/Docs.routes.test.ts`

## Verification

- The API docs route test proves the CDN is absent, the pinned same-origin
  Effect-embedded asset is Scalar `1.43.5`, and `script-src 'self'` is present.
- The security lane proves the remediation adds no advisory-bearing package.
- `@beep/api-docs` package verification.
