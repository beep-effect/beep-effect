# Reflection: beep-effect-web-alchemy (2026-10-31, claude)

## Summary

beep-effect.com is served by a TanStack Start app on Cloudflare through an Alchemy v2
per-package stack. State lives in the Cloudflare state store, and prod deploys run from CI on
`main` (first green run 41244684210, after #2435 merged as `441c6d94de`). The goal shipped
every decision from the grill. Most of the time went to repo gates, not to Alchemy.

## Tooling experience

- **Worked:** Alchemy's `Website.Vite` plus `Cloudflare.state()` deployed on the first try once
  credentials were right. The redeploy was a no-op, and the domain `redirects` prop gave www → apex
  without a hand-written rule. The `cf` CLI made it possible to script the token mint.
- **Didn't:** The IaC token in 1Password lacked Secrets Store, Durable Object and ruleset scopes.
  The agent `op` shim cannot write, so the first mint orphaned a token.
- **Frustrating:** Repeated generated-file conflicts on main merges, and hosted-only reds that
  local cheap gates do not replay: coverage row, ci-runner-security exemption, ai-sync deny rule.
- **Wished existed:** One command that lists every repo baseline or exemption a new app must
  register.

## Implementation improvement opportunities

- Personal stages (`live_$USER`) are documented but never exercised in CI. A preview-stage
  workflow for PRs would cover them.
- The smoke check asserts status codes only. Checking the `<title>` would catch an
  empty-but-200 deploy.

## Goal & prompt critique

- GOAL.md should list the operator-only steps up front: token mint via `op-human`, the GitHub
  environment and secrets, and installing the workflow when an edit deny rule applies. The
  agent could then batch those requests into one operator touchpoint instead of three.

## TODOs worth codifying

- See frontmatter `todos`.

## Lessons (confidence-tiered)

- **HIGH (critical):** Count commit-subject length before every commit. GitHub squash
  commitlint rejects anything over 98 characters at merge time, after all the CI spend.
- **HIGH (critical):** Never pattern-kill processes. Stop only your own PIDs, because other
  sessions' final-checks share the machine.
- **MEDIUM (best practice):** For a generated-file conflict, take main's copy and regenerate,
  never hand-merge it.
- **LOW (consideration):** Alchemy v2 is beta (`2.0.0-beta.84`). Pin it, and re-read the
  source in `.repos` before bumping.
