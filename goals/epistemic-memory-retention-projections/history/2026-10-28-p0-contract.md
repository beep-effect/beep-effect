# Retention projection P0 contract

The bitemporal core is completed-retained. This lane consumes its EdgeVersion
and ClaimDisposition entities without changing either schema or any table.
Persisted EdgeVersion rows are the core authority write seam; candidate detector
rows and arbitrary fact payload review flags are never an acceptance signal.
The caller supplies an organization and bounded logical-edge keys. Reads must
match both scope and keys; no global scan or operator-memory source is allowed.

A server-owned read-only repeatable-read transaction selects the visible edge
versions using both half-open temporal axes and claim dispositions resolved by
knownAt. Each claim endpoint uses its latest disposition by (resolvedAt, id);
absence stays unresolved. Both endpoint dispositions are visible. Group counts
count a row once in each distinct disposition bucket; they need not sum to the
row count. Non-claim endpoints have no claim disposition.

Projection identity is the canonical request (organization, sorted unique keys,
validAt, knownAt, disposition filter), mechanism version, policy and approved
calibration identity. No clock, random id, filesystem path, or generation time
enters report bytes. Canonical output is schema-encoded sorted JSON and a plain
text report. Measured memory pressure means canonical edge-payload UTF-8 bytes
and visible edge count, not database allocation, RAM, tokens, or inferred
salience. Missing keys remain explicit in the report.

Policy data supplies age cutoffs, rational age decay scale and a payload-byte
budget; no production defaults ship. A deployment-owned calibration registry is
the sole admission path. A receipt must bind the exact policy, organization,
mechanism, measured dataset and evaluation report, approved human principal,
nonzero sample count and approval/expiry bounds. Missing, synthetic, mismatched
or expired receipts leave all rows unclassified and pressure thresholds inert.
Schema validity alone never activates policy. This release registers no receipt.
Receipt authenticity and evaluation quality belong to the controlled registry,
not request JSON. Rational age decay is a repo-native diagnostic of record age;
it never claims access/reinforcement or confidence that authority does not store.

The projection store owns only report.json and report.txt beneath its dedicated
root. Removing that complete store and rebuilding from the same accepted
snapshot, policy and registry must reproduce both bytes and query answers.
The adapter contains SELECTs only. Integration proof compares authoritative
edge/disposition rows before and after report generation and complete deletion.
A snapshot is transaction-consistent; separate rebuilds require identical
source state. A changed authority snapshot must produce a changed report.

## Provenance and license inventory

The source exploration, July core contract and August retention amendment were
read before implementation. The inherited research contains donor examples;
its older recommendations to port constants are superseded by the explicit
August decision and current SPEC. Agentmemory is reference-only:
https://github.com/rohitg00/agentmemory . No donor implementation, constants,
dependency or upstream licensing assertion is needed or adopted. Existing core
Graphiti notices remain with their owning modules. All new behavior is derived
from this contract and existing repo entities. No RRF or operator memory work.

## Reversal

Remove the read-only consumers and disposable store; there is no authority
migration, data deletion or policy activation to roll back.
