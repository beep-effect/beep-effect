# Reflection — legal-position-relator-runtime (2026-08-07, claude)

## Summary

Both rungs landed in one overnight run: the closed eight-member Hohfeld domain
with proven-total/involutive/commuting derivations and the one-stored-relation
relator (P1, failing-first test evidence in `history/`), then the rung-2
transition/correction vocabulary, five-table append-only durability with an
executed PGlite proof, and a 32-test competency-question acceptance suite (P2).
The rung-2 cross-slice handoff was deferred with guardian-checked standing
evidence (SPEC decision 13) — the sibling's owner-ruling precedent, and the only
option requiring no owner sign-off. Verdict: the packet's unusually precise SPEC
made eight delegated Opus stages land near-first-try; the real costs were
environmental (session limits, docgen escalation) and one foundation-tier schema
gap discovered late.

## Tooling experience

- **Worked:** the packet contract itself (quote-anchored citations survived line
  drift; the four-shape handoff pre-analysis made P0 decisive); Opus 5 subagents
  with design-note-first briefs and on-disk report handoffs (two session-limit
  deaths, zero work lost); the CandorRecord/candor-gate precedent trio (every
  durability decision had a live in-slice answer); the db-admin migration lane
  (delta generation, snapshot chaining, and a proof oracle that survived a
  negative probe); `beep tsconfig-sync`; the guardian review, which caught the
  "unbound outbound port" trap — a port typed in epistemic vocabulary exercises
  the exception the moment it is authored.
- **Didn't:** `S.HashSet` on persisted fields (Encoded = HashSet; both decode
  legs reject what the database returns); package `check` not typechecking
  `test/`; `assertSchemaArbitraryDecodesToSelf` on transforming schemas;
  `withConstantDefault` on the decode path.
- **Frustrating:** `docgen:local` escalating to the full 129-package proof twice
  because one root-alias row changed; the inherited-red schema-catalog lane that
  cannot be paid down incrementally; `SelectedRowFieldShapeError` surfacing at
  test-import time with a message naming the storage rule rather than the
  offending field shape.
- **Wished existed:** an immutable array-backed HashSet schema (now exists —
  this goal added it); a shared encoded-round-trip test helper; a
  foundation-port coupling-record lint; a session-limit-aware agent scheduler.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Probe persistence round-trips at the schema stage, not
  the storage stage — encode the fixture, JSON-serialize it, decode it back —
  because a schema whose Encoded side is a runtime container type-checks
  everywhere and fails only against a real column.
- **HIGH — Critical:** Have every delegated agent write its full report to disk
  before returning; treat the returned message as a courtesy copy. Two agent
  deaths cost zero work because the deliverable was already on disk.
- **MEDIUM — Best practice:** When a coupling decision looks like "build a port
  now, bind it later", check whether authoring the port already creates the
  coupling — import edges, not invocations, are what boundary rules count.
- **MEDIUM — Best practice:** Mirror-the-precedent beats stronger-than-precedent
  in proof suites (the TRUNCATE name-presence call): repo-wide consistency is
  what future readers trust, and strengthening one suite quietly weakens the
  precedent's authority.
- **LOW — Consideration:** Spawning a subagent while the account session limit
  is active appears to queue it for the reset window, while hitting the limit
  mid-flight kills the agent — if that mechanic holds, pre-spawning the next
  stage during a stall converts dead time into queued work.
