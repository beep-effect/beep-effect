## Evidence detail

### ONNX override declaration

- `package.json` 342–344, inside `"overrides"` (opens at 314): a version-scoped nested override `"onnxruntime-node@1.30.0": { "adm-zip": "npm:fflate@0.8.3" }`. Only this ONNX version's `adm-zip` edge is aliased.
- `bun.lock` line 2 has `lockfileVersion: 3`, which the `.md` says the scoped form requires. The override is mirrored in the lock's `overrides` block (3476, entry 3504–3506). The package row is `"adm-zip": ["fflate@0.8.3", …]` (6281), so no adm-zip code is installed (`node_modules/adm-zip` holds fflate's `esm/` and CHANGELOG).
- `patchedDependencies`: `package.json` 357–364 and `bun.lock` 3468–3475 list six entries (five retained plus knip).
- Catalog pins: `@effect/platform-node-shared` 4.0.2 (32), `@xstate/effect` 0.1.0-alpha.6 (143), `drizzle-orm` 1.0.0-rc.5-ab785fc (163), `effect` 4.0.2 (166), `fflate` ^0.8.3 (179), `onnxruntime-node` ^1.30.0 (208). The face-detection package consumes `onnxruntime-node: catalog:` (`packages/drivers/face-detection/package.json` 72).
- Range risk: the catalog says `^1.30.0` but the override and patch keys are exact `@1.30.0`. A 1.30.x bump would silently drop both. The regression test asserts fflate through `installerRequire("adm-zip/package.json")` and would catch it.
