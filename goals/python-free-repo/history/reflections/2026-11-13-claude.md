# Reflection — python-free-repo (2026-11-13, claude)

## Summary

The goal removed all 308 tracked Python files in four PRs and banned them with the `no-tracked-python` law, a lefthook hook, a cheap-tier CI lane and an AGENTS.md line.

- **Deleted:** 275 one-shot probes with no runtime consumer. Each packet carries a removal note.
- **Ported:** 33 live files.
  - photo-face moved to onnxruntime-node (#3283). Embedding cosine ≥ 0.9997 and box IoU ≥ 0.9991 against the old Python.
  - The skill scripts moved to bun TypeScript (#3293).
  - The small scripts, workflow Python and infra/r2-cache moved into repo-cli (#3296).

Verdict: done. The bulk deletion was cheap; the cost sat in hosted round trips for stale doc paths and coverage.

## Tooling experience

- **Worked:**
  - Per-packet removal notes generated by script.
  - `goals manifest --write` for the researchReports projection.
  - `yeet reply` with draft dispositions.
  - Delegating the two heavy ports to Codex Sol lanes in their own worktrees while Opus subagents ported the small scripts in this worktree.
  - beep-reviewer found a real P1: the Buffalo cache failed with EEXIST after an AdaFace run.
- **Didn't:**
  - rg's default skip of dot-directories in triage.
  - Final-check runs that I piped through `tail` lost their failure detail.
  - Two final-check processes ran at once in one worktree, one started by a subagent.
- **Frustrating:**
  - Host pressure: load ~110–130 and earlyoom killing final-check processes. The whole-repo coverage replay triggered by a bun.lock diff never finished locally, which forced the "just push" ruling.
  - I stopped a subagent's parity run because I took it for my own stale shell.
- **Wished existed:**
  - A reverse-reference query.
  - Semantic-delta in the cheap local gates.
  - A per-file scope for `lint schema-first` and the jsdoc ratchet, so fix waves can be proven without whole-repo runs.

## Implementation improvement opportunities

- **producer-diagnose speed:** it takes about 100 s against Python's 45 s, because it routes every digest through RFC 8785 JSON. A streaming canonical encoder would recover most of that inside the 300 s deadline.
- **Adapter host cleanup:** the in-process r2 adapter host loses the old Python parent-death cleanup on SIGKILL. A systemd `BindsTo=` relationship or a PDEATHSIG-style watchdog would restore it.

## Goal & prompt critique

- **r2-cache ownership:** the Non-Goals line "Porting Python that lives in infra/r2-cache (deleted wholesale by infra-alchemy-rebuild)" contradicts acceptance item 1 whenever that packet has not reached its cleanup. Replace it with "infra/r2-cache Python is ported here unless infra-alchemy-rebuild has already deleted it."
- **Per-file triage table:** the SPEC asks for a per-file triage table, but a single 308-row table duplicates the per-packet removal notes. Allow the table to list ported files individually and deleted files per packet.

## TODOs worth codifying

- A reverse-reference query that covers dot-directories.
- Semantic-delta in the cheap gates for diffs that delete tracked files.
- Detection of inline Python heredocs.

## Lessons (confidence-tiered)

- **HIGH — Critical:** search with `--hidden` (or a beep query) before deleting anything a workflow might run. A plain rg missed a live heavy.yml consumer.
- **HIGH — Critical:** when a reusable workflow is consumed `@main`, ship the consumer switch and the file deletion in separate PRs.
- **MEDIUM — Best practice:** never pipe a long gate run through `tail`; write the full log to a file. Rerunning final-check to recover failure detail cost about an hour under load.
- **LOW — Consideration:** a worktree shared by several subagents works when every commit uses explicit pathspecs. Generated catalog shards that the hooks regenerate must then be folded in by amend.
