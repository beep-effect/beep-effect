  shipped and dated it.
- **Didn't:** nothing in the yeet/goal workflow required flipping the manifest

  month.
- **Wished existed:** a `goals doctor` pass that compares phase statuses
  against git activity on declared target surfaces.

  alignment, lowercase match offsets, parse-failure tagging) all shipped

  subsequently ran over this package with ratchets now blocking.

## Goal & prompt critique

- The phase list ended with "Quality Review Fix Loop" and "Yeet And PR
  Babysitting" as separate pending phases, but neither had an owner or a
  trigger once implementation merged. A closeout phase should name the action
  that flips it (e.g. "flip manifest in the merge commit").

## TODOs worth codifying

- Goals doctor/index command cross-checking manifest status vs git evidence.
- Dated manifest note required whenever a phase is subsumed by repo-wide work.

## Lessons (confidence-tiered)

- **HIGH — Critical:** flip manifest phases in the shipping commit — the
  langextract manifest lagged reality by a month with production consumers
  live.
- **MEDIUM — Best practice:** record "this phase is subsumed by X" decisions
  when made; P5 looked abandoned when it was actually covered by PRs
  #294-#326.
