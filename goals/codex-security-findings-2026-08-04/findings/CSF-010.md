# CSF-010: Image audit can be DoSed by large image sets

- Severity: Medium
- Codex ID: `ef1d789bde688191bfb2b03e5d78a8ce`

## Public Summary

Image audit accepts unbounded source counts and image sizes, then materializes
pairwise comparisons and clusters. Large or malicious datasets can exhaust CPU,
memory, or output capacity before useful bounds apply.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Bound image audit file count, file bytes, decoded pixels, and Sharp input pixels.
