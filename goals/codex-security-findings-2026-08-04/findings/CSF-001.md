# CSF-001: Unbounded source resolution enables sidecar memory DoS

- Severity: Medium
- Codex ID: `d2b9e11e8550819193516057a336ff90`
- Source commit: `244529aa4f560421cd096c2a4a4cb3cd21923070`
- Owner: epistemic contradiction source paging / workspace source resolver
- Status: remediated; local Yeet proof green

## Public Summary

The contradiction source-page endpoint returns bounded pages only after the
workspace resolver has read, decoded or extracted, hashed, and cached the entire
source. No pre-read size bound protects the desktop sidecar from attacker-sized
candidate evidence.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Added a 32 MiB pre-read and post-read resolver bound so paging cannot first materialize an attacker-sized source.

Changed files:

- `packages/workspace/server/src/SourceText/WorkspaceSourceTextResolver.ts`
- `packages/workspace/server/test/WorkspaceSourceTextResolver.test.ts`
