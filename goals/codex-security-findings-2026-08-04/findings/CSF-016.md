# CSF-016: Unvalidated language tags allow Turtle triple injection

- Severity: Low
- Codex ID: `0913c3d234e481918df4ee2751dcc549`

## Public Summary

Typed literal language tags accept arbitrary strings and are appended directly
to Turtle syntax. A crafted tag can terminate the literal and inject additional
triples despite value escaping.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Validated typed-literal language tags with the canonical RDF LanguageTag schema before Turtle projection.
