# CSF-021: CodeMode sparse arrays can bypass execution bounds

- Severity: Informational
- Codex ID: `90b96433d96c81918c7e867e6e9d78c7`
- Source commit: `f9b8aaac15e5c02bf609b278936d44594ff024e3`
- Owner: scratchpad CodeMode result normalization
- Status: remediated; local Yeet proof green

## Public Summary

Guest code can return a huge sparse array. Result normalization densifies or
iterates its declared length before applying output bytes or timeout bounds,
allowing synchronous memory or CPU exhaustion.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Rejected result arrays above 100,000 elements before sparse-array densification.
