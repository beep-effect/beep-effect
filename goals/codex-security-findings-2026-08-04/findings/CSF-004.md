# CSF-004: Agent prompts and session keys exposed via process argv

- Severity: Medium
- Codex ID: `831a0b829e3081919caf4168528af1a9`
- Source commit: `3dbf2d277b2c2a7b82f7c901cb95e5826af67af5`
- Owner: OpenClaw CLI process boundary
- Status: remediated; local Yeet proof green

## Public Summary

The OpenClaw agent-turn wrapper places both the prompt and session key in child
process arguments, exposing them through process-list surfaces while the command
runs. Sensitive turn input needs a private channel or an explicitly safe CLI
contract.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Moved agent prompts to stdin via --message-file - and removed explicit session keys from process argv.

- `packages/drivers/openclaw/src/Openclaw.models.ts`
