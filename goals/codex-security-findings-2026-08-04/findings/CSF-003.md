## Public Summary

Hosted OpenAI-compatible provider URLs accept plaintext HTTP even though the
rendered provider carries a secret-backed API key and confidential agent turns.
The hosted-provider boundary must fail closed to HTTPS.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Required HTTPS for hosted and secret-backed OpenClaw providers while retaining loopback placeholder support.
