# CSF-023: Script text can spoof the new test-typecheck lint

- Severity: Informational
- Codex ID: `6ffbd2b6fd208191bd3140d99ffee6b8`

- Status: remediated; local Yeet proof green

## Public Summary

The test-typecheck lint recognizes `tsgo` or `tsc` by regex over raw shell text.
Non-executing text such as an `echo` can therefore satisfy the coverage ratchet
without running a compiler.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Anchored TypeScript compiler recognition to executable position so echoed compiler names cannot satisfy the lint.

- `packages/tooling/tool/cli/src/commands/Lint/PackageTestTypecheck.ts`
- `packages/tooling/tool/cli/test/lint-command.test.ts`
