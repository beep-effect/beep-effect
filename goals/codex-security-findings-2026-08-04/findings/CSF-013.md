# CSF-013: PGlite extension loaded from poisonable temp path

- Severity: Medium
- Codex ID: `053d6b3fc3648191adb2270241662919`
- Source commit: `d117ecf26d9aca68f5e9e32536b852df64e940cf`
- Owner: professional desktop PGlite extension materialization
- Status: remediated; local Yeet proof green

## Public Summary

The desktop runtime materializes a loadable PGlite extension under a predictable
shared temporary path. Another local process can pre-create or replace that path
before the database loads it.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Materialized the PGlite extension in an unpredictable private temp directory with exclusive mode-0600 creation.

Changed files:

- `apps/professional-desktop/src/runtime/Pglite.ts`
