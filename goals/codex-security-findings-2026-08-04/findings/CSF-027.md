# CSF-027: Unescaped PR comments printed to terminal

- Severity: Informational
- Codex ID: `cbe85d133e408191bc0ca9e0643905d9`
- Source commit: `aee2664b91d163cd7481eb16b0c5a485c092f5c2`
- Owner: repo-cli Yeet monitor
- Status: remediated; targeted proof green

## Public Summary

Yeet monitor rendered GitHub-controlled comment fields directly into the
operator terminal. A malicious comment could include terminal control sequences
that spoof output, create deceptive hyperlinks, or manipulate the clipboard.

## Current-HEAD Validation

Confirmed reachable at the synchronized branch head: review and conversation
comment authors, bodies, paths, and URLs reached `Console.log` without a
terminal-safe rendering boundary.

## Remediation

Strip ANSI CSI, OSC, other escape sequences, and remaining C0/C1 controls from
each untrusted field before interpolation. Sanitization is field-scoped so the
renderer's intentional line structure remains intact.

Changed files:

- `packages/tooling/tool/cli/src/commands/Yeet/internal/MonitorComments.ts`
- `packages/tooling/tool/cli/test/yeet.test.ts`
