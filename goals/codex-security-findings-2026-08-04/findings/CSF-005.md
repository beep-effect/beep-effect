# CSF-005: Claims batch follows symlinks and can leak local files

- Severity: Medium
- Codex ID: `f72e298b753081919b7a2760ed5754f9`
- Source commit: `bc322e025719899d1e63d1893586dffc21b58929`
- Owner: practice KG claims batch
- Status: remediated; local Yeet proof green

## Public Summary

The claims batch reads docket-prefixed directory entries without rejecting
symlinks, proving real containment, restricting extensions, or bounding bytes,
then can submit the content to remote extraction.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Restricted claims inputs to bounded regular UTF-8 files inside the canonical input root and rejected symlinks.

Changed files:

- `packages/law-practice/server/src/PracticeKg.claims.ts`
- `packages/law-practice/server/test/PracticeKg.projections.test.ts`
