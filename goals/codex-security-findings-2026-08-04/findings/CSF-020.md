# CSF-020: Execution grants ignore principal during authorization

- Severity: Low
- Codex ID: `65d01b70a1cc81919b4f00cc7d744755`
- Source commit: `8c022633c942c29f4c8740d1285e6f2ed956a69c`
- Owner: epistemic execution authority evaluator
- Status: remediated; local Yeet proof green

## Public Summary

Execution grants are principal-scoped, but requests and evaluator narrowing omit
the requesting principal. A mixed-principal grant set can therefore authorize a
caller using another principal's matching grant.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Added Principal to execution requests and narrowed grants by principal before every other authorization axis.
