- Severity: Medium
- Codex ID: `0baee9d15f7c8191b3057ebfb17a436f`

## Public Summary

The files pipeline hashes prepared bytes but discards them before dispatch.
Real engines reread the locator later, allowing an input path to change between
the recorded digest and extraction or remote submission.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Retained the exact hashed source bytes through dispatch; Tika App and libpff now process private byte snapshots instead of reopening locators.
