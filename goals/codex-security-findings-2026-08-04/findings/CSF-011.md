# CSF-011: MCP mutation tools are auto-approved when registered

- Severity: Medium
- Codex ID: `1763c86c9618819197a6903bb278f397`
- Source commit: `d2c2bc29ca4fbfd898c6a2e6c18a31e0952751d5`
- Owner: professional desktop ontology MCP approval policy
- Status: remediated; local Yeet proof green

## Public Summary

An omitted mutation-tool approval option is interpreted as approval for every
registered mutation, and the production sidecar relies on that default. Missing
approval policy must fail closed.

## Current-HEAD Validation

Confirmed reachable at the current branch head before remediation; the exact affected surface and source commit are recorded above.

## Remediation

Changed mutation-tool approval to fail closed by default; tools must now be explicitly approved.

Changed files:

- `apps/professional-desktop/server/OntologyMcpTransport.ts`
