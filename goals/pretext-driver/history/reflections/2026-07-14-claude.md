# Reflection — pretext-driver (2026-07-14, claude)

## Summary

Shipped `@beep/pretext` exactly as specced: pure root (versioned
FontMetricsSnapshotV1 contracts, typed codecs, greedy layout helpers),
`/browser` capture with typed capability failures, fixture-backed test
layers, centralized errors — zero product surface. PR #391 merged
2026-07-14 (squash `1c0977ccad`) after a full quality-review-fix-loop
(crispen baseline `f9598694f8`, −35 lines; panel fixes `35b9710c95`).
Verdict: the packet shape and sequencing were right; the only real pain was
operator tooling at the publish boundary, not the build.

## Tooling experience

- **Worked:** `bun run beep architecture` scaffolding; the 10-role
  quality-review panel (2 true blockers, ~14 adopted improvements, round-2
  clean); `.repos/effect-v4` as ground truth (refuted one plausible-but-wrong
  finding before it became code); `provideScopedLayer` from
  `@beep/test-utils` replacing a local copy; scratchpad full-circle proof
  re-run against the shipped surface (17/17).
- **Didn't:** yeet `--start-pr-early` (circular `--monitor` requires-PR
  validation) — manual push + `gh pr create` fallback.
- **Frustrating:** the post-push CI wall was 100% foreign to this packet:
  every hosted job died at `bun install --frozen-lockfile` because another
  lane's lockfile entry was staged but uncommitted. Diagnosis cost a full
  log-pull cycle; the fix belonged to the other lane.
- **Wished existed:** a local "would hosted setup pass?" probe — frozen-lock
  install against clean HEAD — runnable before any push of a rebased branch.

## Implementation improvement opportunities

- Live-capture happy path needs a CI lane with canvas (today: `skipIf`).
- Error family: message-only capture drops upstream causes; fold into the
  repo-wide CauseTaggedError sweep rather than diverging solo.
- Observability backlog recorded in the loop: span attributes on capture
  (word count, font), input text in measurement error messages.
- Encode-failure branch of the codec statics has no test (decode side does).

## Goal & prompt critique

GOAL.md was execution-grade: the six First Moves were the actual execution
order, and the guardrails (v4 verification, `npx vitest run` law, no product

`getEngineProfile` is unexported upstream, so the driver mirrors its fences

## Lessons (confidence-tiered)

- **HIGH — Critical:** Local gate results on a dirty tree prove nothing
  about HEAD — hosted CI installs from the committed tree only. Any push of
  a branch carrying rebased foreign-lane work needs a clean-HEAD
  frozen-lockfile check first.
- **HIGH — Critical:** Empirically probe framework behavior before writing
  the "fix" a reviewer suggests — the EB-2 path-plumbing finding was
  refuted by a 5-line decode probe against the real v4 formatter.
- **MEDIUM — Best practice:** When wrapping an upstream that hides an
  internal you must mirror (engine-profile fences), pin the mirrored values
  in a test AND record a catalog-bump revisit trigger in the owning
  DECISIONS log — the pair converts silent drift into a loud failure.
- **LOW — Consideration:** Fixture-corpus limits are a doctrine, not a bug:
  DOM-free consumers can only measure fixture words, so consumer tests
  should compose titles/text from the fixture sentence by convention.
