# P2 spike verdict — oxlint-tsgolint behind hard gates

Date: 2026-08-13  
Branch: `feat/lint-policy-oxlint-spike`  
Verdict: **NO-GO — do not cut over. Keep the ESLint shard architecture.**

The candidate engages and is fast enough on this workstation, and the focused parity corpus has
an empty normalized identity diff. The locked coverage gate fails: 25 in-scope TS/TSX files receive
no tsgolint program, including every one of the 23 pre-existing files currently matched by the
ESLint profile's `allowDefaultProject` globs. Full-repo parity also has 13 substantive Oxlint-only
findings on existing source. Per `engine-swap-behind-hard-gates` and the packet stop condition, P3
must not cut over on this evidence.

No `.github/` file was created or changed. The one-week main-push shadow remains future work only if
the coverage and semantic-parity failures are first repaired; it cannot make the present candidate
eligible for cutover.

## Gate 1 — typed-rule engagement: PASS

The first command intentionally tested the existing root config and failed to engage:

```sh
./node_modules/.bin/oxlint --type-aware -A all \
  -D typescript/no-deprecated \
  apps/architecture-lab-proof/src/__p2_oxlint_deprecated_canary__.ts
```

Observed: exit 0, no diagnostic. `--print-config` showed `rules: {}`. The existing
`.oxlintrc.json` therefore defeats the CLI-only `-D` experiment; the 0.55-second smoke result was
not evidence that the typed rule had run.

With the isolated dedicated profile, the required typed invocation reports the seeded use:

```sh
./node_modules/.bin/oxlint \
  -c .oxlintrc.deprecated-apis.jsonc \
  --disable-nested-config \
  --type-aware \
  -D typescript/no-deprecated \
  apps/architecture-lab-proof/src/__p2_oxlint_deprecated_canary__.ts
```

Observed: exit 1 and exactly:

```text
apps/architecture-lab-proof/src/__p2_oxlint_deprecated_canary__.ts:4:33: error typescript(no-deprecated): `deprecatedCanary` is deprecated.
```

Direct unsupported-CLI diagnosis also confirmed that tsgolint itself sees the canary in
`apps/architecture-lab-proof/tsconfig.json` and emits `no-deprecated`. Engagement is proven only
with the dedicated profile.
