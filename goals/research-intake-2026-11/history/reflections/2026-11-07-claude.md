# Reflection — research-intake-2026-11 (2026-11-07, claude)

## Summary

The third intake ran end to end. That included the November corpus at hops 0,
1 and gated 2, and the Box legal-ontology pile as its own T1-only intake. Mining
produced 12,330 span-checked CiTO findings routed to 90 live packets, with 22
amendments, three deep-research runs and an `/adhd` portfolio. Most of the
effort went into making the library survive real scale and real model pools,
not into the mining itself.

## Tooling experience

- **Worked:** the `mine` runners with output schemas and per-artifact records
  (every interruption resumed cleanly); reflink backups on btrfs (a 57 GB
  library copied in seconds and made the restore safe); `yeet merge-gate
  --relaxed` plus the goals-only re-final recipe for the routes closeout.
- **Didn't:** background `op run`/bun launches from the agent shell (SIGINT at
  random points until `setsid -w`); `status` over a 78k-source catalog (SPARQL
  view dataset, 50+ minutes and 13 GB); the completion verifier with an S11
  final.
- **Frustrating:** every pool ran dry in one day; earlyoom killing test workers
  on a host loaded by other sessions; zsh not word-splitting `$files`.
- **Wished existed:** a `verify --intake` scope; a cheap catalog write path
  (journal) for bulk imports; a Hugging Face resolution proof.

## Implementation improvement opportunities

- Fold per-capture receipts into a journal and write the catalog in batches;
  two full catalog writes per source is the remaining cost of acquisition.
- Give the SPARQL views an incremental store so `status` and `verify` do not
  rebuild a dataset of millions of quads per run.

## Goal & prompt critique

- State the prerequisite as a gate the launcher checks: "Stop and report if
  `goals/research-library-routes` is not completed-retained on origin/main".
- Replace "T2 on Junie while credits remain, then Opus children" with a
  per-tier fallback table that includes the proxy routes, since quota, not
  model choice, decided the pools.
- Give hop 2 an explicit global budget alongside the per-domain cap.

## TODOs worth codifying

- Real-size fixture tests for every catalog-wide library command.
- One qualifying live job per runner profile, recorded like adapter qualifications.

## Lessons (confidence-tiered)

- **HIGH — Critical:** take a reflink backup of an operator library before the
  first write of any run — it turned an accounting-corrupting defect into a
  clean restore.
- **HIGH — Critical:** scope derived writes to the run's own intake — whole-catalog
  recomputation silently edits history.
- **MEDIUM — Best practice:** run a single live job per new pool or profile
  before a batch — fakes do not exercise provider schemas, quotas or logs.
- **LOW — Consideration:** an LLM triage pass is far more permissive on cheap
  models (Luna selected 83% at hop 1; Opus selected 16% at hop 2); calibrate T1
  per model before trusting the select rate as a budget.
