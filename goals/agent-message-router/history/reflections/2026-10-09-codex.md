## Tooling experience

- **Worked:** Schema-first contracts, real SQLite transactions and scoped MCP
  handlers made ownership, quota and receipt behavior observable. Focused crash,
  concurrency and filesystem fixtures exercised actual failure boundaries.
- **Didn't:** Synthetic peers could not expose every installed CLI behavior.
  Earlier native attempts retained transport, permission and storage failures;
  the passing [managed receipt](../../../agent-session-bridges/research/GROK-MANAGED-ROUNDTRIP.json) is a later independent run.
- **Frustrating:** In-flight source/test changes produced stale loaded-code reds.
  Digest checks and a frozen rerun prevented their promotion into final proof.
- **Wished existed:** A supported per-provider effective permission readback for
  all managed routes; launch-enforced evidence is currently distinct from the
  runtime-reported Codex policy.

## Implementation improvement opportunities

- Validate contradictory host/provider metadata at enrollment before reserving messages. See [R1](../../research/FOLLOW-UPS.md) for current scope and evidence.
- Preserve ACK and an unknown native-completion hold as separate receipt facts.
  An acknowledged message can still require original-attempt reconciliation;
  replay must not clear the hold or duplicate model effects.
- Keep native input/frame queues bounded and every enrollment/control call under
  a typed deadline, with cleanup owned by the session scope.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Distinguish durable acceptance, participant ACK and known
  native completion. The repaired store cases demonstrate that each state can
  survive independently and that uncertainty must hold unsafe retry.
- **HIGH — Critical:** Qualify the actual MCP child sandbox before live inference.
  Outer filesystem access alone did not prove Grok's inner child could write the
  owned database directory.
- **MEDIUM — Best practice:** Freeze sources and verify digests around each live
  proof so receipts bind to the implementation and executable that actually ran.
- **LOW — Consideration:** Automate more per-provider permission inventory checks
  if installed runtimes expose a stable readback contract; do not infer it from
  a successful end_turn or handshake model field.
