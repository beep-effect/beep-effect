# Reflection — goal-closeout-hosted-verification (2026-11-13, claude)

## Summary

The packet replaced pre-merge, clone-local completion evidence with hosted facts
read after the merge, and collapsed goal closeout from two PRs to one. PR B
(#3245) merged; PR A (#3248) carries the schema, services, migration of twelve
packets and the launcher rewrite. Eleven of the twelve migrated finals verify;
literal-kit-subset-algebra #2080 does not and needs an operator ruling.

## Tooling experience

- **Worked:** The grill (ten questions, one at a time) produced rulings precise
  enough to record as decision files before any design. `goals decisions add`
  kept every agent call reversible. `yeet final-check --skip coverage=<reason>`
  gave PR B a receipt in about ten minutes. The orchestrator session merged
  #3245 on a `final <sha> #n` comment without operator relay.
- **Didn't:** The first design workflow lost five of seven agents to the weekly
  usage limit and had to be resumed. A session restart killed a running
  final-check and a subagent mid-task; both resumed, but only because their
  state was on disk.
- **Frustrating:** main moved three times while PR A was open, and each merge
  surfaced a new packet to rewrite or migrate. `yeet open` refused a stale base
  for a single generated catalog file.
- **Wished existed:** a `goals` subcommand that rewrites the generated parts of
  every live launcher, and an online doctor mode that budgets its own GitHub
  calls.

## Implementation improvement opportunities

- The completion port maps a 404 and a network failure on a fix PR to the same
  error, so a missing fix PR reads as transient instead of leaving its red
  unattributed.
- `yeet sweep --retire` keeps exit status 0 after a blocking closeout check
  (DN-14). The P0 inbox row is the only signal; exit 1 is the recorded reversal.
- The refresh hint suggests `goals decisions add` for an archived tombstone,
  which DN-23 forbids.

## Goal & prompt critique

- Ruling 6 and ruling 7 interact: one-PR closeout makes manifest equality true
  at merge. The ruling text should have named verification as part of done.
- "Rewrite every active packet's GOAL.md" should have said what happens to
  packets main closes while the PR is open. DN-21 settled it (closed packets
  keep main's bytes), but only after a reviewer found 25 files rewritten in
  packets main had closed.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Read a workflow's per-agent journal before trusting an
  empty review — two empty reviewer results looked identical to a clean review.
- **MEDIUM — Best practice:** For a PR that edits many packets, re-run the
  packet census after every merge of main — three merges each added work.
- **LOW — Consideration:** Publish the small supporting PR first — #3245 merged
  in under an hour and removed the 20-minute coverage shard from PR A's own
  goals-heavy final-check plan.
