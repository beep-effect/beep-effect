Read README.md, SPEC.md, PLAN.md, ops/manifest.json, ops/EVIDENCE.md and
research/SOURCES.md in this packet, then repo instructions, architecture and
the retained baseline report packet. SPEC.md is normative.

Use merged PR #2322, commit 732e11fd6dc417e5954b22fbbd856a026299ea50,
as the mechanism baseline. Reverify current source and record any drift.

Deliver a reproducible offline calibration workflow and evidence bundle for
all five RetentionPolicy fields. Freeze dataset provenance, product-access
authorization, temporal/tenant splits, independent evaluation labels or
workload objectives, candidate search, metrics, uncertainty and acceptance
criteria before selecting values. Synthetic data proves the harness only.
Do not import donor constants or invent salience or access history.

Evaluate candidates against a no-policy baseline and held-out data, quantify
errors and canonical payload-byte pressure, justify each parameter and preserve
all failed/negative outcomes. Prove replay, full projection delete/rebuild,
as-of/disposition correctness and unchanged authority. Validate every field and
digest against the shipped policy and receipt contracts.

Deliver an approval-ready recommendation, or an explicit insufficient-evidence
result. Neither result is production activation. Keep the report CLI's inert
registry and every production composition unchanged. Do not create a trusted
production receipt, register production membership, deploy, enable a policy,
or treat a candidate JSON/evaluation result as approval. Activation requires
accepted calibration evidence AND separate explicit authenticated human
approval for the exact policy, dataset, organization, mechanism, deployment,
validity, revocation and rollback plan; execute only in a separately authorized
follow-on. A general launch or permission to merge is not activation approval.

Use schema-first native contracts and reuse the existing report seam. No
authority mutations, production/private data reads without scoped permission,
external authority, operator-memory coupling, RRF integration, donor code or
new paid resources. If evidence/access is missing, record the precise hold;
never manufacture production eligibility from fixture results.

Run scoped package verification for changed code and packet checks. Publish the
calibration delivery through Yeet; keep lifecycle operative until exact-head
hosted readiness, reviews, merge, completion receipt and lane retirement are
verified. Retain a reflection and synchronized packet evidence. Finish the
calibration goal without requiring production activation or approval to exist.
