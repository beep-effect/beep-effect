# Reflection — oip-web-launch (2026-07-14, codex)

## Summary

The retained deliverable is the repo-native OIP marketing site, typed content,
assets, SEO posture, package proof, and desktop/mobile browser smoke. Closeout
showed that initial build/test failures belonged to the restricted sandbox and
that a nonexistent type-test script belonged to the plan, not the app.

## Tooling experience

- **Worked:** A normal-session rerun passed the full Next build and 48 of 48
  tests; accessibility-tree smoke plus console inspection covered both viewports.
- **Didn't:** The restricted environment could not create Turbopack loader or
  Vitest fork processes, so its failures were not valid code verdicts.
- **Frustrating:** The plan's undefined `type-test` command produced an instant
  red lane that could never pass without changing the proof contract.
- **Wished existed:** Proof tooling that labels sandbox capability failures and
  validates named package scripts before execution.

## Implementation improvement opportunities

- Keep all defined package lanes green and preserve browser smoke against the
  production build.
- Do not submit the live contact form during smoke without explicit permission.

## Goal & prompt critique

The goal should derive proof commands from `package.json` and state that
restricted-sandbox process failures require an external rerun. It should also
say plainly that merge-ready implementation does not approve public launch.

## TODOs worth codifying

- Validate packet proof command names against package scripts.
- Retain client-logo, named-matter, credential, contact, and legal-notice gates
  as user-owned launch prerequisites.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Classify environment failures before editing code — the
  same build and tests passed outside the restricted sandbox.
- **MEDIUM — Best practice:** Verify the real package script surface — an
  undefined lane is a plan defect, not an implementation failure.
- **LOW — Consideration:** Accessibility snapshots can close functional smoke —
  pixel capture timed out on video while rendering and consoles stayed healthy.
