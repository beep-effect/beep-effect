# Reflection — skill-effect-probe (2026-11-13, claude)

## Summary

The probe built `beep agent-effectiveness evals probe stage|preflight|score|select|report`.
It proved that `claude plugin eval` ties each kept run directory to its case,
cell and run through `tracePath`. It returned **Insensitive**: on a laws-prompt
pilot of 48 B and C runs, no task ever passed all lanes or the law lanes, so
the archived corpus cannot measure the `schema-first-development` skill at
Opus 5.5 without tools. The skill's fired rate of 0.71 fired the activation
gate, and the source exploration reopened at `decompose`.

## Tooling experience

- **Worked:** the retained law scorer scored kept directories unchanged. Its
  sandbox made a probe-only scorer profile cheap to add. `claude plugin eval`
  isolation was clean: both arms listed identical built-in skills, and the
  `with` arm added only the plugin skill. `goals decisions add`, `explore
  atlas --write` and the harness-ledger CLI kept every packet surface
  generated.
- **Didn't:** the case format is undocumented locally. `scaffold_script`
  is a file path under `context:`, not inline bash, and was found by reading
  the binary. The plan limit cascaded through a whole invocation.
- **Frustrating:** the shell's working directory drifted between commands
  (`Script not found "beep"`), and hook-modified files needed re-reads before
  edits.
- **Wished existed:** a harness flag to stop at the first plan-limit
  rejection, and a scorer-side way to declare profile repairs instead of
  filtering findings after the shared scorer runs.

## Implementation improvement opportunities

- Fold `SkillProbeRunRecord` and `AgentConventionTrial` into one shape if a
  later comparison needs both. They were kept apart deliberately; see the
  decision of 2026-11-13.
- Let `probe score` drive reruns end to end (stage only the excluded slots
  and invoke the harness), rather than relying on `--prior` after a
  hand-run invocation.

## Goal & prompt critique

- Add to the GOAL's P0: "check that each task's completion contract is
  reachable from that cell's prompt and tools" next to the
  run-to-directory check. That one line would have produced the Insensitive
  verdict in P0 and saved about 250 runs of plan quota.
- The SPEC treated "fixtures drifted" as a scorer-environment risk. The
  larger risk was contract drift against the live skill. Name it in the
  Rabbit Holes.

## TODOs worth codifying

- Corpus reachability check for any future eval corpus.
- Known-good rescoring whenever the law set changes.
- Abort-on-plan-limit and active-account reporting.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Pilot the cells your gate reads before freezing a
  primary. The cell A pilot measured the prompt, not the skill.
- **HIGH — Critical:** Exclusions must read structured fields. A regex over
  serialized metadata silently turns failures into counted zeros or the
  reverse.
- **MEDIUM — Best practice:** Keep C minus B unseen until the rule is final.
  Voiding the two runs that completed in the rate-limited attempt kept the
  amendments clean.
- **LOW — Consideration:** A probe that grants Bash and a type checker
  measures a different treatment; it needs its own rule, not a rerun.
