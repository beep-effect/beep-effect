# Reflection — uspto-mcp (2026-07-11, claude)

## Summary

Retroactive closeout. The goal itself succeeded: `packages/drivers/uspto-mcp`
shipped a thin USPTO MCP host proving `@beep/mcp-kit`'s credential-keyed
composition, `api_key_required` envelope, and field-tier projection, with
three fixture tests and full check/test/lint green since 2026-07-01
(`e9cce72e6f`, merged via `8dbd778313`). The only failure was paperwork: the
packet stayed formally "active" with P3/P4 pending for ten days after the
work merged.

## Tooling experience

- **Worked:** The packet structure itself — SPEC/PLAN/manifest made the
  retroactive reconciliation easy because P0–P2 evidence was already recorded
  precisely (commands, test names, deviations noted in PLAN.md).
- **Didn't:** Nothing enforced the manifest flip at merge time. The
  completionGate is declarative prose plus JSON; no tool reads it back
  against git state.
- **Wished existed:** A `goals doctor` command that flags active packets
  whose deliverable paths already exist on main.

## Implementation improvement opportunities

- None outstanding for the code: the host is read-only by design, and the
  tier-gate write-path proof is explicitly deferred to the `mcp-write-wall`
  follow-on (recorded in the exploration's MAP.md), so the deferral is
  tracked, not lost.

## Goal & prompt critique

- The PLAN's closeout checklist was correct but toothless — it should say
  "flip statuses in the merge commit", not "before marking the packet
  closed", which invites deferral.
- The completionGate's `requiresPullRequest: true` became unsatisfiable in
  its literal form once the branch was direct-merged pre-ruleset; gates need
  an escape hatch for recording "satisfied by other means" with evidence.

## TODOs worth codifying

- Goals doctor/index command (see frontmatter todos).
- Status-flip-rides-the-merge convention.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Close the paperwork in the same commit that ships the
  code — checklists that run "later" run never; this packet drifted ten days
  despite an explicit closeout checklist.
- **MEDIUM — Best practice:** Shared branches need per-packet commit
  attribution so each packet can be closed independently when the branch
  merges.
