# CSF-004: PR code now runs on owned EC2 CI runners

- Severity: High
- Codex ID: `a3a281b2a3d881919fdcbf68ee2364f0`
- Source commit: `69045830e2c3acca1ec771e23a5e4be3a9fc0e3c`
- Owner: CI runner admission architecture
- Status: confirmed; remediate; architecture/deployment-blocked

## Public Summary

Pull-request code still executes on organization-owned EC2 runners in the Check, Integration, Coverage, and Docgen lanes. Those jobs cross the trust boundary before approval and can affect persistent runner state or any identity reachable from the host.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

The workflow remains triggered by pull requests and assigns these four lanes to the self-hosted `beep-ec2-heavy` label. The jobs check out the proposed code, use a repository-controlled setup action, and invoke repository scripts, so the reported execution path is present at current HEAD.

Evidence:

- `.github/workflows/check.yml:3` registers the pull-request trigger.
- `.github/workflows/check.yml:76`, `.github/workflows/check.yml:88`, `.github/workflows/check.yml:100`, and `.github/workflows/check.yml:106` place Check, Integration, Coverage, and Docgen work on the self-hosted label.
- `.github/workflows/check.yml:223` checks out the proposed tree, `.github/workflows/check.yml:227` runs its setup action, and `.github/workflows/check.yml:236` begins repository-controlled task execution.

## Remediation

Pull-request jobs must move to a non-privileged execution class or be admitted
by a control outside repository-editable YAML. The finding remains
dispositioned `remediate` and is handed to the runner-admission/workload-
identity arc for external GitHub organization runner-group and AWS deployment
proof. This PR does not claim that proof.

## Verification

- Against the deployed GitHub organization and AWS fleet, prove that a hostile
  pull request cannot acquire an owned production runner even after changing
  repository workflow content.
- The receiving arc must record exact-ID dashboard closure after the deployed
  evidence passes.
