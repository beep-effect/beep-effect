# CSF-018: setup\-agent\-memory requires GNU realpath

- Severity: Informational
- Codex ID: `72cb800162448191b684be534a4358e6`
- Source commit: `9df5225874a02ca04db654a8c45282e45b76c0af`
- Owner: agent-memory bootstrap portability
- Status: confirmed; remediate; repo-side remediated

## Public Summary

The agent-memory bootstrap requires GNU `realpath -m` while claiming support for macOS. The system `realpath` shipped on macOS does not provide that option, so first-run setup exits before it can create the shared memory links and CodeGraph index.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

The script enables immediate exit on command failure and unconditionally passes the GNU-specific `-m` option while canonicalizing a possibly missing target. No portable fallback is present, making the documented fresh-machine path fail on the supported platform.

Evidence:

- `scripts/setup-agent-memory.sh:13` enables `set -euo pipefail`.
- `scripts/setup-agent-memory.sh:71` starts the target-resolution helper.
- `scripts/setup-agent-memory.sh:75` invokes `realpath -m` unconditionally.

## Remediation

The setup script now resolves the longest existing directory prefix with
`cd -P` and `pwd -P`, then normalizes missing suffix components in shell. A
relative or absolute `BEEP_EFFECT_CHECKOUT` may therefore end in missing
components without requiring GNU `realpath -m`.

- `packages/tooling/tool/cli/test/setup-agent-memory.test.ts`
