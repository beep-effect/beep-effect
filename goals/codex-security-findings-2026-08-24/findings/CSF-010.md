# CSF-010: Depth\-blind data archival segment bypasses refs gate

- Severity: Low
- Codex ID: `2f05c1b1d1e4819182ffc5b0de75004b`
- Source commit: `2aecd8fd2184b0e3b9408c8eb7002138632ff28e`
- Owner: knowledge-reference policy
- Status: confirmed; remediate; repo-side remediated

## Public Summary

The knowledge-reference scanner treats any path containing a segment named `data` as archival. A live agent-facing file can therefore move beneath an otherwise ordinary `data/` directory and bypass the provenance controls applied to live knowledge references.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

The scanner includes live roots such as `.claude`, `docs`, and `goals`, but its archival classifier checks for a configured segment at any depth rather than an approved archival root or context. Files such as `.claude/skills/data/SKILL.md` are consequently classified as archival and skip the live-reference gate.

Evidence:

- `packages/tooling/tool/cli/src/commands/Knowledge/Knowledge.refs.ts:1157` defines the scanned knowledge roots.
- `packages/tooling/tool/cli/src/commands/Knowledge/Knowledge.refs.ts:1173` includes the generic `data` segment in the archival set.
- `packages/tooling/tool/cli/src/commands/Knowledge/Knowledge.refs.ts:1247` classifies a path as archival when any segment matches.
- `packages/tooling/tool/cli/src/commands/Knowledge/Knowledge.refs.ts:1864` assigns archival provenance, and `packages/tooling/tool/cli/src/commands/Knowledge/Knowledge.refs.ts:1977` applies the stricter policy only to live references.

## Remediation

The archival classifier no longer treats every `data` segment as captured
evidence. Only `goals/<packet>/data/` receives packet-archive treatment; nested
`data/` paths under live knowledge roots remain subject to the live-reference
gate.

Changed files:

- `packages/tooling/tool/cli/src/commands/Knowledge/Knowledge.refs.ts`
- `packages/tooling/tool/cli/test/knowledge-refs.test.ts`
