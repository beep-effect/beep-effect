# CSF-016: Overbroad deletion changeset exemption hides residue

- Severity: Informational
- Codex ID: `141acacb3b1081919daab52ebdfc3e75`
- Source commit: `e6fbad9abe92fc5615edfe048b96e53dd144fb40`
- Owner: delete-package safety
- Status: confirmed; remediate; repo-side remediated

## Public Summary

The delete-package check exempts a changeset solely because its filename matches the command's canonical deletion-note name. It never verifies the file's contents, so arbitrary or stale release changes can be hidden under that name and evade the safety check.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

Registration geometry filters out the canonical basename before reading or parsing changeset contents. Although the apply path writes a canonical deletion note, the preflight probe cannot distinguish that note from a manually crafted changeset with the same filename.

Evidence:

- `packages/tooling/tool/cli/src/internal/cli/RegistrationGeometry/RegistrationGeometry.probes.ts` scans changeset files and previously skipped the canonical basename without inspecting its body.
- `packages/tooling/tool/cli/src/commands/DeletePackage/DeletePackage.command.ts:334` defines the canonical note written by the apply path, which provides the exact content the probe could validate.

## Remediation

A shared deletion-changeset helper now renders the canonical note and validates
candidate files through parsed frontmatter plus exact byte-for-byte body
matching for the selected package. Registration geometry exempts the canonical
basename only when that complete validation succeeds.

Changed files:

- `packages/tooling/tool/cli/src/commands/DeletePackage/DeletePackage.command.ts`
- `packages/tooling/tool/cli/src/commands/DeletePackage/internal/DeletionChangeset.ts`
- `packages/tooling/tool/cli/src/internal/cli/RegistrationGeometry/RegistrationGeometry.probes.ts`
- `packages/tooling/tool/cli/test/delete-package.test.ts`

## Verification

- `packages/tooling/tool/cli/test/delete-package.test.ts` is part of the focused
  DeletePackage run: 2 files, 51/51 tests passed under Bun.
- Command: `zsh -ic 'bun test packages/tooling/tool/cli/test/delete-package-labs.test.ts packages/tooling/tool/cli/test/delete-package.test.ts'`.
- The suite rejects tampered frontmatter, a tampered body, and a deletion note
  for another package. It exercises geometry directly and does not perform a
  real recursive deletion.
