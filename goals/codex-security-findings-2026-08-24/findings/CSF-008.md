# CSF-008: Turbo op\-run wrapper exposes all local secrets to tasks

- Severity: Medium
- Codex ID: `bb86533fe99c819182a6edf7e72fe1b8`
- Source commit: `cf772b58cd890fef395be725b640ccef0647ac80`
- Owner: quality-command secret minimization
- Status: confirmed; remediate; repo-side remediated

## Public Summary

When remote cache credentials are needed, the quality runner wraps every otherwise environment-free Turbo step with `op run --env-file=.env`. That exposes every secret reference in the project environment file to all Turbo subprocesses instead of injecting only the cache credentials they need.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

The remote-secret session marks all environment-free Turbo steps for local-environment wrapping. The wrapper loads the complete `.env` file, and spawned task processes inherit the resulting environment. The current implementation intentionally does not scrub unrelated injected variables before starting the child.

Evidence:

- `packages/tooling/tool/cli/src/commands/Quality/Tasks.ts:701` establishes the remote-secret session and `packages/tooling/tool/cli/src/commands/Quality/Tasks.ts:1481` applies it to Turbo steps.
- `packages/tooling/tool/cli/src/commands/Quality/Tasks.ts:972` builds an `op run --env-file=.env` invocation.
- `packages/tooling/tool/cli/src/commands/Quality/Tasks.ts:993` and `packages/tooling/tool/cli/src/commands/Quality/Tasks.ts:1060` spawn children from the inherited process environment.
- `packages/tooling/tool/cli/src/internal/cli/EnvConfig.ts:496` likewise defines whole-file environment injection, while `packages/tooling/tool/cli/src/internal/cli/EnvConfig.ts:300` preserves ambient injected values for wrapped commands.

## Remediation

Remote-cache resolution no longer loads the project `.env`. The quality runner
passes `op run` an explicit, non-extending child environment in which only
`TURBO_API`, `TURBO_TOKEN`, and `TURBO_TEAM` may retain secret references.
Unrelated references cannot re-enter through ambient inheritance, and the root
build uses the same conditional cache-session planner as other Turbo steps.

Changed files:

- `packages/tooling/tool/cli/src/commands/Quality/Tasks.ts`
- `packages/tooling/tool/cli/src/internal/cli/EnvConfig.ts`
- `packages/tooling/tool/cli/src/internal/cli/TurboCache.ts`
- `packages/tooling/tool/cli/test/quality-tasks.test.ts`
- `packages/tooling/tool/cli/test/shared-internals.test.ts`
- `packages/tooling/tool/cli/test/turbo-cache.test.ts`
