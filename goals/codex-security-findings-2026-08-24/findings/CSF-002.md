# CSF-002: Anonymous conflict\-resolution endpoint by default

- Severity: High
- Codex ID: `1d2e8bb3c81c81919cd12685143ff8a6`
- Source commit: `ff2184e6b3c5cef6d00fe196b5e5ea8be95ed408`
- Owner: effect-ontology HTTP authorization
- Status: confirmed; remediate; repo-side remediated

## Public Summary

The effect-ontology HTTP server still defaults authentication off and supplies a system conflict actor to unauthenticated requests. An anonymous caller can discover conflict identifiers and invoke the conflict-resolution mutation with system authority.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

Authentication remains disabled by default, and the no-auth middleware path installs `SystemConflictActor` instead of denying mutation access. The router exposes both conflict listing and conflict transition endpoints, so the required conflict identifier is also available through the same anonymous surface.

Evidence:

- `scratchpad/effect-ontology/Service/Config.ts:281` defines the API authentication setting with a default of `false`, and `scratchpad/effect-ontology/Service/Config.ts:555` applies that default to environment configuration.
- `scratchpad/effect-ontology/Runtime/HttpMiddleware.ts:45` defines the system actor, while `scratchpad/effect-ontology/Runtime/HttpMiddleware.ts:95` supplies it on the no-auth path.
- `scratchpad/effect-ontology/Runtime/HttpServer.ts:575` exposes conflict listing and `scratchpad/effect-ontology/Runtime/HttpServer.ts:588` exposes the conflict transition mutation.
- `scratchpad/effect-ontology/server.ts:153` wires this router to the repository-backed runtime.

## Remediation

Authentication now defaults on. Explicitly disabled authentication and public
paths receive a non-authoritative anonymous actor, and the conflict list and
transition handlers reject actors without a credential fingerprint with HTTP
401 before parsing inputs or reaching repositories.
