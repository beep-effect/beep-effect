# CSF-003: Baked runner trusts mutable Bun binary

- Severity: High
- Codex ID: `9459410104b881919cd820b97c673b67`
- Source commit: `4b8bd76c2b14f998639a0f5c36525577a0b0a481`
- Owner: runner AMI bake integrity
- Status: confirmed; remediate; repo-side remediated; deployment proof pending

## Public Summary

The runner image bake installs Bun and warms dependencies as the same mutable user that later executes CI jobs. The fast path verifies version and lock markers but does not verify the installed executable or warmed cache, so prior job code can persist a replacement that later bakes accept.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`; disposition: `remediate`.

The bake script performs the Bun installation and dependency warm-up as `ec2-user`. Its integrity markers cover the requested version, archive digest, and lockfile digest, but not the installed Bun binary or warmed dependency state. The setup action trusts those markers plus executability, and the remote AMI check repeats the marker-only validation.

Evidence:

- `packages/tooling/tool/cli/src/commands/Runners/Runners.service.ts` starts the bake command, installs Bun, warms dependencies, and records the bake markers.
- `.github/actions/setup-monorepo-ci/action.yml:26` implements the fast path, and `.github/actions/setup-monorepo-ci/action.yml:49` checks executability rather than a binary digest.
- `packages/tooling/tool/cli/src/commands/Runners/Runners.service.ts` validates the baked image through the same marker set.

## Remediation

The bake installs root-owned Bun and `bunx` entrypoints under `/usr/local/bin`,
records the installed Bun digest, seals the warmed install cache as a root-owned
mode `0444` archive, records its digest, and removes mutable home-directory
entrypoints and cache state before AMI creation. The setup action discards any
writable cache, verifies artifact ownership, mode, link target, and digests,
then restores the job cache only from the authenticated archive.

Changed files:

- `packages/tooling/tool/cli/src/commands/Runners/Runners.service.ts`
- `.github/actions/setup-monorepo-ci/action.yml`
- `packages/tooling/tool/cli/test/runners-bake.test.ts`
