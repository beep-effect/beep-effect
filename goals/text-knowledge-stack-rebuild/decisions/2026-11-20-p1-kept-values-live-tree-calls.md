Commit 12 (PR C, `feat(identity): internal namespaces with kept values`) follows the live tree at four points of design section 14. (1) Shards: the 13 kept shards of section 5.2 land as written there (epistemic, beepQA, qa, skill-contract, contracts, schemas, document, documents-taxonomy, practice-kg, identity-rdf, semantic-foundation, semantica, lejeune), with no bindings and no deprecations. The csv and xlsx packages main added (#3426) are package composers only: they read no IRI, so they add no shard. (2) Read sites: the read codemod of section 6.3 item 1 does not run here. Main #3431 bundles `@beep/identity` into the CI runner Lambda handlers and fixes `ALLOWED_IDENTITY_SOURCES` to Authority.ts, Id.ts, Root.ts, internal/Segment.ts and internal/schemaStatics.ts, so how commit 14 realises "the composer reads its IRI from the registry" is still open: if the composer keeps deriving its IRI purely, with a build-time proof that every published composer IRI is a declared term, rewriting the kept read sites to `@beep/identity/Registry` would be churn across twelve packages for no byte change. Commit 12 therefore leaves every read site on its composer and adds that proof for the kept values instead: `identity/test/KeptValues.test.ts` pairs each kept read site's composer expression with the registry declaration it must equal, byte for byte, plus a property test that `Registry.mint` under a kept instance base equals the composer's bytes. All composers involved live in `@beep/identity/packages`, so the proof needs no new dependency edge. (3) Instance-only namespaces: semantic-foundation, semantica and lejeune declare no term, so the Vocab test that every namespace lists at least one term now applies to external namespaces only. (4) Release: additions bump the snapshot minor under ruling 2, so the term snapshot moves to release 1.2.0. No handler source map changes: the commit edits no module the handlers load; Registry.data.ts now imports Authority.ts, and only Registry.ts, IdentityRegistry.ts and a type-only import in Id.ts read it.
