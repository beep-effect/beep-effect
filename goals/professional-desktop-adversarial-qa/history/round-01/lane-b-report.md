## Clean areas

- The slash menu initially exposes all nine requested commands: Text, Heading 1, Heading 2, Heading 3, Bulleted list, Numbered list, Check list, Quote, and Code block.
- Slash keyboard navigation works in the clean state: ArrowDown changes selection and Enter chooses the command without sending the draft.
- Slash menu positioning flips above the bottom composer and remains horizontally clamped inside the viewport in the clean state.
- The `- `, `1. `, and `> ` markdown shortcuts converted clean paragraphs to bulleted list, numbered list, and quote blocks respectively.
- The character count updated live for typed and cleared plain text in the clean state.
- Clearing the composer retained editor focus in the clean state.
- Toolbar controls expose stable accessible names and `aria-pressed` values for inline marks and block controls.

## Coverage note

The stale typeahead state is campaign-blocking for reliable continuation of Enter/send, mention, and subsequent formatting scenarios in the same draft: once reproduced, it suppresses send and contaminates later block state. The findings above capture the reproducible causal chain rather than treating each downstream no-op as an unrelated defect.
