## Clean areas

- Ontology navigation opened in the agent-created Chrome tab without affecting other tabs.
- Initial empty state rendered consistently: zero resources/quads, no selection, no query result, no validation result, and disabled session-dependent actions.
- Resource search accepted exact (`Pizza`), partial (`piz`), garbage, and empty input without crashing; empty input restored the empty filter.
- All/TBox/ABox selection and L0/L1/L2/L3 fold controls accepted changes without crashing in the empty state, and the fold badge tracked the selected level.
- SPARQL example selection updated the editor/profile for All triples, Classes, and Hierarchy graph without crashing; Run correctly remained unavailable without a session.
- The sidecar was reachable at port 3939 and correctly required bearer authentication; no raw token was requested or exposed.
- Browser console inspection found no app-origin error for either failed Open attempt.

## Blocked coverage

Because the required tutorial file could not be opened and there is no other repository TTL fixture at a usable workbench path, session-dependent testing was blocked at the entry gate. This prevented meaningful verification of Save/Preview and dirty transitions; tree/inspector synchronization; graph selection, edges, zoom/pan, modes, folds, and inference; Turtle updates; Add Triple and graph gestures; undo/redo; executable SELECT/CONSTRUCT/error/zero/heavy SPARQL cases and the keyboard shortcut; SHACL focus/repair/export; change-log and worker-metric updates; dirty-file guards; and edit/race adversarial sequences. These surfaces were not marked clean.
