## Clean areas

- Completed-turn parity held after reload for prose, paragraphs, hard line breaks, H1/H2/H3 headings, blockquotes, bullet/number/check lists, inline links, wide tables, ordinary code, artifact references, and literal tabs.
- The 9-column table preserved all rows/cells and mixed bold/italic/code marks after reload without escaping its message container.
- `ArtifactRefNode` was reachable from the real LLM only when the paragraph contained exactly one `artifact://` link; the `⧉ QA demo` chip rendered identically after reload and did not expose an interactive role.
- Literal tab characters survived the real-LLM response and persisted reload (`\t` remained in the code node).
- An uninterrupted huge response completed with its requested terminal marker, remained responsive while streaming, and did not drop blocks. The model stopped at roughly 1,120 words despite the approximate 2,000-word request; this was model instruction adherence, not classified as a renderer defect.
- The valid YouTube response was classified into a `youtube-nocookie` iframe in both pipelines; the player-content failure is recorded above.
- Invalid YouTube-id prompting was not reliable: the model reused the valid id rather than emitting the requested invalid id, so invalid-id renderer behavior was not independently proven.
