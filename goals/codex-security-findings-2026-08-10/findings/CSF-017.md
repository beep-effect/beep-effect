# CSF-017: Candor gate can release unrelated superseded AI citations

- Severity: Low
- Codex ID: `2d34ada6ee4481918084f95a0d6414db`
- Source commit: `5e4df6be4ae3a088c8c3b3d750f5090e068df9cc`
- Owner: Law practice candor policy
- Status: fixed-now

## Public Summary

Supersession checked only event identity and source digest, so a different
patent reference in the same source group could retire a gated citation.

## Current-HEAD Validation

Verdict: `fix-now`. The existing exact-version binding did not compare the
parsed patent references of the two events.

## Remediation

The policy now uses schema-derived `PatentReference` equivalence before
honoring a supersession link. A crafted foreign-reference regression remains
blocked with ambiguous lineage.

- `packages/law-practice/use-cases/src/CandorPolicy/CandorPolicy.service.ts`
