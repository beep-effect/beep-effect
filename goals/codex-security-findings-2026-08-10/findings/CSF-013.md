# CSF-013: Git option injection via fleet origin URL

- Severity: Medium
- Codex ID: `fcbbae0865ec819198226bd6ae156169`
- Source commit: `6b42b239a64e845716fc48f415d8c7d70ab5a92e`
- Owner: Repo CLI worktree fleet
- Status: fixed-now

## Public Summary

Fleet mirror probes passed a repository-derived origin URL after Git options
without an option terminator, allowing an option-like value to be reparsed.

## Current-HEAD Validation

Verdict: `fix-now`. Both `ls-remote` and `fetch` had the same missing argument
boundary.

## Remediation

Both commands now place `--end-of-options` before the origin operand. The
regression test uses an option-like origin and proves no marker process runs.

Changed files:

- `packages/tooling/tool/cli/src/commands/Worktree/Fleet.service.ts`
- `packages/tooling/tool/cli/test/worktree-fleet-scan.test.ts`
