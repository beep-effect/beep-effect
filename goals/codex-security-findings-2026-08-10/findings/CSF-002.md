# CSF-002: Non-ephemeral CI runners expose PR jobs to trusted push secrets

- Severity: High
- Codex ID: `382c538bc3c8819195f83b4a36b002fb`
- Source commit: `7de49674756e76cdd4fa3864a13cb6a38b79ffb1`
- Owner: CI fleet architecture
- Status: confirmed; defer-p2

## Public Summary

Reusable burst runners allow state planted by an untrusted pull-request job to
persist into a later trusted push job that receives secrets.

## Current-HEAD Validation

Verdict: `defer-p2`. The ephemeral one-job-one-VM controller is the structural
fix for runner reuse across trust levels. The remaining gap is the live
heavy-lane label cutover, not additional controller code.

## Remediation

This PR hardens the JIT ephemeral controller that destroys each VM after one
job. The finding remains open until the heavy lanes are cut over to that fleet;
merged controller code alone does not change live lane routing.

## Verification

- Prove each runner accepts exactly one job and is destroyed before reuse.
