# CSF-014: Hook-pulse disarm can falsely succeed without disabling hooks

- Severity: Low
- Codex ID: `0af8bec915008191bda6375ea0ef2255`
- Source commit: `e9a1fadb985f7e632129646d36a73472ed9233f0`
- Owner: AI metrics instrumentation
- Status: fixed-now

## Public Summary

The disarm helper treated every failed atomic publish as an existing effective
sentinel, including a dangling symlink that does not stop the writer.

## Current-HEAD Validation

Verdict: `fix-now`. The success path did not verify that the sentinel existed
after the failed hard link.

## Remediation

Disarm now exits nonzero unless the failed publish left an effective sentinel.
A real-shell regression test covers the dangling-symlink case.

Changed files:

- `.claude/hooks/hook-pulse-switch.sh`
- `packages/tooling/library/ai-metrics/test/hook-pulse-writer.test.ts`

## Verification

- `cd packages/tooling/library/ai-metrics && bunx --bun vitest run test/hook-pulse-writer.test.ts`
