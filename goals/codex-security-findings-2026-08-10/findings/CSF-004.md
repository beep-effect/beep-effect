# CSF-004: Shadow runner exposes AWS role creds to job code

- Severity: High
- Codex ID: `c799c2269d748191997ff176ce4bfd48`
- Source commit: `37f289a025b5072e7099a24d195103ab8b2ea4f1`
- Owner: CI fleet architecture
- Status: confirmed; defer-p2

## Public Summary

Host-process job steps can reach instance metadata even though the container
probe is blocked, exposing the runner instance role to workload code.

## Current-HEAD Validation

Verdict: `defer-p2`. The fix belongs in host-level metadata isolation or
removing the bootstrap identity before a job starts.

## Remediation

Deferred to the ephemeral fleet bootstrap redesign. No workflow or
infrastructure files were changed in this PR.

## Verification

- Prove metadata access fails from the actual host job user after bootstrap.
