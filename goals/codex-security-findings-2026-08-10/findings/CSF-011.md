- Severity: Medium
- Codex ID: `98d316271ef08191a2b6939597ae8fec`

## Public Summary

Semantic-delta probes import and execute modules from scanned revisions; a
hermetic environment does not make those modules a sandbox.

## Current-HEAD Validation

Verdict: `defer-p2`. Current code skips fork pull-request probes, but
same-repository and local scans still execute archive code. The remaining class
needs a non-executing probe or a real process sandbox.

## Remediation

Deferred as an architecture change. A context-only guard would leave local and
other untrusted revision scans unsafe.

## Verification
