# CSF-008: JSDoc title tool can leak API tokens to arbitrary proxy URLs

- Severity: Medium
- Codex ID: `6e4c67fc822081918e9546cd4a412c56`
- Source commit: `e500bac6a9afd11992f5749d5da884e956171cf7`
- Owner: Repo CLI quality tooling
- Status: fixed-now

## Public Summary

A caller-controlled proxy URL received the first available provider credential
without validating the destination.

## Current-HEAD Validation

Verdict: `fix-now`. The proxy option accepted any URL and provider credentials
were treated as interchangeable proxy credentials.

## Remediation

The proxy URL now decodes through a loopback-only HTTP schema. Only the
proxy-specific credential is read, and it remains redacted until the request
header boundary.

- `packages/tooling/tool/cli/src/commands/Quality/internal/JSDocMigrate.schemas.ts`
- `packages/tooling/tool/cli/src/commands/Quality/internal/JSDocMigrateTitles.ts`
- `packages/tooling/tool/cli/test/jsdoc-migrate.test.ts`
