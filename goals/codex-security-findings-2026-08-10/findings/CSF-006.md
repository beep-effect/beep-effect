# CSF-006: LLM title data can break out of JSDoc comments

- Severity: Medium
- Codex ID: `23c96402ecec8191977f281cddc19ec7`
- Source commit: `634b7ef88c43415804f1784da6b4bc6fdcea8804`
- Owner: Repo CLI quality tooling
- Status: fixed-now

## Public Summary

Model-provided titles and see-purpose phrases were unrestricted strings that
the migration rewriter interpolated directly into JSDoc blocks.

## Current-HEAD Validation

Verdict: `fix-now`. Current code lacked a single-line/comment-delimiter schema
at the model-response boundary.

## Remediation

The response and frozen-record schemas now require non-empty single-line text
that cannot contain a closing comment delimiter.

- `packages/tooling/tool/cli/src/commands/Quality/internal/JSDocMigrate.schemas.ts`
- `packages/tooling/tool/cli/src/commands/Quality/internal/JSDocMigrateTitles.ts`
