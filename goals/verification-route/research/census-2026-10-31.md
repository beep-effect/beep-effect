At the all-`unknown` record recall is 100% by construction, so the value of
this run is the two facts the first attempt found before it was:

1. **An empty tree diff is not an empty change.** Two PR #1399 heads have trees
   byte-identical to their merge base (a merge of `main` into a branch whose fix
   had already landed), so the classifier emitted no atoms and the route
   selected nothing. The heads still add commits, whose messages commitlint
   reads. The change taxonomy gained a `commits` kind.
2. **Some lanes read inputs outside the head.** On one of those heads Security
   was red while green on the base: `osv-scanner` reads the live OSV advisory
   database (`check.yml`), so its verdict can change with no change at all (the
   same feed reded #2332 on 2026-10-28 with a six-comment-line diff). Footprints
   gained `external`; an external lane is selected for every change.

The first attempt read 97.92% (48 skipped lane runs, 1 skipped red) before both
facts were modelled.

### The `unknown` third

33.55% of all atoms are `unknown`. Classifying the 38,294 changed paths of 300
sampled PR heads with the classifier's own `pathAtomKind` shows where they come
from: packet data files the taxonomy only recognizes as `packet` when they are
markdown (`goals/**` `.json`/`.jsonl`, `explorations/**` `.yaml`/`.properties`/
`.ndjson`, packet `.out`/`.py`), `scratchpad/**` sources that sit outside a
`src/` folder, and `standards/*.json(c)` baselines. `unknown` is sound (it
selects every lane), so this is a taxonomy refinement, not a soundness gap.

## Ranked refinements for slice 2

set is whatever the replay measures under the refined record over the same
