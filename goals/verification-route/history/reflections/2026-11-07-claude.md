# Reflection — verification-route (2026-11-07, claude)

## Summary

Slice 2 landed the first enforced refinement (packet markdown and the commits atom out of `build`
and `check`), admitted by mutation fixtures and a 100% replay over 5,083 pinned heads (242 skipped
lane runs, 0 skipped reds). It also landed a catalog-free root `package.json` projection in
turbo's global inputs and a route section in `yeet final-check` receipts. Slice 3 routes the
hosted Heavy lanes per lane through the admission job: #2879 (`heavy.yml` inputs, admission route
outputs) and #2884 (`check.yml` wiring), two PRs because `heavy.yml` is called at `@main`. The census ranked loss well, but the
refinement it ranked third was unsound; the replay plus a read of each package's build command is
what makes admission safe.

## Tooling experience

- **Worked:** `beep ci route replay` (deterministic, digest-pinned, about 15 minutes per run);
  `beep goals decisions add`; Codex Sol lanes for disjoint packages in one worktree (layer 1 and
  final-check ran in parallel without conflicts); `yeet open` for committed work.
- **Didn't:** local `yeet final-check` under host memory pressure; `yeet publish --push-only` on
  unverified commits (refused, by design).
- **Frustrating:** P0 inbox rows raised by a delegate's mid-edit package-verify run against files
  another lane was still writing; tracing a coverage exit 1 back to one SIGTERMed worker.
- **Wished existed:** a final-check that accepts the same head's passing hosted job; a turbo
  dry-run helper in repo-cli for invalidation counts.

## Implementation improvement opportunities

- Read the workspace graph at the head once a lane first selects from affected packages (decision
  `2026-11-07-propagation-stays-a-label-in-slice-2`).
- Move Biome out of the root manifest's devDependencies if root-dependency bumps should stop
  invalidating every task.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Prove a footprint absence from each package's real command before trusting a
  census rank. The census measures what a refinement would save, not whether it is sound.
- **HIGH — Critical:** Model the atoms every change carries (commits) inside the refinement; without
  that, the refinement skips nothing.
- **MEDIUM — Best practice:** On a loaded workstation, push and let hosted CI prove the head, and
  attribute each local red (exit code, signal, run alone) before fixing.
- **LOW — Consideration:** Delegate disjoint packages to parallel lanes in one worktree only with
  explicit file fences; their verify runs still see each other's half-written files.
