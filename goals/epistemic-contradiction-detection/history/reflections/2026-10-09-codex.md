## Implementation improvement opportunities

Compiler and syntax policies both govern test service lifetimes. Canonical
`it.layer` gives the test suite its service through the sanctioned harness.
The detector has no resource acquisition, so no manual resource wrapper is
needed. The remaining shared-clock judgment requires semantic review: all
clock advances are serial, with no forked work, and the assertion explicitly
falsifies clock dependence. Preserve that assertion when changing the harness.
A successful row export still must not be reported as enforcing lint success.

Runtime goldens cannot catch a widened encoded array type. Encoding through
the shipped non-empty field codec keeps its TypeScript invariant, and a typed
assessment wire in the regression makes this failure visible to package checks.


The detector trusts caller-declared single-valued predicates and opaque modality
keys. A future representation owner can supply a typed adapter, but inference
or taxonomy ownership would exceed this packet. Conflict class remains encoded
in versioned detector identities; a future contract owner may give it a typed
seat while preserving the current evidence-provenance vocabulary.

Proposal facts carry the other assertion's subject, predicate, value and
polarity. Any shape or semantic change must version the detector and preserve
the existing golden vectors as compatibility evidence.
