not further binary axes.

  tooling kind need not equal --type, and foundation does not require library
  unless the separate stories flag is requested. This gives22 states.
- App type with no family/kind: each real appKind nextjs/vite/service/tauri
  permits standard or lab placement; runtime-proof permits standard only.
  This gives9 states. isRealApp is true for the first four, false for runtime.
- Every other flag is fixed by the carried type/appKind/family. All source
  conditions remain the existing1188–1332/1354–1412 gates. Do not fabricate an
  additional parentDir literal domain or use descriptions as Boolean axes.

invocations with defaults, explicit families/kinds, real apps, runtime proof,
