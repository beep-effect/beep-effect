## Binding exclusion and exhaustive check

`goals/boolean-creep/SPEC.md:30–32` excludes generated surfaces, expressly including `_generated` and codegen headers; `goals/boolean-creep/DECISIONS.md:30–32` independently records the generated-source corpus exclusion. That rule applies to actual generated outputs even when the directory is `generated` rather than `_generated`, or the format is JSON and therefore has no comment header. Generated external data is out of corpus before any external-mirror D2 judgment. Authored consumers of generated data remain in scope.

The file audit used the exact frozen `includedFiles` list, not a graph result as the universe:

1. Inspect every included path for `generated/`, `_generated/`, `.gen.`, and `.generated.`; these identify 18 of the 20 files. Broader `autogen`, `codegen`, `generat`, `.pb.`, and `.g.` path probes found only authored generation tooling beyond that set.
2. Scan complete contents of all 3,061 included files for provenance terms (`auto-generated`, `generated by/from/file/code`, `@generated`, `do not edit/modify`, `DO_NOT_EDIT`) and inspect generation mentions in each leading comment block. This identifies `Html.meta.ts` and `Html.model.ts` despite their ordinary role suffixes. It also separates banners in emitted string payloads, imported generated modules, documentation examples, and partial generated sections from file-level output headers.
3. Read each actual output header and every JSON generator destination/emission declaration. All nine JSON paths appear as `outputFile(...)` entries in their target's `SyncDataTargetProjection.files`; they are generated output artifacts, even when called `canonicalPath`. `packages/tooling/tool/cli/src/commands/SyncDataToTs/internal/Source.ts:161–164` constructs the path/content output record, and `packages/tooling/tool/cli/src/commands/SyncDataToTs/SyncDataToTs.command.ts:239–254` resolves and writes these outputs in write mode. No generator was run.
4. Match every canonical record's actual `file` against the complete confirmed exclusion set. The row snapshot below records exact current IDs, not historical search hits or symbol-name guesses.

No additional **whole included file** is established as generated output by these path/header checks. The mixed authored/generated regions documented below are retained as whole files; their generated regions do not become authored carrier candidates merely because the file is retained.

Graft preceded source discovery and supplied generator/consumer anchors. It was followed by the required raw path/header scan and exact source reads; graph edges and absent indexed hits are not completeness proof.
