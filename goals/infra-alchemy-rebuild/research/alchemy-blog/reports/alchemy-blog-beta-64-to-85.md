### beta.64 — 2026-07-22 — 2.0.0-beta.64 — Full AWS Coverage

Source: https://alchemy.run/blog/2026-07-22-beta-64/

**Resources.** 206 AWS services, 683 resources, 2842 bindings plus event sources and sinks. Bindings are 1:1 with IAM on Lambda, ECS, and EKS. Samples: `AWS.DynamoDB.GetItem` / `PutItem` and `*Http`, `AWS.SQS.SendMessage`, `AWS.S3.GetObject`. ECS: `AWS.ECS.Cluster` / `Service` / `Task` / `RunTask`, `AWS.ECS.every`. Image sources: `{main}`, `{main,image}`, `{context,dockerfile?}`, `Dockerfile.inline` from `alchemy/Docker`, `{image}` mirrored to ECR. Service `loadBalancer`, shared ALB, autoscale on CPU or request count, Fargate Spot, EFS, secrets, health checks. A Task returns `{run}`. EKS: `AWS.EC2.Network`, `AWS.EKS.Cluster` with `compute:"auto"`, `AWS.EKS.Deployment` (replaces `ServerHost`), `Job` / `CronJob`, `Manifest` (replaces `alchemy/Kubernetes`), `HelmChart` via local `helm template`. `AWS.Lambda.DurableFunction` plus `Durable.step` / `sleep` / `waitForCallback`; the replay body has no credentials. D1: `Drizzle.Schema` plus `Cloudflare.D1.Database` `migrationsDir` and `Drizzle.D1` / `alchemy/SQL/D1`. Also: Python Workers, Workers AI, Durable Object `locationHint`, Durable Object class transfer, `GitHub.Environment` plus `alchemy login` for GHES, RDS `MasterUserPassword` fingerprint, `skipFinalSnapshot: false`. Out of scope, as the post states it: deprecated APIs, data-only endpoints, billing objects. https://alchemy.run/blog/2026-07-22-beta-64/

**Packages.** AWS provider expansion in-tree. `Dockerfile.inline` from `alchemy/Docker`. `alchemy/Kubernetes` is removed in favor of `AWS.EKS.Manifest`. https://alchemy.run/blog/2026-07-22-beta-64/

**CLI.** `alchemy login` without `alchemy.run.ts`. `alchemy dev` wasm. `--force` refreshes stale bound attributes. https://alchemy.run/blog/2026-07-22-beta-64/

**State.** Destroy aggregates GC failures and does not leave silent zombie rows. Binding diffs are stable. Unresolved Outputs are never persisted. Truncated physical names stay unique. A v1 migration adopts instead of destroy/recreate. No type named `BucketState`. https://alchemy.run/blog/2026-07-22-beta-64/

**Testing.** Effect-native `alchemy-test` runner. 2692 live tests default green, 375 env-gated. A zero-orphan test loop. The suite at the end of the post is 4458 passed. https://alchemy.run/blog/2026-07-22-beta-64/

**Effect.** Bindings grant IAM on the host. `{run}` on ECS Task, not `{fetch}`. Durable steps, sleeps, and callbacks. Duration props are `Duration.Input`. Secrets are `Redacted.Redacted<string>`. https://alchemy.run/blog/2026-07-22-beta-64/

**Breaking.** `docker: {base}` becomes `image`. `AWS.EKS.ServerHost` becomes `Deployment`. `alchemy/Kubernetes` is removed. ECS Task implementation is `{run}`, not `{fetch}`. https://alchemy.run/blog/2026-07-22-beta-64/

**Migration.** Update image sources, EKS host types, and Kubernetes manifests to the names above. Duration and secret types change at the type level. https://alchemy.run/blog/2026-07-22-beta-64/

**Tips.** Image source shapes are flat and interchangeable, including an inline Dockerfile. Auto Mode EKS is `compute: "auto"`. A durable Lambda replay body holds no credentials. `AWS_REGION` overrides the SSO region. Actions local bindings exist. https://alchemy.run/blog/2026-07-22-beta-64/
