# Reflection — merge-queue-lab (2026-11-10, claude)

## Summary

The lab ran a real merge queue on `queue-lab` behind a toy required check,
drove about thirty synthetic pull requests through it, and recorded every
Observations row with saved evidence. `@beep/github` gained typed
`enqueuePullRequest`, `dequeuePullRequest` and `mergeQueueEntry`. The verdict is
**go**: every fleet identity can enqueue, the App can jump and enqueue workflow
pull requests, and the landed commit is the commit the group proved.

## Tooling experience

- **Worked:** the GitHub GraphQL timeline (`AddedToMergeQueueEvent`,
  `RemovedFromMergeQueueEvent.reason`) answered most questions directly. One
  bash driver with `open`, `enqueue`, `wait`, `ruleset-set` and `cleanup`
  turned each observation into a short scenario, and two background batches ran
  twenty scenarios with no supervision. `yeet open` for a pre-committed head
  and `yeet reply` drafts worked as documented. `package-verify` caught the
  Biome sort and the `yieldInCallArgument` diagnostic before any push.
- **Didn't:** `yeet open` refuses untracked files anywhere in the tree, so lab
  evidence collected in the driver lane's checkout had to move to a second
  worktree. Hosted CI lost two shards to an apt mirror timeout, and three
  aggregate rows followed from them as separate P0/P1 inbox rows.
- **Frustrating:** `yeet final-check` (about 30 minutes) found two reds that
  `package-verify` does not run: the instrumentation catalog shard for new spans
  and an `effect-vitest` resource finding. A review thread then made the first
  receipt stale, and the second final-check had to be stopped before editing.
- **Wished existed:** a `package-verify` mode that also runs the catalog and
  effect-vitest checks for the touched package; a Yeet inbox ack that covers a
  red and the aggregate rows derived from it in one call.

## Implementation improvement opportunities

- `enqueuePullRequest` returns `Option<MergeQueueEntry>`; GitHub never returned
  a null entry in the lab, so a later change could make it a plain entry with
  a decode failure for the null case.
- The driver script polls every 30 s per pull request. For the activation goal,
  a single GraphQL document over `mergeQueue.entries` would read the whole queue
  in one call.
- `MergeQueueEntry` drops the queue `configuration`; `merge-queue-activation`
  will want a typed read of it (note `checkResponseTimeout` is in seconds).

## Goal & prompt critique

- Replace "Branch names start with `queue-lab/`" with "Branch names start with
  `queue-lab-`" in `SPEC.md` Constraints.
- Add to Target Surfaces: "Workflows on the lab branch may use only
  `pull_request`, `merge_group` and `push` triggers; `workflow_dispatch`,
  `schedule` and `issue_comment` need the default branch."
- The Observations table was the right unit. Ordering it by verdict weight
  (identities, landed SHA, failure handling, then parameter probes) let the
  first two hours settle the verdict; keep that ordering note in future lab
  packets.
- The prompt's hard limit "never print a token" plus "observe secrets by
  presence" was enough guidance; nothing else was needed.

## TODOs worth codifying

- The four `todos` above, owned by `merge-group-parity` and `yeet-queue-states`.
- A packet lint that checks planned branch names against planned base branches.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Enqueue with the App, never with `GITHUB_TOKEN` — a
  token-made enqueue builds the group but starts no workflow run, so the entry
  dies at the timeout.
- **HIGH — Critical:** Probe a live API before writing a fixture for an error
  path — the not-found shape was wrong in the first test and only a reviewer
  caught it.
- **MEDIUM — Best practice:** Run lab batches from a script that sources one
  environment file with `GH_REPO` set, writes one evidence file per scenario,
  and waits on queue drain between scenarios — it kept twenty scenarios
  independent.
- **LOW — Consideration:** Keep the lab ruleset's check timeout short (ten
  minutes) — the timeout probes then finish in minutes, at no cost to the
  design settings for `main`.
