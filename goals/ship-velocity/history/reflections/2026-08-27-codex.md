# Reflection — ship-velocity (2026-08-27, codex)

## Summary

The closeout branch completes the unfinished P2-P5 engineering backlog: failures now reach and
constrain owning sessions, local proof models the 17 required hosted contexts, expensive work is
admitted against machine memory, cache behavior is measurable and recoverable, and derived
portfolio files no longer create merge churn. The Atlas closeout includes the D6 README projection
instead of treating deletion alone as retirement. The engineering verdict is positive, while the
initiative verdict remains deliberately open until its post-merge outcome gate is observed.

## Tooling experience

- **Worked:** CodeGraph provided the required first structural pass; targeted source inventory
  resolved the few deferred symbols. Schema-first and Effect-first checks kept new persistent
  contracts typed. Focused Bun tests, repo-cli typecheck/lint/docgen, and Yeet provide progressively
  stronger proof. Live GitHub trials made E7 and E8 decisions evidence-based instead of speculative.
- **Didn't:** `@effect/vitest` finalizers hung after otherwise successful subprocess tests in two
  new test files; native Vitest with explicit `Effect.runPromise` and cleanup completed reliably.
  GitHub refused direct base-branch editing while a PR belonged to a stack, which is useful product
  behavior but rules out treating stacks as ordinary chained PRs.
- **Frustrating:** A global `turbo.json` edit escalated local docgen to the entire cold graph before
  the package-level missing-annotation finding appeared. The full graph cost was valid, but the
  failure could have been surfaced cheaply first.
- **Wished existed:** A bounded metrics command that joins Yeet watch events, the parity ledger,
  cache summaries, admission/RSS receipts, and contention retries into one schema-validated
  observation report.

## Implementation improvement opportunities

- Exercise two full verifies concurrently from isolated exact-head worktrees and retain both
  admission and peak-RSS receipts. Unit tests prove scheduling semantics; the manifest asks for a
  live no-OOM result.
- Retire `manifest-adoption` packet by packet only through the fleet migration. Once an exploration
  has `ops/events/`, a broken stream must stay a hard projection failure rather than falling back to
  legacy manifest state.
- Keep stacked publication manual until Yeet can bind proof, lease ownership, repair waves, and
  closeout to multiple heads atomically. The live two-layer trial proved the GitHub surface, not
  the missing Yeet model.
- Add the cheap changed-export documentation preflight before full docgen escalation.

## Goal & prompt critique

- Replace the original “each item = its own PR” sentence with an explicit normal-case rule plus an
  operator override field. The one-PR closeout request was clear, but the packet should not retain
  a contradictory execution law after that decision.
- Separate “implementation complete” from “initiative complete” in the phase vocabulary. P5 has
  finished engineering work yet must remain in progress for a representative post-merge week;
  the current status enum cannot express both without a status note.

## TODOs worth codifying

- Add a `beep metrics closeout ship-velocity --from … --to …` report or a goal-generic equivalent.
- Add a docgen annotation preflight that runs before affected/full graph selection.
- Preserve the E7 rule: a successful GitHub stacked-PR spike does not authorize Yeet stack
  publication until multi-head proof and lease semantics exist.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Do not close an outcome-gated initiative from pre-merge synthetic proof —
  capability evidence and representative production evidence answer different questions.
- **MEDIUM — Best practice:** Prove external workflow decisions with disposable draft PRs and then
  close and remove every trial branch — product constraints emerge that local modeling misses.
- **LOW — Consideration:** A dedicated “implementation-complete” phase status may make long-running
  observation gates more legible than carrying the distinction only in prose.
