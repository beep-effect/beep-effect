# tsgo 0.45 Effect idiom sweep — Spec

## Objective

Bump `@effect/tsgo` from 0.39.1 to 0.45.0 with every installed rule at
`error` and every plugin config key set explicitly, widen the directive gate
so the whole repository is scanned with exactly two declared exemptions,
retire the redundant TaggedError equivalence hook that upstream rc.113 made
unnecessary, and restore idiomatic Match combinators repo-wide behind a lint
law. Main is never red while this lands.

## Non-Goals

- Changing the effect RC pin. The packet consumes whatever main pins
  (rc.115 is in flight on `@chore/slop-fixes-09-12-26`).
- Any idiom tsgo 0.45 cannot detect (D9). Record such findings in
  `research/OPPORTUNITIES.md`; do not fix them in fixer lanes.
- Rewriting the root `vitest.setup.ts` Bun shim Effect-native (D1).
- Replacing the `@beep/schema` `Opaque.Defect` wrapper; upstream `Defect` is
  still `decodeTo<Unknown, Json>` (D4, D10).
- Test deletion, schema weakening, or `flakyTest` to satisfy a diagnostic.

## Constraints

- No `@effect-diagnostics` directive is added anywhere. The allowlist is the
  complete set of exemptions and has exactly two entries.
- No installed rule runs below `error`. No allowance counts, no baselines
  for tsgo diagnostics.
- Lanes never run `git`. The orchestrator stages by name and commits.
- Disjoint ownership: a shard owns its paths; no two fixers touch one file.
- Every fixer edit is verified against the clones, not memory. Cite the
  clone `file:line` in the lane report for any API that is new to the repo.
- Lane PRs must be green on the 0.39.1 gate. The worktree-local 0.45 install
  used for visibility is never committed (`git status` must not show
  `package.json`, `bun.lock`, or `node_modules` changes from it).
- `@beep/repo-cli` changes ship alone, as in prior packets.
- Package handoff: `bun run beep quality package-verify <@beep/pkg>` per
  touched package before a lane reports done.
- Test files follow the effect-vitest canon: `it.effect` with
  `Schema.decodeUnknownEffect` / `encodeUnknownEffect`, never
  `Effect.runSync` wrappers around decode.
- Public-safe paths only in packet prose: write `$HOME/...`, never a
  tilde-relative or absolute home path.

## Stop Conditions

- A shard's fixes require a schema or public API change not named here.
- tsgo 0.45.0 fails `effect-tsgo patch` against the pinned TypeScript 7.0.2
  binary. Record the failure and stop; the pin decision is Benjamin's.
- A lane needs a third exemption. Stop and ask; the allowlist is closed.
- The same hosted check fails twice on unrelated files (attribute before
  repairing: introduced, inherited, unrelated, environment-only).
- Any request to merge.
