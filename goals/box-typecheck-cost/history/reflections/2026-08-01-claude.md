# Reflection - box-typecheck-cost (2026-08-01, claude)

## Summary

This packet scoped `@beep/box`'s generated SDK surface to declared demand: 9 of
85 `BoxClient` managers, 34 of 333 operations, 294 of 2,763 model schemas, via
an explicit manager manifest plus a transitive model-closure prune. Package
instantiations fell 7,472,755 → 2,503,112 (−66.5%); `Box.models.gen.ts` fell
88,709 → 9,822 lines and 6.797s → 0.816s to check.

Lever 1 met budget alone. The staged levers 2 (generator-emitted explicit type
annotations) and 3 (per-manager file split) were never fired and are retained
as designed-but-unbuilt.

## What the measurement changed

The packet's most useful output was not the prune — it was discovering that the
budget metric was wrong. The original per-file budget (≤1.5M instantiations,
absolute) was set from the observed 4.8M without asking what a *floor* file
costs. It costs 1,649,265. The budget was therefore below the floor: no file in
this repo importing `effect/Schema` could ever satisfy it, and the metric it
gated was ~83% constant after the prune.

Restating the per-file budget as marginal cost (`total − floor`) makes it
respond to work on the package. The package-wide ≤3M absolute budget needed no
amendment and was met.

The general lesson: an absolute instantiation count for a single file in a
schema-heavy repo is mostly a measure of its imports. Budget the delta.

## Tooling experience

- `bun run beep goals doctor` caught four real manifest schema violations while
  the packet was being authored (`"open"` is not a `GoalStatus`; `"conditional"`
  is not a `GoalPhaseStatus` — conditionality belongs in a phase's `exit` field;
  `supersededBy` is a slug string, not an object). Running it immediately after
  authoring a packet is cheaper than discovering these at closeout.
- The Effect LSP rejected `Effect.dieMessage` as a v3 API and named the v4
  replacement inline. Separately, `A.filterMap` in v4 takes a `Filter`
  (`Result`-returning), not an `Option` — the file's existing
  `A.getSomes(A.map(...))` idiom was the correct local precedent. Both confirm
  the standing rule: validate Effect APIs against v4 source rather than writing
  from priors.
- 76 dropped managers are logged by name on every generation, so the reduced
  surface is self-documenting rather than a silent cap.

## Carry-forward

The manifest at `packages/drivers/box/scripts/box.surface.ts` is the single
chokepoint through which generated mass can regrow, which is why the budget is
enforced as a review obligation on manifest edits rather than a CI lane. If a
future manager addition pushes marginal cost past 750K, lever 2 is the
pre-agreed next step — and `SPEC.md` §4 records why a file split must not be
tried first.
