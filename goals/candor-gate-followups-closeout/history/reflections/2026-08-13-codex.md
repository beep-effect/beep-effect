# Reflection — candor-gate-followups-closeout (2026-08-13, codex)

The packet terminally disposed all five inherited candor follow-ons plus the
Lint Policy divergence. It shipped the shared promotion contract, fail-closed
law adapter, acceptance consultation, widened examiner gate, authoritative
ST.13 boundary and migration guard, while retaining evidence-backed no-build
decisions for the speculative index and shared Crypto helper.

## Tooling experience

- **Worked:** The quality reviewer loop found schema, migration, ownership,
  observability, and documentation defects before publication; Yeet then tied
  exact-head local proof, replies, hosted checks, and closeout into one verdict.
- **Didn't:** Focused package checks did not cover the repository's strict
  test-source compiler contract, and line-sensitive lint inventory entries
  drifted after harmless test edits.
- **Frustrating:** Full verification repeatedly paid the global docgen and
  hosted coverage costs for small closeout-only corrections.
- **Wished existed:** Stable symbol-addressed lint exceptions and a changed-file
  strict test-source lane that exactly matches hosted compiler rules.

## Implementation improvement opportunities

- Treat snapshot consistency as an explicit service-boundary invariant whenever
  a decision combines multiple append-only record families.
- Keep the synchronous promotion gate only while the two real consumers need
  it; the package's removal trigger already names the shared command/event
  alternative.

migration bundle test, and the Yeet closeout receipt from the start. Those were

## Lessons (confidence-tiered)

- **HIGH — Critical:** Bind promotion decisions to a coherent evidence snapshot
  and recheck immediately before acceptance — fail-closed vocabulary alone does
  not prevent a stale-clear race.
- **HIGH — Critical:** Include the referenced object in lineage identity — one
  prosecution source can contain multiple independent citations.
- **MEDIUM — Best practice:** Prove wire migrations against a real pre-upgrade
  database and the actual migration bundle — hand-copied constraint tests do not
  establish deployment safety.
- **LOW — Consideration:** Delay shared fixture helpers and physical indexes
  until live duplication or representative planner evidence earns them.
