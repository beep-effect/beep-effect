# Reflection — tsrs-gates (2026-10-27, claude)

## Summary

The typecheck and build gates moved from tsc-rs 0.8.0 to the Effect-patched tsrs
0.20.0 that `@effect/tsgo` 0.59.0 ships (PR 1, #2260, merged as e39244dbc5), and
the standalone Effect Diagnostics lane folded into Check (PR 2, #2262): all 130
rules live in `tsconfig.base.json`, the three ignore flags are false, and the
standalone profile, command, CI lane, final-check gate and hosted matrix job are
gone. Diagnostics were identical on all 181 check projects; hosted Heavy / Check
ran in 3m36s on tsrs.

## Tooling experience

- **Worked:** `beep goals bootstrap --plan/--write`, `beep worktree new --base`
  for the stacked lane, `beep cache audit --json` to size drift exactly,
  `beep yeet final-check --skip` for attributed inherited reds, `yeet reply` for
  the CodeRabbit thread, and an Opus subagent for the repo-cli side of the lane
  removal while the orchestrator handled configs, docs and workflow.
- **Didn't:** `yeet repair` overran ten minutes and rewrote unrelated files;
  `yeet ready --inherited` ignored optional reds the receipt had failed.
- **Frustrating:** five baseline-only merge conflicts; the knowledge
  semantic-delta checker reads committed content, so a working-tree fix still
  reported eight findings until it was committed.
- **Wished existed:** a baseline rebase mode and a tool-owned ruleset apply.

## Implementation improvement opportunities

- Move editors to `tsrs --lsp` once upstream qualifies it; today the LSP and the
  tsgo-only quality lanes stay on the Go binary.
- Re-measure `--fast` on tsrs before considering it for CI.

## Goal & prompt critique

  (npm `tsc-rs`)."

## Lessons (confidence-tiered)

- **HIGH — Critical:** Prove compiler parity per project before swapping a gate
  compiler — the 181-project sweep (0/0 diagnostics) and the unknown-rule overlay
  (11 vs 0 TS377134) decided both PRs.
- **HIGH — Critical:** When main lands a stacked PR as a squash, check that main's
  copy of each conflicted file equals the stacked parent's final head before
  taking the lane side wholesale.
- **MEDIUM — Best practice:** Split a gate swap from the retirement of a lane it
  makes redundant; each risk gets its own hosted evidence.
- **LOW — Consideration:** Peak RSS per project rose on tsrs while wall time fell;
  watch the runner memory budget if concurrency is raised.
