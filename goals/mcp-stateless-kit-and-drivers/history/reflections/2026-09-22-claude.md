# Reflection — mcp-stateless-kit-and-drivers (2026-09-22, claude)

## Summary

Four PRs in one day rebased `@beep/mcp-kit` on the rc.117 `2026-07-28` adapter, added the in-repo
2026 client and conformance port (#1192), and cut m365, uspto (#1204), gov-legal and practice-kg
(#1209) over to `[McpProtocol.v2026_07_28]` only, each proven by `conformance2026` over HTTP and
stdio and the compiled `.mcpb` smoke. nlp-mcp is held by the D-cli-contract capture
(`history/nlp-mcp-capture.md`): the daily CLI opens stdio with a legacy `initialize` unless
`MCP_PROTOCOL_NEGOTIATION=auto` is set, so the flip would break every default launch. Verdict:
the goal's outcome holds for five of six hosts with a recorded, gated hold on the sixth.

## Tooling experience

- **Worked:** `conformance2026(host)` as one proof standard for five hosts; the scoped
  `vitest run --coverage --coverage.reporter=lcov` loop matched the hosted ratchet to two
  decimals; `yeet publish --start-pr-early --monitor --pr --detach` plus `job wait`; the
  stdin-logging shim in front of the host for the capture; cross-session messages to the
  session that owned PR #1201's lane instead of merging into its worktree.
- **Didn't:** a detached proof reads the lane's live tree, so a mid-proof merge poisoned it;
  `beep worktree new` branches from the clone's checked-out branch (`@slop/…`), not
  `origin/main`, and needed a reset every time; `worktree remove --delete-branch` on a lane the
  monitor had swept onto `main` deleted local `main`.
- **Frustrating:** five spot reclaims read as "needs code fix"; `gh run view --log` and the
  redirecting `gh api` returned empty logs while a run was in progress (a direct authenticated
  download worked); commitlint's 100-character header bit three times with the goal slug in the
  header (put it in the body); the JSDoc root-import ratchet is invisible in the inventory rows.
- **Wished existed:** a package-scoped coverage gate in `package-verify`; a monitor that
  serializes reruns on one run; a `quality package-verify --quick` that builds project references
  in a fresh worktree instead of failing on TS6305 until `turbo run check` has run once.

## Implementation improvement opportunities

- Registrations before transport for stateless stdio hosts (see finding); the harness fix only
  covers tests.
- The `api_key_required` non-error envelope and the array-in-text projection are now proven in
  host tests; the kit README should state the projection rule in one line next to the consumer
  table.
- `withStdioHost` builds a fresh server per stdio arm; hosts with heavy registrations would
  benefit from a per-describe layer like the HTTP arms already use.

## Goal & prompt critique

- Spell out the capture's decision rule and the two opt-in switches in GOAL.md (finding above).
- GOAL.md's "PR 4 ... flip nlp-mcp if a daily CLI sends `server/discover` first" should say
  "by default"; as written it is satisfiable under an environment switch nobody's daily launch sets.
- Keep the four-PR split: the first stdio red (spot reclaim, then the practice-kg race) was
  attributable only because each PR carried one or two hosts.

## TODOs worth codifying

- See `todos` in the frontmatter; the two highest-value are the detached-proof write fence and
  the spot-reclaim flake class in the monitor.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Never mutate a lane that has a live detached proof — the proof reads the
  tree it is running in, and a merge with conflict markers turns a green run red on every shard.
- **HIGH — Critical:** A "lost communication" Heavy red with no failed step and a `BlobNotFound`
  log is the fleet, not the diff; confirm with the EC2 instance's `StateTransitionReason` and
  rerun once per occurrence.
- **MEDIUM — Best practice:** Reproduce coverage floors with the package-scoped lcov run before
  the first push, and restore lost coverage with real tests; keep pre-existing rows at main's
  floors and set new-file rows to measured-or-lower.
- **MEDIUM — Best practice:** A stateless host has no handshake to hide slow startup behind;
  test harnesses and hosts must wait for registrations before serving.
- **LOW — Consideration:** For a decision like the nlp-mcp flip, record both the default and the
  opt-in behaviour verbatim; the operator can then flip by setting one variable, and the gate says
  exactly which.
