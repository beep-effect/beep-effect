# Reflection — ci-fleet-residue (2026-08-24, claude)

## Summary

The packet is ready to close: P3 (#686) and the packet docs (#692) established
the base, P2 deployed through #708/#717 and passed run 31779611279, P0
activated through #702/#718/#725 and passed run 31971776803, and P1's #730
revert was followed by a calm tripwire week with zero in-window interruption
re-runs. The verdict is positive, but the closeout arc showed that
generated-template, secret-state, runtime-shape, and attribution boundaries
need explicit proof.

## Tooling experience

- **Worked:** `pulumi preview --diff` exposed the HCL bridge failure before a
  deploy, and `pulumi preview --refresh` proved the P0 rollback that a plain
  preview hid. Gate E plus the complete red-team run 31779611279 proved the
  P2 hook on a live ephemeral worker, while the two P0 probe runs turned a
  missing `bunx` symlink into #725 and then demonstrated the baked fast path.
- **Didn't:** #708's source-string tests did not round-trip user data through
  Terraform's JSON-template parser. A plain Pulumi preview could not support a
  rollback verdict for the secret-valued SSM pin, and Yeet's Greptile score
  reader could not distinguish score-shaped prose from the actual score on
  #727.
- **Frustrating:** the first live bake burned through more than a dozen failed attempts across IAM
  policy shape, EC2 propagation, console-posting latency, AWS CLI decoding,
  and AL2023 `cloud-init` differences. The serial-console narration and ERR
  trap eventually made those failures actionable, as itemized in
  `research/OPPORTUNITIES.md`. Separately, the P2 wrapper died before teardown
  because zsh reserves `status`; run 31779611279 still completed green and
  teardown was asserted manually before the wrapper fix.
- **Wished existed:** a pre-merge plan smoke test for module-bound user data,
  a structured Greptile score field, and one attribution collector that
  retains job and annotation evidence for both re-run and never-re-run
  failures.

## Implementation improvement opportunities

- Move the required `beep-ci-bake` launcher policy into IaC. The P0 evidence
  records that policy v4 remains hand-managed even though future bakes depend
  on its SSM reads, tag-conditioned console access, and image creation rights.
- Extend the baked-image contract beyond marker, lockfile hash, and Bun
  version to cover required executable links. Run 31969468654 proved that an
  otherwise fresh image could still fail at the first `bunx turbo`; #725's
  self-heal should be the recovery path, not the first detector.
- Reuse the #717 HCL escaping boundary for every Terraform-module string
  input and keep its rendered-byte equivalence test. The callback form of
  `replaceAllWith` is part of the correctness contract, not a style choice.
- Make the refresh requirement visible in the P0 operator recipe wherever a
  preview is used as evidence. The rollback proof in
  `research/p0-activation-evidence.md` shows that a no-diff result without
  refresh is inconclusive for the secret-valued runner AMI parameter.

## Goal & prompt critique

The GOAL's hard rail that fleet changes are accepted by live probes worked
exactly as intended: it caught the #725 `bunx` gap after #718 and gave the P2
hook a real Gate E rather than a configuration-only claim. Preserve that rail.

The P1 gate also made the right decision shape—measure, attribute, then act—but
`once a calm on-demand week is measured` was underspecified. Replace it with:

> Measure the on-demand baseline over an explicit `[start, end)` UTC interval.
> Attribute every re-run using attempt-1 job and annotation evidence. Deploy
> spot only after `end`, unless a dated operator decision records the measured
> coverage, the omitted interval, and why omission cannot change the verdict.
> Monitor the same explicit interval after deploy; more than two
> interruption-attributed re-run IDs returns the longest lanes to on-demand.

That edit retains the successful dated-decision gate while removing the
ambiguity between a calendar token and an evidence condition. An exact cutoff
also mattered in practice: run 32688837330 had an explicit runner-loss
annotation after the window and correctly did not increment the tripwire. For
P4, the prompt should also name the durable tripwire artifact as required
input; the supplied `attribution-report.md` and the packet's
`research/p1-tripwire-week-evidence.md` made the closeout verdict auditable.

## TODOs worth codifying

- Generalize the HCL-template escape helper and rendered-value test across
  Terraform-module inputs; protect the `$${` callback replacement explicitly.
- Add `--refresh` to every secret-valued SSM preview, deploy, and rollback
  recipe, with a warning that a plain no-diff preview is inconclusive.
- Anchor the Greptile parser to `Confidence Score:` and invalidate cached
  results when the summary comment's `updated_at` changes.
- Build a tripwire collector that captures attempt-1 jobs and check-run
  annotations for all failed or cancelled runs, whether or not they were
  re-run, so the never-rerun population is classifiable.

## Lessons (confidence-tiered)

- **HIGH — Critical:** validate the artifact at the boundary that consumes it
  — #708 was valid TypeScript and invalid HCL until #717 tested the
  module-bound representation.
- **HIGH — Critical:** do not activate infrastructure from configuration proof
  alone — run 31969468654 found the missing executable surface, and run
  31971776803 proved #725 plus `Baked fast path: true` under a real lane.
- **HIGH — Critical:** refresh secret-backed state before accepting a rollback
  preview — #718's plain preview hid the SSM pin change that `--refresh`
  revealed.
- **MEDIUM — Best practice:** measure a control noise floor before changing
  capacity posture — the 528-run on-demand baseline made the P1 post-#730
  interruption classifier meaningful instead of treating every re-run as a
  spot reclaim.
- **MEDIUM — Best practice:** attribute before counting — the tripwire week had
  12 in-window re-run IDs but zero interruption-shaped events; code failures,
  service errors, explicit cancels, and timeouts were all evidenced separately.
- **LOW — Consideration:** parse human-edited bot comments through labeled
  fields, not visual tokens — #727 demonstrated that bare `N/5` text can occur
  in ordinary prose and that the summary can be edited in place.
