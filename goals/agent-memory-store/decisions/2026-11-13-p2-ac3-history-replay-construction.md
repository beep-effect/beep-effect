AC-3's bars (resolver-needed 26/279, per-op landing 95%) came from S14 and S14b, a replay of this repository's goals history with sequential commits replayed as concurrent writers. The P2 fixture (p2-adversarial-fixture-is-seeded-contention-strata) cannot be compared with them, so AC-3 is judged on a re-derivation of that replay from public git history; nothing from the spike's machine-local folders is used. The rule is fixed here, before any admission outcome was measured. Pinned commit: 3f0261b37a0 (S14's corpus commit, an ancestor of origin/main). Commits: every non-merge commit reachable from the pin that touches goals/**/*.md (git log --no-merges -M), in committer-time order. Sessions: consecutive commits naming the same first Co-Authored-By agent (no trailer counts as one agent) at most 30 minutes apart; the trace is the most recent 200 sessions. Writes: a session's net edit of one file along a continuous blob chain; an added file never clusters. Clusters: a write whose base blob is the serial head of an open cluster on the same path, starting within two hours of the cluster's first write, joins it while it has fewer than eight writers, otherwise it opens a cluster; clusters of two or more writers are kept. Writer text, so every writer starts from the cluster's one base: the first writer's own result; each later writer's own line delta (previous serial head to its result) moved onto the base at line level, where a base line an earlier writer changed and this writer changed again takes this writer's text, a line only an earlier writer inserted cannot be removed from the base so only this writer's new text is kept, and a hunk of an earlier writer that this writer replaced whole removes its base lines too. Exclusions: the generated goals index goals/INDEX.md, and every cluster whose base or any writer text is over 200,000 UTF-8 bytes or holds U+FFFD (a blob that is not UTF-8); non-Markdown files never enter the log query. The cap was chosen from the frozen-file budget alone (about 700 KB): with a 400,000-byte cap nothing is excluded and the packed file is 873,554 bytes; at 200,000 it is 671,533 bytes. Shape against S14: before exclusions the trace has 120 clusters and 279 cluster writes, S14's primary trace exactly; the cap removes two clusters (two SPEC.md bases of 254 KB and 322 KB, 4 writes), leaving 118 clusters and 275 writes. Op capture (no admission run) turns the 275 writes into 3,364 operations (208 replace, 3,093 insert, 29 delete, 34 setStatus), 12.2 per write against S14's 1,977/279 (7.1): op capture places the bytes between content nodes in gap nodes, so a new paragraph is two inserts, while S14's row nodes carried no gaps. Measurement: each cluster's base is one file of one memory folder under its own numbered folder (so clusters never share a node), imported once; every writer captures its whole edited text against that export narrowed to its file (capture and status typing read only the file an edit names, admission never reads a batch's base) and is status-typed with the goal phase lifecycle pending, in-progress, complete, superseded (GoalPhaseStatus in the goals CLI schemas); a writer whose capture is empty counts as a write with no operations. Orders: the history order (clusters in order, each cluster's writers in commit order) is the judged run, because S14b's sequencer admitted writers in causal commit order; three seeded orders (seeds 1 to 3, shuffling all writes) are reported and must also show zero silent loss. No cluster sampling: all 118 clusters run in every order. Counting: resolver-needed writes have at least one held operation; the structural floor is the writes with a held operation whose findings name deleteVersusEdit or insertUnderDeletedAnchor; per-op landing is landed over captured operations, with landing over operations on non-gap nodes reported beside it for comparison with S14's gapless nodes. Bars as integers on the history order: resolver-needed x 279 <= 26 x writes, landed x 100 >= 95 x operations. Like S14, the replay is an upper bound on contention: S14 found 2 of 70 real merges touching one goals file on both sides.
