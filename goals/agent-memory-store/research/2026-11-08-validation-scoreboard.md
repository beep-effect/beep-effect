## What the kills mean

All three kills fired on criteria the plan pre-registered, and each lands on the plan's stated failure branch:

- S7 → "the gate stays an admissibility filter and the cross-encoder is the only relevance model." The design loses a stage.
- S9 → "keep counts out of ranking." The design loses a ranking feature it never shipped.
- S35 → the hash demotes from verdict to signal. The design loses a claim, not a component.

S14 is the exception. The plan said "arm A fails → Loro on agent paths too". The data says the opposite: arm A failed a bar that no text merge can reach, because the contested nodes are single-valued fields, while Loro converged on every write and corrupted most of the contested ones. The fallback line in PLAN v2 (line 78) is wrong and is withdrawn here.

## The design after Day 2 (v3)

1. **Authority is the set-union fact log of immutable events.** Unchanged. S15 adds the proof that the CRDT cannot hold provenance: shallow snapshots drop it by design.
2. **No CRDT on agent write paths.** Agent writes go through store-side admission: per-node CAS at row and list-item granularity, three-way merge on disjoint nodes, contested nodes held with both texts, per-op admission so clean ops land while one node waits. Zero silent loss is the bar, with a bounded held rate; 95% auto-merge is not a reachable bar for free text.
3. **Status leaves free text; the residual is prose-shaped state.** S14b: typed status fields resolve cleanly (10/10, 0/14 wrong) and need a lifecycle guard against backward moves; counters are already generated projections in the repo, so nothing to derive; `## Current Phase` paragraphs are the remaining state-in-prose (13/31 residual conflicts) and want a single owner or generation from the manifest, not last-writer. Structural conflicts (delete vs edit, insert under a deleted anchor: 8/279) are held in every arm. Held writes needing a resolver settle near 9% on this upper-bound trace with zero silent loss; that is the figure to budget for, not 5%.
4. **Loro, if at all, is for human editing only**, with tree ops sequenced through the durable replica, per-peer subsections for concurrent appends, links by NodeId, and never `update` on free text from agents.
5. **Write boundary is the raw-slice L0 projection** (S1), with a reparse check for parse-boundary changes an edit can cause without touching other bytes.
6. **Identity is tiered with abstention** (S2). Handles and op capture carry claim transfer; the similarity tier only mints with a candidate edge. S9 reaches the same place from the other side: 38% of unlinked updates lose even with no count, so the link must be captured at write time.
7. **Retrieval order:** authoritative filters → BM25-leaning fusion (convex combination beat RRF 64/71 vs 59/71 recall@5; BM25 alone tied convex; dense alone 44/71; RRF is not the default) → cross-encoder → admissibility gate with typed findings, now including the typed identity lookup → budgets. No separate relevance stage. The near-miss stratum (qualifier changes, 16/16 accepted) is unsolved by every arm and is the one place a query-to-claim rewriter might earn a stage.
8. **Prevalence is an observation log.** Counts never enter rank or gate. Derived independence metrics are displayed, not enforced.
9. **Dedupe:** exact hash defers to tier 0; near-duplicates flag only.
10. **Symbol liveness:** SCIP resolves identity; a normalized span hash (no whole-file edges, no bare names) marks "re-verify"; `lat` is not trusted alone.
11. **The 120-competitor budget is gone.** Result budgets stay rival-, evidence- and token-based (S6 later).

## Cross-cutting findings

- **The memory store has no history.** S7 (all 54 superseded fixtures had to come from git-tracked goals; 75 memory blocks say "superseded" inline and read as current), S14 (0 memory sessions replayable) and S35 (memory counts for prevalence, not drift) all hit the same wall: the operator's machine-local memory folder is flat files with no revision record. The fact log is the fix, and the memory directory should be the first corpus it ingests.
- **Real concurrency is rare today.** 2/70 real merges touched one goals file on both sides. S14's rates are upper bounds built by replaying sequential history as concurrent. The sequencer plus held conflicts is sized for a problem that is mostly future.
- **Retrieval queries here lean on exact terms.** BM25 ties the tuned convex fusion; dense retrieval alone is weak. Treat this as "do not assume RRF or dense-first" for an agent-memory corpus of paths, symbols and status lines.
- **One labeller everywhere.** Every lane authored its own fixtures and labels. The bounds are honest about n; they are not honest about labeller agreement, because there is none to report.
- **Cross-encoder cost:** 3.4 s p50 per query on 20 CPU threads for a 50-candidate pool. ONNX or a GPU changes this; the arm ordering does not.

Not licensed: any CRDT on agent paths (S14), a relevance stage (S7), counts in rank (S9), hash-as-stale (S35), the 120 number (S5), a sub-5% held-write target for free-text agent writes (S14b).

> ## 2026-11-08: Agent memory Layer 2 is a fact log with projections; no CRDT on agent write paths
>
> **Context:** Three deep-research reports (ChatGPT 6 Pro, Opus 5.5 xhigh, Grok 4.7 xhigh) on the agent-memory packet were reconciled on 2026-11-08 and validated the same day by nine spikes in a throwaway repo over real corpora (beep-effect `goals/**` history, `the operator's Claude auto-memory folder`, 20 transcripts). Raw-slice projection held byte identity in 5168/5168 replays. Per-node CAS held every contested node with zero silent loss, while Loro corrupted 48 of 70. Prevalence counts in rank cost 53 points of update adoption. A separate relevance stage added nothing over cross-encoder plus admissibility gate. A normalized span hash was 84.5% false as a staleness verdict.
>
> **Decision:** Layer 2, when built, is a set-union log of immutable node events as the sole authority. Markdown files, CRDT documents and every index are projections. Agent writes enter through store-side admission (per-node CAS at row granularity, held conflicts, per-op admission), never through hooks and never through a CRDT merge. Retrieval is BM25-leaning fusion, cross-encoder, admissibility gate with typed findings. Prevalence is an observation log and never a ranking feature. Near-duplicate filters flag only. Symbol hashes mark re-verification, not staleness. This refines the 2026-04-15 "Semantic Memory = Managed Cache" entry (the log is the source, indexes are the cache) and keeps the 2026-08-29 entry (file memory remains the memory layer; the log projects to it).
>
> **Reversal:** the log is append-only and its projections are rebuildable, so reversal is deleting the projector and keeping the files; the spikes repo records the measurements that would have to change first.
