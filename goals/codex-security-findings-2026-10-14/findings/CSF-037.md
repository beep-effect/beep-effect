# CSF-037: Checkout\-root swaps bypass residue\-reap containment

- Severity: Informational
- Codex ID: `commit:9e43e8b231a081918d76574437a153ad`
- Source commit: `6d85719b0c74ba2e9cc944358f5ccada89a87e85`
- Owner: Repository residue cleanup
- Status: confirmed; repair implemented

## Public Summary

Residue cleanup re-resolved a checkout root after discovery. If that root changed to a symlink between planning and application, the new real path could become the containment boundary for a candidate discovered under the old root.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. Current HEAD obtains the outer boundary during application from a mutable checkout path. The regression replaces the path with a symlink after the first probe and confirms the replacement is refused.

## Remediation

Resolve and freeze each checkout root boundary in settings before discovery; use only the frozen boundary for candidate application.

- `packages/tooling/tool/cli/test/residue-reap.test.ts`
