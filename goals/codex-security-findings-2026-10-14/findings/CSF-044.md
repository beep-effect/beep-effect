# CSF-044: Unvalidated Fallow sidecars can block the tmpfs janitor

- Severity: Informational
- Codex ID: `commit:f112c76569fc81919044a36b92133681`
- Source commit: `649129464573c7a9a1182be755267cc14fdc0bc9`
- Owner: Tmpfs Fallow cache janitor
- Status: confirmed; repair implemented

## Public Summary

A Fallow cache sidecar could be a FIFO, symlink, or oversized file. Reading it with an unrestricted string read could block the janitor or follow a link outside the cache.

## Current-HEAD Validation

Verdict: confirmed at current HEAD. The current discovery path read every matching .last-used sidecar before age and process checks. A FIFO without a writer could wait indefinitely.

## Remediation

Open sidecars without following the final symlink and with nonblocking flags, accept only regular files, and cap reads at 4096 bytes. A focused test covers FIFO, symlink, and oversized inputs.

- `packages/tooling/tool/cli/src/internal/repo-run/TmpfsReap.ts`
- `packages/tooling/tool/cli/test/tmpfs-reap.test.ts`
