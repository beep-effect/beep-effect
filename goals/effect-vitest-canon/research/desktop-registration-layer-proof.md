# Sidecar registration uses public layer boundaries

The contradiction registration suite now provides BunCrypto through public
it.layer instead of six per-body provider calls. The installed adapter aliases
the Node-compatible crypto implementation. It does not hold the per-case
source text, captures, repository, or handlers; those remain local. Its explicit
hook budget preserves the shared ten-second normal/five-minute coverage and
deep-sweep policy. The remaining dynamic contradiction handlers are a separate
review obligation and are not claimed closed here.

The ontology registration case now builds its effectful handlers in a one-test
public layer fixture. The fixture retains the original session, RDF dataset,
validation result, provenance paths, and stub behavior. A test-only Context
service exposes those inputs and read-only accessors for the original invocation
counters. The RPC client is still acquired inside the test scope, and the test
requires exactly one validation invocation and one export invocation.

All seven original cases passed under Node and Bun. AST comparison preserved
all seven test titles and 67 assertion call expressions after normalizing only
the two counter reads through their fixture accessors. The count includes nested
expect calls; this is preservation evidence, not a coverage metric.

Final package verification passed its audit and docgen stages. The final Node
and Bun runs each passed all seven cases. The strict packet validator retained
5,001 unique baseline identities and 15,249 unique ledger identities. The two
schema-first registration exceptions were reanchored by one line with their
existing statuses and reasons preserved; no exception was added by this batch.
