# Editor resource and property proof

The code-fence helper keeps synchronous Lexical dispatch semantics. Nested
finally blocks own command registration, atom mount and registry disposal in
reverse acquisition order. A private injected dispatch failure leaves all three
owners unreleased in the original helper; the corrected helper releases them in
order. The instrumentation preserves the dispose method receiver. The normal
code-fence examples remain unchanged in meaning.

Two capability schema laws, four grouped chat codec laws and the real Lexical
state-admission law now use native Effect Vitest properties. Each retains its
original schema generator and equality/acceptance predicate. Capability and
Lexical floors remain 25; the chat floor is 100, matching checkEffect's default.
fcRuns allows the configured larger run count and replay seed. A Lexical editor
is created for each generated state, so evaluations do not share mutable state.
Independently inverted predicates fail all seven laws with native replay seed
20260708 and shrunk inputs. No production schema is narrowed.

A new generated typeahead law uses nonnegative indices and constructive positive
offsets, checking four distinct IDs across two composers, repeated-call stability
and nonempty whitespace-free IDs. Original fixed examples remain.

Error diagnostics now name the identifiers required to act on each of eight
error variants. Projection tests require nonempty outputs and the complete
ordered command set for each declared surface. The keyboard test selects actual
DOM text, requires an emitted serialized state with bold set and underline
absent, and retains both preventDefault assertions. The remount case retains its
codec round-trip oracle and additionally unmounts and remounts a real composer,
checking the heading and textbox content.

Private controls compare original and strengthened tests: missing state emission,
suppressed bold, ignored runtime initial state, empty toolbar/slash projections,
and generic text for three formerly unchecked error variants. All eight changes
pass the original oracle and fail the corrected oracle. The positive corrected
projection/runtime/ID suite passes twelve tests. The first projection attempt
used an obsolete filterMap contract and an incorrect surface token; its failed
run and preliminary mutation controls are diagnostic receipts only. Final controls
use the declared slash-menu surface and explicit filter/map.

Mermaid render/DOM polling and the keyboard selection test use it.live. Their
subjects depend on native jsdom scheduling and React act/waitFor; no browser timer
is frozen or test deadline extended. The direct vi import remains for Vitest's
module-mock hoisting; other peer exports use Effect Vitest and all nineteen test
files register through the instrumented runner.

AST conservation preserves 272 original assertions and 93 static registrations.
Six checkEffect Passed-status wrappers are replaced by native assertion failures;
those wrappers previously covered seven runtime laws because one helper was used
twice. Ninety-four Boolean/Option assertions use public helpers without changing
operands or polarity. These receipts establish headless Lexical/jsdom behavior,
not visual browser acceptance. Temporary test and production control mutations
were restored byte-for-byte.
