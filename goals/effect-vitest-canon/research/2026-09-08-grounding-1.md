| Call | Binding | File:lines | FastCheck runner | Schema input |

There is no options key named `arbitrary` on either overload (**verified**: `fastCheck` at `index.ts` L87 and L132; runtime `timeout?.fastCheck` at `internal.ts` L145, L168, L189, L208). Local identifiers named `arbitrary` are loop variables only.

### 6.2 Options object — verified

Shared type (`index.ts` L84–93 and L129–137):

```ts
timeout?: number | V.TestOptions & {
  fastCheck?: FC.Parameters<{ ...decoded arb types... }>
}
```

Runtime (`internal.ts`): `isObject(timeout) ? timeout?.fastCheck : {}`. If the fourth argument is a **number**, FastCheck gets `{}` (library defaults). If it is an object, `fastCheck` is forwarded to `fc.assert`.

`testOptions(timeout)` (`internal.ts` L52) also forwards that same object to vitest as `TestOptions`. **Inference:** vitest ignores unknown keys such as `fastCheck`; not executed in this lane.

### 6.3 `FC.Parameters` fields

`effect/testing/FastCheck` at the tag is a full re-export (`packages/effect/src/testing/FastCheck.ts` L90: `export * from "fast-check"`). Examples in that file (L38, L58, L85) pass `{ seed, numRuns }` to `FastCheck.assert`.
