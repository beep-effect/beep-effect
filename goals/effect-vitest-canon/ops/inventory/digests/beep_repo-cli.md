# @beep/repo-cli four-lens source audit

All 249 census files are reviewed: 192 tests and 57 support or declaration files.
Thirteen disjoint chunks cover all 996 file/lens pairs. The inventory contains
103 open review proposals (51 major and 52 minor) and 893 file-specific
no-findings rows. Review proposals include preservation constraints and coordinated
views of the same issue; they are not a count of independently reproduced defects.
Mechanical detector candidates remain open and separate from human review.

## Scope and native boundaries

Pure schemas, parsers, planners and command fixtures coexist with native Git,
filesystem, compiler-discovery, process and locking tests. Preserve Git objects,
index/stash/ref behavior, archive bytes, symlinks, permission denial, procfs identity,
open descriptors, flock, subprocess stream draining and actual compiler/Turbo
subjects. MemoryFileSystem is not a blanket replacement for these contracts.
Provider stubs and local bare origins do not establish external provider execution.

Several fixtures allocate native roots before release ownership, remove them only
after successful assertions, or discard cleanup failures. Own roots before fallible
setup and bracket cwd/global mutation separately. Preserve explicit early closes,
shorter child scopes, process termination joins and correctly scoped fixtures.
Current CLI configuration serializes files and cases. This limits interference but
does not repair an acquisition failure before finalizer registration.

D14 layer migration must keep mutable console buffers, configuration, scripted
responses, cursor state and native roots independent. Shared stateless services may
be considered where their actual lifetime permits it. Repeated Git setup, native
process startup and compiler discovery are visible in source; retained package
elapsed time does not isolate their cost or establish a speedup.

## Review priorities

The assertion findings require evidence for the intended behavior. Examples include
Corpus mutation verdicts that are discarded, vacuous every/Option branches,
permissive child-command stubs, a tee assertion that observes only captured output,
and codec laws that compare only a subset of generated fields. Preserve every
existing assertion and add the missing positive or negative witness. Do not treat
all generated mutations as invalid or replace normalization-aware idempotence with
an incorrect raw-identity law.

Synchronization proposals preserve real native subjects. OS spawn does not prove
that a child opened a descriptor or acquired flock. A sleeping negative lock check
does not prove a contender reached acquisition. Recording a failed poll invocation
does not prove its failure budget was processed. Observe the corresponding event
before checking the outcome, without increasing timeouts or adding test retries.
Controlled TestClock timeout subjects remain distinct from external process time.

The inspector coverage filter/recovery behavior needs explicit instrumentation
review before any change. Keep original evidence and do not silently remove or
waive instrumentation. Ambient journal reads and a global hostile-payload sentinel
need owned deterministic inputs; do not delete or filter unrelated live data.

Native property generation, shrinking, seed controls and existing run floors remain
part of the contract. Exhausted is not Passed or falsification. Preserve complete
failure/replay diagnostics and schema domains. Git setup errors should retain
bounded sanitized argv, exit and stderr where the fixture already captures them.
