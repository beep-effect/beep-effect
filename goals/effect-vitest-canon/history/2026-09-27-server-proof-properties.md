# Server and proof native properties

Three properties now use native registrations with named arbitrary inputs.
The six-schema server parity group remains one test with 25 runs per schema
and the original Equal-or-schema-equivalence law. The scanner retains its
synthetic block shapes, troublesome Unicode/escapes, 0–5 block count, 0–2000
cuts, maximum 30 cuts, 200-run floor, exact element/order equality and the
single-character control. The proof result keeps its Equal.equals law and
20-run floor. Total test budgets are unchanged.

The scanner now uses the installed fromJsonString(Unknown) codec at its JSON
boundary; no schema restricting scanner input replaces the original arbitraries.
The production scanner is untouched. Both packages pass audit and docgen.
