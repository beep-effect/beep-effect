GovInfo now registers one native property over the same 17 schema-derived
inputs. Each input runs in every trial; custom arbitrary mappings and filters,
round-trip equivalence, the 25-run floor, original registration count and case
deadline are preserved. The obsolete manual check helper is removed. An exact
inverse-edit proof bounds the change to that migration and the cache witness.

The cache case now compares both responses with an independently decoded
nonempty fixture. It retains the exact one-transport-request assertion. Separate
controlled first-response and cached-response count mutations fail the expected
case, proving both output witnesses. A controlled property-oracle inversion
fails with named shrunk inputs and the original replay seed. All probe mutations
are restored byte-for-byte and are not committed.

The configured GovInfo suites pass all eight cases on Node and Bun. Single
whole-command observations are 3.771182 and 1.817455 seconds respectively, with
load/pressure and stable source hashes retained. Full package audit (9.4 seconds)
and docgen (3.4 seconds) pass. The one GovInfo registration and both existing
eCFR registrations pass a 400-run floor with seed 20260708; the eCFR property
implementation is unchanged. Skipped unrelated cases in these filtered runs
are covered by the earlier full-suite observations, not counted as deep passes.
