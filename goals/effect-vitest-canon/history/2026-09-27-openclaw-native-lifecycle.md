# OpenClaw native lifecycle and current renderer boundary

Six renderer registrations now use it.effect or it.effect.prop under a named
Crypto fixture supplying the same real NodeCrypto implementation. Every original
golden JSON, pinned hash, determinism and secret-reference assertion remains;
the property retains its exact intent arbitrary and twenty-five-run floor.

The binary acceptance fixture intentionally excludes deterministic test services:
real child-process deadlines must advance with the live clock. The ten-minute
acquisition budget and existing 120/240-second body budgets remain unchanged.
Temporary workbenches remain scoped; staging caches remain persistent.

A native timeout witness invokes the actual CLI wrapper against an executable
shell fixture that records SIGTERM and continues running. The test observes the
typed ten-second version timeout, exact executable/subcommand, handled signal,
stopped process, and removal of the scoped native workbench. The twenty-second
outer test budget is distinct from the driver deadline and escalation grace.
No wall-time performance threshold substitutes for those terminal observations.

Restoring deterministic TestClock to this witness makes it fail at the outer
timeout, demonstrating why native live-clock ownership is required. The private
control restores the source bytes. The full package audit and docgen pass.
