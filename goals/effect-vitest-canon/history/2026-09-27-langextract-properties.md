# Langextract native properties and independent witnesses

Five manual checks now use named native property registrations. Preserve every
existing arbitrary, the four fifty-run floors and the persisted-failure twenty-
five-run floor. Conditional aligned-span assertions remain conditional; ambiguous
text is not forced to align. The two wire formats still encode and parse in the
same order and compare independently with the original candidate equivalence.

The cap property retains both upper bounds and adds exact minimum length plus
candidate-field prefix ordering. The policy-denial fixture counts actual stub
model generation and requires zero calls while preserving the original request
and typed denial. A separate allowed fixture proves the same recorder observes
one generation call; its counter begins at zero and the empty response is checked.

Three paired controls regress behavior only in the test: always-empty alignment,
reversed output, and one real stub-model call before policy denial. The strengthened
oracles fail each control while the original weaker checks pass. Four additional
property controls invert the aligned bound, wire codec equivalence, persisted-
failure equivalence or range equivalence; each fails one registered property.
All ten runs restore exact source bytes. Full package audit and docgen pass.
