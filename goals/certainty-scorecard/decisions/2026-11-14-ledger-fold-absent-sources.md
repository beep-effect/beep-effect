MEAS-05 slice 2 (PLAN slice 15). `beep ci ledger` (`packages/tooling/tool/cli/src/commands/Ci/CostLedger.ts`, schemas in `CostLedger.schemas.ts`) folds named workflow runs into rows at (lane, partition) grain. It reads `--run <id>` live (the run, its jobs attempt by attempt with the 30-job page fallback, and two job logs) or replays a `--capture` file, and nothing in proof authorization reads it.

- Grain and joins. Each job is attributed by the route census's `hostedJobAttribution` over the slice-14 lane map. A lane job joins the row of its lane and the partition from its name or its caller's (`ciJobPartition`, new in `CiLaneJobs.ts`); a reporting or aggregate job is the lane's `lane` row. Support and unknown jobs add to those minutes. Lane, support and unknown minutes sum to the run's total.
- No double count. A rerun attempt's copy of a job it did not re-execute (same name and timestamps as an earlier attempt) is dropped. A skipped job costs nothing and is counted apart. A caller with no runner whose `<caller> / <job>` jobs are listed is a wrapper: its wall time is reported apart and never added to the called jobs. An umbrella aggregate that ran is its own `lane` row beside its partitions; on the three reference runs every aggregate skipped on success.
- Mapped. A job-minute is mapped when it joins a lane or a named support job, the class ROUT-05 calls an explicit non-lane class; unknown minutes are the unmapped ones. The lane-only share is reported beside it, because the documentation-only run spends most of its 7.1 minutes in Change Profile, Test Plan and PR Size Label (lane share 78.2%).
- Empty legs. Every Test Unit and Test Integration partition row gets `selected`, `empty` or `undetermined`. A partition's own selection line (`[ci] <lane> partition union proved: ..., <p> in <partition>.`) wins. Otherwise the run's Test Plan output decides: a lane plan that selected no task makes every leg it allocated empty, and a sharded partition the plan allocated had selected packages. The catch-all `int-rest`, allocated whatever the selection, needs its own line, so the live reader reads the latest executed Test Plan job's log and the catch-all job's log. `emptyLegMs` is absent while any leg is undetermined.
- Absent sources. `turbo-tasks` (MEAS-06), `final-check` (MEAS-07 journals), `economics` (local Yeet attempt lanes) and `psi` (MEAS-08) are `absent` rows with the reason; `hosted-jobs` and `test-plan` are judged over every part they cover, summed across the runs: `hosted-jobs` over each run's attempts, `test-plan` over each run's Test Plan output and the selection line of each catch-all job it executed. A log read that fails leaves its part unread rather than absent from the count, so a push run whose `int-rest` line could not be read makes `test-plan` partial, the leg `undetermined` and `emptyLegMs` empty, and the row's note names each missing part.
- Asymmetric digests. A row carries `hostedDigest` and `localDigest` as separate optional fields with no equality; the hosted fold sets neither, so the ledger cannot read as parity evidence.

Reference runs, read 2026-11-14 and committed as `packages/tooling/tool/cli/test/fixtures/ci-cost-ledger/reference-runs.json` (steps and runner names dropped): Check 43604442987 (push to main, every partition allocated: 307.1 job-minutes, 100% mapped, 99.4% lane, empty legs 0), 43585338714 (documentation-only pull request: 7.1 min, 100% mapped, 78.2% lane, no partition allocated, empty legs 0) and 43605277972 (pull request whose plan allocated `int-rest` with 0 of 24 integration tasks selected: 203.7 min, 100% mapped, 98.2% lane, one empty leg of 1.97 min). The SPEC names no run ids. The exploration's three (42637312401, 42646019844, 42656046751, all created 2026-11-09 before #3043 merged) predate the 24-job Test Unit layout, so three current runs that cover a full matrix, a documentation-only head and an empty partition were read instead.
