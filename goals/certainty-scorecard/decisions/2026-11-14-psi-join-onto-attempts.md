MEAS-08 (PLAN slice 16). `yeet economics` joins two pressure sources that already exist onto each attempt, in a new `pressure` section of the `yeet-economics/v4` report (additive, as the slice-8 rule allows). Nothing new is sampled, stamped or written on any path; the join only reads.

- Sources. The PSI recorder (`$HOME/.local/state/beep-psi/safe-pressure.jsonl`, appended about every 30 s by `beep-psi-sample.timer`, kept about 14 days), the source the exploration's MEAS-08 lever names (`explorations/ten-minute-certainty/research/phase2/merged/measurement.md`), and the SCHE-09 slice 2 stamps on admitted and v3 released rows of the admission history (archive segments plus the live journal). The live reader is `YeetPressureSource` in `packages/tooling/tool/cli/src/commands/Yeet/internal/EconomicsPressure.ts`, schemas in `EconomicsPressure.schemas.ts`; it reads the history through `readAdmissionJournalHistory` under the per-user admission root without creating a directory, and never fails.
- Keys. Recorder samples join by time: a sample belongs to an attempt when its instant lies between the attempt's start and end, both included. Each window reports its sample count, distinct boot ids, mean and max of cpu, memory and io `some avg10`, and minimum MemAvailable; a figure is present only when every sample in the window carries it. Stamps join by attempt id (admitted and released rows carry the yeet attempt id), grouped into leases by nonce; each lease has an admitted and a released stamp, joined or absent.
- Absence. Every joined field is `joined` or `absent` with a reason: `remote-host` (a fleet-host journal, or a start row naming another host), `source-unread`, `untimed`, `outside-recorder` (no sample and the window lies outside the recorder's span), `no-samples` (inside the span, but shorter than the tick or in a recorder gap), `no-admission-row`, and per lease `no-row` or `unstamped` (pressure gate off, an older writer, a v1 released row or an unrecognised stamp). No value is interpolated or taken from a neighbouring sample.
- Source rows. `psi-recorder` and `admission-journal` rows use the cost ledger's rule, now shared as `ciLedgerSourceStatus` in `CostLedger.schemas.ts`: `present` only when every part the note names was read, `partial` when some was not (the note names how many), `absent` when nothing was. The recorder's parts are its lines, the journal's its distinct rows; a line or row that does not decode is an unread part, and the attempt journal's torn-tail rule exempts an append still in flight. Each row also counts the attempts joined and the absent ones by reason, summing to every attempt in the report.
- Fleet hosts. A fleet host's attempts count as `remote-host` in the source rows and are never listed per attempt: PERIL-11 slice 3 lets only aggregates leave the fleet-host fold, which its leak test holds.
- Closeout summary. `printYeetEconomicsCloseoutSummary` reads no pressure source, so the hot closeout path gains no read; its report carries the default section (both sources `absent`, "not read on this path").
- Ledger `psi` row. It stays `absent`, with a new note: the recorder samples this workstation, and hosted jobs run on runners it never samples, so joining it onto ledger rows would report another machine's pressure. SPEC's MEAS-08 row says "onto attempts"; the slice-15 checkpoint's closing line ("MEAS-08 can now join pressure samples onto ledger rows") is superseded, since SPEC wins. The ledger's `economics` source (local Yeet attempt lanes) is still absent, so there is no local ledger row for PSI to join.

Evidence: `packages/tooling/tool/cli/test/yeet-economics-pressure.test.ts` (fixtures only; the live reader runs over an in-memory filesystem with a test runtime root) covers every gap reason, the every-sample rule, the lease grouping, each read status and its note, the torn tail, the remote exclusion and the command wiring, on Node and Bun.

Rejected: joining PSI onto ledger rows (wrong machine); taking the nearest sample for a window with none (an invented value); a figure averaged over only the samples that carry it (a summary over some, the 5b `unadmittedSliceGib` rule); listing fleet-host attempts with their ids (breaks the PERIL-11 aggregates-only rule); reading the recorder in the closeout summary (a new read on the closeout path); joining PSI windows onto admission lease spans as well (the 5b stamps already record pressure at admit and release; a later slice can add it).
