# Reflection — document-ast-pattern-classification (2026-10-05, claude)

## Summary

Shipped the `po` Pattern Ontology annotation as a `@beep/schema/PatternOntology`
LiteralKit plus Effect schema annotation key, stamped it on all 91 tagged
constructors across Md (31), Pandoc (44), and Lexical (16), and proved the
conservation law over the live codecs with property tests that read patterns
from the annotations only. The derived correspondence report is regenerated from
the same annotations and codecs. No sidecar table and no second issue channel
were needed; every Pandoc demotion is already explicit through
`PandocMappingIssue`, and every Lexical demotion is in the locked README profile.

## Tooling experience

- **Worked:** `graft skeleton` for the three 3,000-plus-line model files;
  `S.toTaggedUnion(...).cases` as the iteration surface for per-constructor
  property tests; `Arbitrary.sampleEffect` for a fast probe before writing the
  law into tests; `biome format --write` after a scripted annotation stamp.
- **Didn't:** the `.repos/effect` reference drifted from the installed 4.0.0
  snapshot on four APIs; the fresh lane had no dependency dists, so the first
  `bun run check` reported unrelated red until a filtered `turbo build` ran.
- **Frustrating:** the `zsh -ic` wrapper prints gitstatus and zle noise on every
  tool call, and a bare `===` in a shell echo is a zsh path expansion.
- **Wished existed:** a one-command "annotate every constructor matching a
  table" codemod; the Python stamp worked but is not reusable.

## Implementation improvement opportunities

- A typed Lexical demotion record (see findings) would make both codecs share
  the same mechanical law.
- The walker records a class once per identifier, tag, and pattern triple
  because type-only projections clone ASTs; a stable AST identity for class
  declarations across `S.toType` would remove that dedupe.
- `QuoteNode` is the one multi-pattern constructor (legacy inline quote versus
  shadow-root container). Instance-level refinement is a natural follow-up.

## Goal & prompt critique

- The GOAL's "Inventory the live unions in P0" undersold the work: five Md
  classes and six Pandoc metadata structs live outside the unions, and only the
  AST walk over the root schema catches them. Say "every tagged constructor
  reachable from the root schema".
- Name the lossless re-realization class next to preserved and demoted so the
  tests do not look like they carry an escape hatch.

## TODOs worth codifying

- Test-utils helper for annotation exhaustiveness over tagged constructors.
- Lexical codec demotion record.

## Lessons (confidence-tiered)

- **HIGH — Critical:** check the installed `effect/dist` typings before using a
  SchemaAST or collection API — the reference checkout runs ahead of the pinned
  snapshot and the gap costs a round-trip per API.
- **MEDIUM — Best practice:** probe a conservation law with sampled arbitraries
  and print the demotion set before encoding it in property tests — the probe
  surfaced the four re-realizations in one run.
- **LOW — Consideration:** exact-path issue matching, not prefix matching, is the
  honest evidence for a construct's own demotion; prefix matching let child
  issues justify the image alt-text transition until it was tightened.
