# Reflection — todox-marketing-site (2026-09-11, claude)

## Summary

Two builds in one day. The Terminal of Record homepage shipped locally in `apps/todox` through P0–P2: schema-first session model, seven passages with verbatim claim-gated copy, self-hosted OFL faces, an auditable direction contract, six recorded QA rounds (final judge `requiredCount: 0`), two finish-review passes, and an authored social card with embedded provenance. Benjamin then rejected that direction on sight and pinned a standard product site in his own palette (Evergreen Ledger) with the Notion positioning; the redesign was rebuilt the same evening, reviewed to ship, and re-judged at zero required findings. P3 publication remains gated on Benjamin's explicit go, so this is an on-demand reflection rather than a closeout.

## Tooling experience

- **Worked:** `beep qa record/extract/judge-pack/judge-ingest` with the Codex vision judge; the beacon clock correlated at ~11 ms residual every round and the judge's R4-01 focus finding was real and reproducible. The Impeccable finish reviewer's recapture-then-fix protocol produced concrete file:line fixes. `LiteralKit` + `S.Class` made the state vocabulary and receipt fields impossible to get wrong by construction. `embed-prompt.mjs --scan` as a provenance gate.
- **Didn't:** the in-app Browser pane could not screenshot reliably at emulated 1440×1000 (timeouts), so inspection captures moved to a scratch Playwright script. `next/font` was avoided because it would need mocking under vitest; plain `@font-face` with `public/fonts` was simpler and self-hosted anyway.
- **Frustrating:** the harness/session directory split (screenshots beside the app, session at repo root); vitest's per-file concurrency masquerading as duplicate DOM; `.next/dev/types` polluting `bun run check` while the dev server runs; portless answering the http name with a 302 to https, which the Browser pane refused until navigated to https directly.
- **Wished existed:** a `beep qa` scenario library for the surface-independent checks; a way to emulate `prefers-reduced-motion` in the Browser pane.

## Implementation improvement opportunities

- The status row at 360px is still four lines (99px). A narrower clock format on mobile (drop the year) would bring it to three without touching the required label.
- The packet's QST records are authored; if the fixture grows a questions output, replace them with fixture-verbatim content and drop the authored provenance flag.
- The OG raster is 2400×1260 (2×). If bytes matter, downscale to 1200×630 and re-embed the provenance chunk.

## Goal & prompt critique

- Replace "Stop and report before adding dependencies" in GOAL.md with an explicit allowlist: "may add the `apps/oip-web` dependency set (`effect`, `@beep/schema`, `@beep/identity`, `@effect/atom-react`) without asking". The launcher and the repo laws it defers to disagreed.
- DEMO-SCRIPT should quote fixture strings by file and key (`input.email.json#subject`) instead of restating them; two of its restatements were wrong and SPEC's "fixture wins" rule had to arbitrate.
- Name the evidence paths the finish reviewer will receive in PLAN.md's P2 row so the reviewer brief and the harness agree before the first pass.

## TODOs worth codifying

- `beep qa` scenario library (overflow-360, reduced-motion-at-load, no-JS static, sticky-header focus visibility).
- Shared round directory or printed harness output path in `qa record`.
- Container-query row layouts as the design-system pattern for record tables.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Record real keyboard input at human cadence before calling a keyboard-first surface done — the only P1 of the build (focus offscreen under smooth scroll) was invisible to unit tests, the detector, and static screenshots.
- **HIGH — Critical:** Scope testing-library queries to the render's container whenever the shared vitest config runs tests concurrently; `screen` queries are cross-test in this repo.
- **MEDIUM — Best practice:** Let the reviewer's first pass be a recapture pass: give it a capture set that already includes every passage at desktop, the focused CTA measured after focus lands, and reduced motion captured at load.
- **MEDIUM — Best practice:** Write the direction contract to a 150-word budget with a test that counts it; the first draft was 181 words and the test caught it before the build did.
- **LOW — Consideration:** A 2× social card renders crisply on every network preview seen so far; only revisit its size if a preview service rejects the byte count.
