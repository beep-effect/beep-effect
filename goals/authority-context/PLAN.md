## P1 Work Breakdown

In order. Each step lands through Yeet; the packet has at most three open pull requests.

1. Kernel: the `Invocation` and provenance schemas and the grant-check language, with stories for what "covers" means.
2. Contract and model: grants, delegation, the Accountability relation, admission and re-admission, proven by stories on `Domain.InMemory`. This may start once the doctrine pull request of `model-first-standard` merges.
3. Host: the Session boundary, stores and adapters, generated by the scaffolder's host shell.
4. The test consumer model and its declared port; the root-construction scan and the proof inventory entries.
5. Cluster: the descriptors, the entry module and the revocation case on the swarm, once `effect-cluster-host` passes conformance.

## Closeout Checklist

Before marking the packet closed:

1. Write a closeout reflection via the `/reflect` skill to
   `history/reflections/<YYYY-MM-DD>-<agent>.md`. Its YAML frontmatter must
   validate against `ReflectionFrontmatter`.
2. Run `bun run beep lint reflection-artifacts`.
3. Update `README.md` (status, latest evidence) and `ops/manifest.json` phase
   statuses. Once the final PR is open, run
   `bun run beep goals set-status authority-context completed-retained`: it writes
   `closeout` naming that PR with the matching `initiative.status`, and the
   commit ships in the final PR. After the merge,
   `bun run beep goals completion refresh --slug authority-context` must print verified;
   name any red required check in a committed decision file
   (`redAttribution`).
