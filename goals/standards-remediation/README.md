## Headline finding

In merge-conflict resolution, never use `git checkout --ours/--theirs <file>` to keep one side of a *hunk*; it replaces the WHOLE file with that side and silently discards the other side's auto-merged, non-conflicting changes. Use `git checkout -m -- <file>` to restore three-way markers, then resolve hunk-by-hunk (or a perl keep-ours pass scoped to the conflict blocks).
