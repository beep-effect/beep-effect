# Reflection — schema-utils-selective-codec-statics (2026-10-05, claude)

## Summary

The goal shipped what it set out to ship. PR #927 replaced the broad
`SchemaUtils` codec-static bundles with an exact `withCodecStatics(keys)`
selector and a frozen `classStatics` bag, migrated every consumer to its
audited minimal tuple (726 attachments down to 213 explicit selections),
deleted all six bundle variants, and recorded the 2,931-finding inline-compiler
baseline that `inline-schema-compile-hard-error` later reconciled to zero.
The packet then failed its own closeout: nobody flipped the lifecycle, and the
artefact was retired by `effect-schema-parity` P5 (#1371) a month later. This
closeout is the missing docs step; there is no live surface left to maintain.

## Tooling experience

- **Worked:** the typechecker-backed inventory and disposable codemod gave an
  auditable minimal-key map; the per-family no-growth baselines kept the
  migration reviewable; `bun run beep quality package-verify @beep/schema`
  and the cheap-gates tier caught the collision case that broke the
  architecture preflight.
- **Did not:** the admission scheduler did not admit the final full proof
  before publication, so the PR was published manually with hosted checks as
  the proof; the coverage parent detached before aggregating and the whole
  run had to repeat attached.
- **Frustrating:** `goals doctor` called a day-old untracked packet stale and
  then had nothing to say when the packet was truly stale; interrupted
  package verification left orphan compilers driving load above 500.
- **Wished existed:** a merged-PR-aware packet doctor, and a resumable
  coverage aggregate that consumes shard receipts.

## Implementation improvement opportunities

- The keyed selector was the safe intermediate, not the destination. #1371
  proved that free `effect/Schema` functions at the read site plus the
  `SFV4-codec-static` rule remove the facade class entirely, with no per-call
  codec rebuild. A future "narrow a broad helper" goal should ask first
  whether the helper is needed at all once a lint rule forbids the facade.
- Generators defaulting to no statics with per-schema overrides was the right
  call: #1371 found the box and runpod override maps always empty and deleted
  the option without a single consumer change.

## Goal and prompt critique

- `GOAL.md` step 9 ("Close with `/reflect` and synchronized packet state")
  was last and unordered relative to the PR. It should say the reflection and
  lifecycle flip land in the implementation PR, before `publish`.
- The acceptance list carried two unchecked boxes that only hosted CI could
  tick. A launcher should name the command that proves them so a resuming
  session can verify instead of inferring from PR state.

## TODOs worth codifying

- `beep goals doctor`: merged-PR-while-active rule.
- `yeet sweep`: active-packet advisory on merged branches.
- Schema-first skill: "retire the facade, do not select it" guidance.

## Lessons

- **HIGH — Critical:** flip packet state in the shipping PR. Evidence: this
  packet and `inline-schema-compile-hard-error` both needed follow-up docs
  PRs, and this one sat open across its own retirement.
- **MEDIUM — Best practice:** when a proof lane is skipped or substituted at
  publish time, write the receipt into the packet, not only the PR body.
  Evidence: `history/2026-08-30-local-verification.md` omitted the
  non-admission that the #927 body disclosed.
- **LOW — Consideration:** a selector that narrows a footgun is worth shipping
  even when a later goal removes the footgun; the migration inventory from
  #927 (213 explicit selections, zero unresolved owners) was the census #1371
  built its codemod on.
