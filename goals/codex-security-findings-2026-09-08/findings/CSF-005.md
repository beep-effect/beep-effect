# CSF-005: Newline worktree paths can make reap delete an unregistered repo

- Severity: Informational
- Codex ID: `6f691d6083348191827f0299697d5e13`
- Source commit: `73c38916a50c454f4ffaa031a74a39904591ce2e`
- Owner: Worktree registration and deletion
- Status: implemented; repository proof and post-merge closure pending

## Public Summary

Line-delimited Git porcelain could treat a newline in a real worktree path as an additional registered target. Removal trusted the parsed path.

## Current-HEAD Validation

Confirmed in the current main baseline `be8995e66a`. Disposition: `remediate`.
No accepted-risk or false-positive dismissal is used.

## Remediation

Request NUL-delimited porcelain everywhere, reject control-bearing paths, and require an exact managed-root registration and matching Git common directory immediately before mutation.
