# Integrated parity feedback

This is an implementation reflection, not a closeout or a change to the goal.
The engine remains incompletely qualified. Earlier linked PRs retain their
implementation and provenance; PR #2847 carries the current assembly and repairs.

The engine's citation behavior comes from the pinned official eyecite source,
source-observed expectations and independently recorded original tests. The two
TypeScript ports are differential and extension references. Effect supplies the
service, concurrency, transaction and RPC primitives; repository contracts own
verified spans, semantic schemas and public boundaries. This is not an algorithm
invented without upstream reference. Exact pins and incorporation rules remain
in research/SOURCES.md.

The main sequencing mistake was allowing extensive component probes and proof
accounting to precede broad original-input replay through the assembled engine.
The integrated replay found a concrete defect: original missing-page model groups
must become None while raw matched text and verified ranges retain underscores.
That defect was observable in legal results and is now repaired with six passing
Bun/Node regressions. More isolated observations would not have substituted for
this integration check.

The cross-lane audit also identified a different failure class: stale test inputs
and boundary assumptions. Required tokenizer counters and HTML startup schemas
must be exercised as declared. Source cleaner failure categories must remain
asserted without exposing those private categories through public errors. Tests
now retain both obligations at their respective boundaries. Neither weakening
the production schemas nor removing meaningful assertions was necessary.

The historical Bun callback timeout remains unexplained. The diagnostic replay
passes at the unchanged limit but Bun markup takes about 90 seconds versus about
16 seconds on Node. That is evidence of limited margin, not proof of a root cause.
The next hosted execution must retain synthetic row identities and physical
child-exit counters. A successful rerun alone must not close the issue.

Exhaustive observable compatibility is more expensive than equivalent citation
results: retained callbacks, native string fidelity, mutation, identity and
alternative paths all carry distinct obligations. This reflection does not waive
those duties or reinterpret a high pending-row count as a defect count. The next
implementation work should follow demonstrated integrated failures and reuse
existing upstream algorithms and Effect facilities. Accounting closes only after
applicable execution and proof are available.

A subsequent isolated check covers original canonical inputs 122, 123 and 129
through the default public engine on both runtimes. These are the original
split-emphasis names, Grant/Esquire markup and split reporter/pagination cases.
All six pass; observed per-test times including fixture installation range from
28.52 to 47.87 seconds. The exact original components, metadata, attribute operands,
verified primary/full/pin-inclusive ranges and child retirement assertions remain.
The historical ten-input group deadline is not explained by these passing isolated
checks. The focused regressions preserve the existing canonical test and engine
limits and do not qualify the full 193-input replay or close accounting rows.
