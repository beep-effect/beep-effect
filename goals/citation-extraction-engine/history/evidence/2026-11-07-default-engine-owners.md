# Production default engine owner assembly

`CitationEngineDefaultLive` now composes the existing production components with
Effect Layer.effectContext. It creates one operation admission and one native
admission for all four operations, authenticates the default parser/helper/
vocabulary assets, derives the existing engine artifact, installs a coherent
cleaner/value/document-container cohort and captures the ordinary engine service.
The Layer output includes those same trusted owner services, allowing server plan
setup without manufacturing a second value owner. Scope cleanup uses Effect's
Layer lifetime; no new registry, worker framework or lifecycle mechanism is added.

`CitationEngineDefaultConfiguration` declares paths, policy, build identity and
all four native backends. The configuration is copied through its schema before
asynchronous installation. Every runtime kind must agree with the deployment
build before asset reads or owner acquisition. Caller-supplied build metadata is
still a claim: this helper does not attest deployed code, executable contents,
selected host adapters or runtime version. All deployment acceptance remains open.

Source access, genuine missing-page semantic-object identity, host protocols and
platform services remain explicit dependencies. No empty test host adapter or
controlled identity integer is installed by production code. The test fixture
supplies those dependencies explicitly and does not promote them to defaults.

The existing `CitationEngineLive` also snapshots its complete structured
configuration, beyond the earlier policy snapshot. In particular, native worker
paths cannot be changed by mutating the installation input after build. Context
services remain intentionally captured capabilities; this data copy neither
clones nor invents host protocols.
