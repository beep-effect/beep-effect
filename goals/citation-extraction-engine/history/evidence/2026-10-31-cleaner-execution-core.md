## Captured runtime and data boundary

The factory captures the decoded limit policy, Clock and a server runtime
service. Each returned method has R = never. The private request contains text
and a registered server program selector; it contains no iterator, callback,
function body or runtime object. This selector is an internal execution seam,
not the final public named/custom cleaner options.

The runtime owns actual values, functions, registry state and cursors. The
executor carries opaque reference data and checks ownership at initial input,
step, selected callable and returned value boundaries. It does not coerce host
values to strings, copy their properties or place them in Citation schemas.
Controlled tests preserve a host object itself and its mutable state across
successive operations. Lifetime/issuance of these values belongs to the captured
adapter; the execution seam does not introduce a portable restoration contract.

Schema construction initially exposed a boundary error: ordinary nested struct
validation reconstructed the reference/ticket data and lost its live identity.
The corrected fields use shape-checked runtime declarations that preserve the
original live handles. Ownership remains a separate check. A structured-codec
round-trip of a reservation still cannot spend that reservation, and a matching
newly constructed data record has no spending authority. No validation bypass
or unsafe constructor was added.

## Lazy source control flow

The executor opens a cursor and fetches one step at a time. Membership is checked
first, followed by a separate value lookup. A matched non-callable reaches the
invoke failure; it does not fall back to the original step. On a miss, callability
is checked before selecting the step itself. A failed step prevents another
cursor fetch. Controlled live-cursor tests depend on the previous callback's
state change, so eager materialization or eager name resolution would fail.

The registry and host protocol implementation remain adapter responsibilities.
The tests here qualify orchestration; they do not claim that a native JavaScript
Map implements the frozen Python hash/equality behavior or Unicode table layout.
The new source corpus's complete 51-scenario adapter replay remains open.

## Shared work and timing

Each top-level execution creates an operation-owned reservation ledger. Positive
text units must be reserved before a producer materializes them; empty text needs
no reservation object. Original ticket identity, exact total units and single
consumption are checked before a stage result can proceed. Forged, reused and
decoded tickets fail closed. Validation yields while consuming long ticket lists.
Ticket issuance uses weak keys, and the work capability closes on success,
error or interruption.
A retained work capability cannot reserve or start another nested execution.

Nested plans reuse the same ledger and enclosing timers. Repeated production is
charged, including a callback returning text already produced by its nested
cleaner. An empty plan charges the returned original text. Caller replacement
of Clock cannot change captured deadlines. The earliest clean/operation deadline
covers input creation, cursor opening, dispatch, callbacks and completion; nested
execution does not reset it. Cancellation stays interruption, and mixed causes
retain fresh interrupt reasons without source-bearing failures or defects.
Other unexpected defects, including raw-boundary access failures, become a closed
redacted private failure. This does not supply the final engine failure union.

The runtime port must use the reservation mechanism before allocation, own and
retire native work, capture its dependencies and avoid detached callback work.
A typed injected service is not a certificate for arbitrary unsafe server code.
Owned native/default adapters and their full safety proof are still required.

## Literal stage connection and retained source behavior

The four existing regex-free primitives now have an additional internal stage
method. It reserves every positive output slice or replacement before rendering
it, then returns the original live reservations with the complete text. A local
count/deadline exhaustion maps to the corresponding clean safety failure.

The raw apply method retains its original source ceiling and narrow error type.
The stage method accepts already-owned intermediate text up to the absolute
produced-text ceiling, while each append still consumes the current operation's
remaining production budget. It does not reapply a smaller original-source
allowance to that intermediate text. A focused test starts with a one-unit raw
source allowance, produces five units, removes underscores and returns one unit:
six total units succeed, while a five-unit production budget fails explicitly.
The original raw helper rejects that same five-unit input under the one-unit
source allowance.

All 440 frozen primitive text vectors pass through the executor and actual stage
implementations with exact outputs and exact UTF-16 charges. The original
primitive tests and source report remain unchanged. These text vectors do not
qualify every physical string-identity/subclass rule for a full host adapter.
