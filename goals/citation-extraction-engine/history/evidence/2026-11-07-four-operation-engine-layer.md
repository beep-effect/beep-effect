# Captured four-operation engine and public cleaner composition

CitationEngine is now a server-only Context.Service with clean, extract, resolve
and annotate methods, each returning the declared result and closed
CitationEngineFailure with R=never. CitationEngineLive and its explicit
configuration export from law-practice server/layer. The Layer composes the
four real admitted implementations, projects public extraction/resolution
results and captures dependencies during build. No unsupported placeholder
method or parallel worker/admission implementation is introduced.

The host supplies coherent shared operation/native admission, cleaner/value,
document/container, frozen vocabulary and canonical source services through
Effect Layer composition. Native admission is required so private fallback
constructors cannot silently introduce another total capacity. Trusted
configuration supplies normalized policy, native runtimes, authenticated
extraction configuration/artifact and annotation geometry. Complete deployment
attestation remains a separate open proof; schema validation alone is not an
implementation attestation. Primitive source operations are connected; retained
Document/general host profiles still require qualification and integration.

## Cleaner ownership and allocation

CitationEngineCleanInput selects an installed bounded plan name beside raw
canonical source data. Executables remain captured ports. The private pipeline
reuses the same plan schema. SourceCleaning snapshots source/plan before source
lookup, verifies canonical evidence, reserves primitive input before creating
its owned value and runs the original owned pipeline under the enclosing budget.
Nested plans retain their original shared work/admission behavior.

The public cleaner result preserves genuine input evidence and the original live
value handle. For native text, it measures through the captured owner, reserves
the copy and only then obtains the independently copied native view. Non-text
host values retain identity without coercion or serialization; text is None.
Rendered cleaner output is not relabeled as a new verified source manifestation.
The captured cleaner and value projection service must belong to a coherent
owner. Broader host adapters and complete allocation proof remain open.

Standalone cleaner/resolver work shares one text-budget helper using Effect
service provision and timing. The enclosing operation owns Scope/admission.
Report policy is detached through the existing Schema snapshot before return.
No thresholds or baselines were changed to address the initial Fallow duplicate.
