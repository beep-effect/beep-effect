## Implemented stable-resource path

The operation owner snapshots initial semantic assertions into its private
registry. Explicit writeCitation accepts a registered mention/detached
reference and schema-owned Citation data, then snapshots the new assertion.
Detached writes preserve their document-local object identity and update all
views of that node. Default callbacks reread current semantic data rather than
using a stale callback argument; this includes current Id./supra/short fields.

Session dispatch and final mention snapshots read the registry. Semantic
updates preserve the genuine source anchor, source identity, engine artifact,
mention ID, component/zone evidence and physical mention count. Semantic
classification remains an assertion; an anchor does not attest its legal
meaning. No callback can issue source proof through semantic writes.

Physical mention writes currently retain the semantic discriminant because cm1
includes that identity input. Class/tag mutation and other general Python
model operations remain unproved requirements; this is not a permanent
compatibility waiver. Detached semantic updates have no physical proof to
forge. Unknown references and stale-kind writes fail before changing state.

All methods remain captured with R = never and serialize through the existing
owner. Read and write snapshots isolate caller mutation. Owner release closes
further access as in the existing lifecycle controls.
