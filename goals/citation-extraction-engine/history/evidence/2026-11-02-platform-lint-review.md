# Citation platform filesystem judgments

Reviewed 2026-11-02 for PR #2511 by the citation-engine implementation owner.

The completed canonical scan found 36 introduced EV010 filesystem candidates. This rule asks whether a memory filesystem preserves the test subject. These parity suites read repository-shipped source observations or kernel bytes, including transitive fixture loaders; replacing those artifacts with seeded literals would drop the committed-artifact replay check. Copying the same artifacts into memory would still require the real read. The worker suites also need files visible to an operating-system child. The registry-only harness has already been changed to a forbidden-spawner stub without BunServices.

These are per-file judgment exceptions, not rule suppressions. No fixture, expected outcome, safety budget, target parity requirement, or native qualification gate changes. Revisit each entry if artifact verification moves to a separately enforced source-bound loader gate or the native-process subject is removed. Unrelated pre-existing decisions are retained.
