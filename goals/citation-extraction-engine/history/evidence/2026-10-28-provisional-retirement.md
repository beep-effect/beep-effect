# Provisional citation contract retirement

Date: 2026-10-28. Local P1 checkpoint; P0/P1 and the goal remain open.

## Applied scope

`provisional-retirement.json` binds the baseline commit and exact paths/hashes
of 76 removed files: 74 source files in 37 provisional value directories, plus
the owning footnote and segment-map tests. The original content remains in the
recorded Git baseline. The retirement removes the following public promises:

- Mixed `CitationBase`, its local donor-shaped `CitationId`, generic warnings
  and array-index `ResolutionResult`.
- Duplicate `Span`, normalization maps, segments, durable locators/options and
  surrounding-context contracts.
- Citation-copy case/history/parallel/string groups and footnote helpers.
- Sixteen provisional extension form branches, with their component and
  inference helper schemas.

The existing `Citation` union now contains only the eight source-backed
canonical families. `FullCitation` has the three canonical full forms;
short/reference and unknown membership remains separate. An adopted donor
extension can be added to this same hierarchy only with its final disposition,
regression proof and semantic/evidence separation.

Removing an old form or test does not reject its donor behavior, prove it is
subsumed, or complete any accounting row. The deleted footnote tests include
behavioral checks against the retired prototype API. Their source and hashes
are recoverable; equivalent regression proof remains required for any adopted
behavior. All 5,674 donor disposition obligations retain their prior states.
Canonical parsing, correction, equality/hash, cleaning, resolution and
annotation obligations remain intact. No parity or safety gate is relaxed.

Pure `CitationSignal`, `HistorySignal` and `StructuredDate` concepts remain.
Their presence is not a claim that the engine extracts or formats those donor
features. The shared persisted `LawPractice.CitationId` remains unchanged;
the canonical citation value contains no occurrence/persistence ID field.

## Consumer migration and selector preservation

The immediate pre-deletion scans cover the frozen legacy surface, broad
symbols, aggregate imports and exports. External production findings are the
same reviewed identity/build/quality package metadata. There is no production
citation-shape compatibility requirement.

The package build caught an owning dependency in `SourceRef`: its unverified
`TextQuote` review selector was defined inside `DurableLocator`. That selector
is now owned by `SourceRef/TextQuote.model.ts`, exported through the existing
aggregate and SourceRef surfaces. Its exact encoded shape, constructor defaults
and schema annotation identity are retained. This is a retained non-citation
contract, with no coordinate, durability, re-anchor or verification operation.
The old locator model is not restored or aliased.

The RDF package's selector has a different contract: a required kind and
nonempty exact text. Substituting it would change existing review data. The
preserved selector permits empty exact text and keeps prefix/suffix optional.
Two regression tests prove those details and the unchanged SourceRef encoding.
Citation evidence must use the prerequisite's runtime proof and cannot treat
this review selector as a verified anchor.

All unrelated patent, knowledge-graph, review and entity values remain outside
the removal scope. The SourceRef quote ownership correction preserves its
existing users rather than changing their data model.

documentation generation. The retained canonical union property also rejects
occurrence/telemetry keys in schema-generated encoded citation values. The
existing canonical model and law suites remain active. Tests tied solely to
retired APIs are removed with those APIs; the upstream/donor accounting suite
is unchanged.

10-component evidence audit passes while leaving target proof open. Goals
doctor reports no new blocking findings. The final frozen-surface scan covers
7,673 source files, retains the same five reviewed production metadata

The sole old locator-name string in domain source is the retained TextQuote
