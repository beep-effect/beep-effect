## Implementation and ownership

The literal stages now retain whether the actual regex matched. An exact
nonempty plain input with no match keeps its reference. Subclasses flatten to
fresh plain text. Empty results share the empty value. A whole-input whitespace
match shares the sole replacement space. Other transformed nonempty results
are fresh, including one-character text; they are not globally interned.
HTML joins XPath smart strings and issues fresh nonempty results, sharing empty.
All previous 440 literal text vectors remain unchanged.

`CleanerValues.ts` captures its Scope and issues frozen original handles into
a weak ownership table. Copied, restored and foreign handles cannot acquire
authority. Host payloads remain opaque; explicit text-subclass and immutable
Python-byte registration preserve source kinds without structural inference.
Bytearray and memoryview are host values, not Python bytes. The byte issuer
captures adapter-owned immutable bytes; its input must remain immutable for
the captured lifetime. Returning an existing handle preserves source identity.
Issuing equal payloads does not infer identity. Two bounded strong caches retain
only empty and replacement-space text. Scope closure invalidates all retained
handles and drops the owner's caches and table. Snapshot issuance counts are
lifetime counters, not a claim about heap retention.

Allocation metadata is schema data, not a production or issuance receipt.
Every stage still reserves and settles original work tickets. A repeated
unchanged-string integration test returns the original reference while charging
all three stages. Concurrent shared-space creation issues one cached reference.
