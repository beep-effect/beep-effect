# Owned protocol-driven input Document

InputDocument.ts connects the original constructor control flow to the existing
owned cleaner pipeline and native geometry preparation. It captures a value
owner and server protocols for truth, html membership, source insertion, plan
selection and warning. No callable or iterator enters public request data.
Private input/output schemas retain issued handles; the actual owner rejects
structural copies. The returned initialize method has R=never and an inferred
closed error union, checked by a compile-time assignment in the replay.

## Source order and identities

A small schema-owned branch domain separates source selection from execution.
Selection performs the original repeated, short-circuited truth calls rather
than reducing inputs to booleans once. Plain-only cleaning is conditional on
step truth. Markup-only handling checks membership without first testing truth,
calls insertion with the literal source arguments (html, zero), warns only on
successful insertion, then cleans. Both-input handling checks step truth before
accepting supplied plain text. Empty input fails without consulting steps.

The protocols retain the actual step container and plan iteration state. They
do not prepend conventionally, normalize generators to arrays, or replace truth
with length. The original source value remains an issued handle even when a
callback returns None as plain text. Successful results retain original markup
and step identities; maps are present only in the markup-only branch.

The existing owned cleaner entry runs directly inside the enclosing admitted
operation, avoiding nested admission. Geometry likewise uses its existing
internal phase rather than invoking another admitted operation. Cleaned plain
validation is deferred until after placeholder generation so the original
placeholder/diff failure ordering can be represented. Existing post-cleaning
geometry callers reuse that same phase. The live cleaner-object codec is shared
by pipeline, registry and Document; no second identity decoder is introduced.

All workers, RPC, admission, captured timing, native text operations and physical
retirement are existing components. This adds domain constructor behavior, not
a new executor or ownership mechanism. Context.Service owns the server protocol
boundary, Schema owns data and errors, and Effect Match dispatches the branches.

## Passed local proof

The final focused regression has eight passing tests across constructor,
connected geometry and owned cleaner controls in 11.91 seconds. The constructor
replays thirty sealed original cases through real cleaning/geometry, matching
successful native values, aliases, geometry presence/emphasis, known failures,
protocol events, generator state and retained container contents. Exactly twenty
children spawn and independently confirm exit; native and operation admission
finish empty. The source traces include ordinary insertion failure, permissive
insertion and warning, truth-throwing/falsy lists, generator membership consumption,
both-input generator refusal, None callbacks and literal surrogate inputs.

The registry codec reuse has a separate nine-test passing replay in 1.55 seconds.
Package lint/source/test type checks pass. Initial branded-error constructor,
yield-in-call and native String-method diagnostics were corrected using the
existing schema constructor, local bindings and Effect String. No threshold,
baseline, suppression, timer or resource ceiling is changed.

## Pending proof and unchanged full goal

Hosted integration requires all 112 original cases, 55 successful constructions,
57 source failures, ten geometries and 55 independently confirmed exits through
the Bun fixture. It remains pending. This test adapter uses actual owned
cleaning and geometry, while providing the captured host/container protocols;
the production default protocol adapter and Node constructor replay remain open.
Original phase ordering is implemented directly; the replay compares protocol
events and separately qualified geometry rather than claiming every internal
phase trace or failed constructor's partial field state as public output.

Cleaner work and geometry retain separate recorded text counters here. Their
whole-engine allocation authority still needs complete composition/proof. General
host/model mutation, arbitrary exception translation and pre-populated Document
fields are also not qualified by the thirty-case smoke. This is an internal
component with no public engine Layer exposure or whole-constructor acceptance.
HTML case names, exhaustive static/runtime accounting, all remaining parity and
safety/scaling requirements, public codecs/service/layer and reflection/lifecycle
closeout remain required. No semantic divergence or waiver is introduced.
