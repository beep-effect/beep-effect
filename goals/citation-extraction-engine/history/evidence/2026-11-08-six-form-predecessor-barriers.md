# Preserve immediate predecessors across excluded observations

The frozen six-form rule says Id. inherits the immediately preceding mention
only when its local result permits inheritance. A controlled actual-public-Layer
probe found a counterexample after profile filtering:

```text
35 U.S.C. 101; 42 U.S.C. 1983; Id.
```

The old result contained two supported mentions and outsideProfile 1, but
incorrectly resolved Id. to 35 U.S.C. 101. The intervening excluded locator's
position had been discarded. This is an in-profile linking defect; no frozen
label or citation-form boundary has changed.

## Repair and ownership

The technical driver now retains original ranges for excluded observations and
checks count agreement and the absolute combined candidate ceiling. The
projector checks captured candidate/mention ceilings separately, orders and
cross-stream overlap, and verifies excluded anchors against the same genuine
canonical source. Those quotes consume the existing aggregate evidence budget.

Resolution input owns structural snapshots and reverifies barriers before
matching. A linear strict-resolver cursor consumes each barrier, charges the
existing resolution-iteration budget and clears both the resolved predecessor
and prior ambiguity. Earlier full-authority history remains available for a
later supported short form or supra. Trailing barriers consume work without
altering earlier results. Excluded observations do not become public mentions,
authorities, edges or another semantic citation variant.

The existing prepared-input owner has a named opaque schema to preserve private
proof declaration boundaries. Legacy callback sessions omit the unused strict
barrier field and retain their previous serialized shape. Calls without the
optional barrier key retain prior candidate/order semantics. No legacy API or
test is retired, and the retained resolver does not consume strict barriers.
