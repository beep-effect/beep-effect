## Reproduction and limits

The three pins and existing isolated installation authorization are recorded
in the preceding nine-case smoke receipt. Capture sources are archived as text;
restore their `.ts`/`.py` extensions and the frozen JSON filename in a scratch
directory to run them against the recorded local caches. No install, production
runtime, dependency or parser code was changed. The runs used Bun 1.4.4 for the
TypeScript source and CPython 3.11.15 for official eyecite.

Observed JSON files preserve selected raw parser fields and ranges, omitting
large edition graphs and irrelevant internals. They are diagnostic projections,
not a lossless serialization of the parser objects. Original local raw hashes
are recorded. The count table checks only recognized in-profile occurrence

linking was not invoked. None of this establishes the new local-link contract.
