# Exclusive cleaner output capacity

Date: 2026-10-31. Scope: the private operation-owned text ledger. Native HTML
adapter integration and exhaustive cleaner replay remain open.

The cleaner work capability now lends its remaining production allowance to a
captured bounded producer. A semaphore holds that allowance until the producer
returns or its failure/interruption cleanup completes. Ordinary reservations
share the same semaphore, so a concurrent producer cannot spend the borrowed
capacity. This is an internal server capability, never a function-valued request
field or public cleaner option. Every returned method still has R = never.

The producer receives the exact remaining UTF-16 allowance, including zero. It
must enforce that ceiling before allocating output and own native retirement.
Successful settlement validates its reported length and issues the original
operation-owned positive charge ticket; empty output issues no ticket. The
existing executor checks the actual owned result length against those tickets.
No output is published if settlement fails. Malformed lengths fail closed and
excess lengths return the existing produced-text safety failure. The trusted
producer contract does not make arbitrary injected code safe.

Same-fiber ledger reentry during a loan fails explicitly instead of deadlocking.
Adapters must not fork ledger work and wait for it while retaining the loan.
Retained capabilities fail after operation closure, before invoking a producer.
Failure and interruption clear borrowing ownership and release the semaphore;
queued producers resume only after the borrowed effect's cleanup completes.
This is logical budget ownership, not proof of process exit. The HTML worker's
existing retirement/quarantine owner must still be integrated, and global engine
admission must retain unresolved native ownership independently of this ledger.

Three focused tests cover exact settlement with a competing reservation, empty
output at zero capacity, malformed/excess settlement, closed capabilities,
same-fiber reentry, failure and interruption with a waiting producer. The test
adapter explicitly signals cleanup before the waiting producer can reserve.
All 12 cleaner-pipeline tests pass, retaining all 440 literal-vector outputs.

No source corpus, divergence approval, frozen policy field, canonical row or
completion claim changes. Remaining work includes intermediate HTML preparation,
complete framing preflight before allocation, widened native input bounds,
captured native adapter composition, live registry/value ownership, all 1,155
sequence cases, maps, global admission and the final public service/Layer.
