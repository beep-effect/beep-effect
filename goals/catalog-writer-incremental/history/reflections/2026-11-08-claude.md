# Reflection — catalog-writer-incremental (2026-11-08, claude)

## Summary

One PR (#2924) made the lefthook `schema-catalog` writer incremental: the scoped run reads each
in-scope owner's committed shard, drops the staged paths' entries, parses only the staged files and
splices the result back, with syntactic export checks in place of ts-morph's checker-backed
`isExported()`. The five-fixture run went from 5.31 GB / 15.3 s to 0.63 GB / 2.1 s with
byte-identical shards; the full writer and hosted Repo Sanity are unchanged. The commit of the
change itself ran the new hook in 2.5 s. The instrumentation writer stays on whole-owner
regeneration (0.57 GB measured; its entries carry no file path).

## Tooling experience

- Worked: `/usr/bin/time -v` per variant; `bun run beep lint schema-catalog` full check as the
  parity oracle; `@effect/vitest` layer tests with the temp-repo helpers in
  `catalog-shard-scope.test.ts`; `goals decisions add` and `goals manifest --write` for the packet.
- Did not work as expected: the exploration's RSS model (per-package loading) predicted a ~1 GB
  result for the splice alone; the checker, not the parse, was the cost.
- Frustrating: a fresh lane's `check` fails until the dependency dists exist (TS6305).
- Wished existed: a per-phase RSS probe flag on the writer.

## Implementation improvement opportunities

- Syntactic-only AST reads on the hook path (see findings).
- `file` field on instrumentation span entries for a future splice.

## Goal & prompt critique

The SPEC was precise about surfaces, fixture files and the budget, which made the lane bounded.
It should have asked for a per-phase profile before fixing the design; the one-week appetite held
only because the lane profiled anyway.

## TODOs worth codifying

See `todos` in the frontmatter.

## Lessons

- HIGH: in commit hooks, any ts-morph call that touches symbols builds the whole program; check
  the AST syntactically.
- MEDIUM: prove a memory budget per phase, not per run, before choosing the fix.
- LOW: keep the measured cost next to the hook definition so regressions are reviewable.
