# Reflection — ontology-workbench-migration (2026-07-17, claude)

## Summary

Migrated the Ontology workbench monolith into nine dock panels across four
PR-gated milestones — dock capabilities (#429), zero-behavior region
extraction (#433), shell integration with the rail panel menu and v2 layout
(#434), and this QA-to-green closeout — with the browser QA loop converging
7 → 2 → 1 → 0 required findings over four rounds. The loop itself graduated
into `.claude/skills/browser-qa-loop` with the capture harness as a template.

## Tooling experience

- **Worked:** the capture-then-vision-judge loop (11 findings, 9 real, every
  one evidence-precise); focused probes as the arbiter between judge claims
  and product truth; the M1 Storybook interaction lane catching what jsdom
  cannot; detached nohup publishes after the harness cap killed two proofs.
- **Didn't:** background yeet runs under the 10-minute harness cap;
  `pkill -f` self-matching its own compound command (twice); codex sandbox
  vitest workers (all runs environment-blocked — operator-side verification
  remained mandatory).
- **Frustrating:** four publish rounds for M3 as review directives and law
  lanes landed serially; the goals INDEX drifting on every packet-state edit.

## Implementation improvement opportunities

- One coordinate space per gesture pipeline (now done); pre-float placement
  memory could live in the kernel schema instead of adapter state if other
  hosts need reversible float cycles.
- The measurement-settling window (2x2 placeholder groups) could get a
  first-class "settling" visual instead of relying on speed.

## Goal & prompt critique

The grill-locked decisions all survived contact: nine panels, rail menu,
core-cluster default, v2 key bump — none reopened. The SPEC's per-claim
evidence plans priced verification correctly; what it under-specified was
gesture-scenario diversity (no vertically-adjacent drop target existed in
any pre-M4 scenario, hiding R1-01 through three merged PRs).

## Lessons (confidence-tiered)

- **HIGH — Critical:** probe before fixing vision findings; two of eleven
  were artifacts of the capture, and only kernel-state/geometry dumps told
  the truth.
- **HIGH — Critical:** coordinate-space mismatches hide until the layout
  grows in the unmeasured axis; convert once at the boundary and assert
  placement, not just count deltas.
- **MEDIUM — Best practice:** scenario diversity beats scenario count — one
  vertically-stacked drop target would have caught R1-01 in round one of the
  PREVIOUS packet.
- **MEDIUM — Best practice:** an unused capability is an unverified one;
  land a consumer with the kernel feature.
