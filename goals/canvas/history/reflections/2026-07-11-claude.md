# Reflection — canvas (2026-07-11, claude)

## Summary

The bootstrap goal delivered the `@beep/canvas` slice and Tauri app scaffold with
typed scene/save/load command bridges; P1/P2 completed 2026-05-21 with evidence in
`history/outputs/p1-p2-contract-proof.md` and `history/outputs/p1-prd-deferrals.md`.
This is an administrative closeout: the 2026-07-11 roadmap synthesis
(`docs/ROADMAP.md`) flipped the lifecycle to `completed-retained` after
goals-doctor had flagged the packet phases-terminal-but-active.

## Tooling experience

- **Worked:** `beep goals set-status` as single writer (manifest + README + INDEX
  in one command); goals-doctor baseline caught the terminal-but-active drift.
- **Didn't:** `set-status` refused to run until a template-format `Lifecycle:`
  line was hand-inserted into this legacy README.
- **Frustrating:** two conventions (status flip, reflection gate) both required
  at closeout, discovered serially via CI failures rather than one advisory.
- **Wished existed:** a `beep goals close <slug>` that chains status flip,
  reflection scaffold, and INDEX regeneration.

## Implementation improvement opportunities

- None to the shipped code in this pass; the packet's deferred P3+ scene-graph
  scope is intentionally retained as evidence, not reopened.

## Goal & prompt critique

- The packet's PLAN tracked implementation phases but had no closeout phase;
  adding "flip status + write reflection" as the last checklist item would have
  prevented the 7-week drift.

## TODOs worth codifying

- goals-doctor terminal-but-active advisory should emit the exact remediation
  commands.
- Legacy README Lifecycle-line backfill (or auto-insert in `set-status`).

## Lessons (confidence-tiered)

- **HIGH — Critical:** Close packets when their last phase lands — status drift
  compounds into portfolio noise; this packet read as "active" in INDEX for ~7
  weeks after work stopped.
- **MEDIUM — Best practice:** Administrative closeouts still owe a reflection;
  the gate firing here (lint reflection-artifacts) is the system working, not an
  obstacle.
- **LOW — Consideration:** Bespoke early packets (pre-template) accumulate silent
  incompatibilities with newer tooling; budget a small conformance pass when
  touching them.
