# CSF-016: Runner AMI bake executes unverified remote installer

- Severity: High
- Codex ID: `a0921bdb2c4c8191bef211deceacdbce`
- Source commit: `ddc8a873b154bcddecb956580b77e165698bdffc`
- Owner: Runner AMI bake supply chain
- Status: remediated locally; combined publication pending

## Public Summary

The runner AMI bake fetched a mutable installer script from `bun.sh` and
executed it as root. Selecting a Bun version did not authenticate the installer
or the installed binary before the machine was converted into a reusable CI
runner image.

## Current-HEAD Validation

Verdict: confirmed vulnerable. Disposition: remediate. The current bake path
trusted TLS delivery of a remotely controlled script and carried no
repository-pinned digest for the executable artifact.

## Remediation

The bake now downloads the versioned `bun-linux-x64.zip` GitHub release asset,
verifies a tracked SHA-256 digest before extraction, and installs only the
verified binary. The digest participates in dirty-input checks, bake plans,
image tags, freshness checks, and durable reports, so changing it makes an old
AMI stale.
