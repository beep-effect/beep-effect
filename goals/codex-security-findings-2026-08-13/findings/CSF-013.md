# CSF-013: Lambda API integrations use the wrong ARN

- Severity: Informational
- Codex ID: `cde426d1c9ec8191b780fe9a25c0b789`
- Source commit: `b8fb5c97aab1683252277f990e1ae54095312fbb`
- Owner: CI Turbo cache infrastructure
- Status: confirmed; remediate; fixed locally

## Public Summary

Both API Gateway proxy integrations use the Lambda function ARN where API
Gateway requires the Lambda invocation URI.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`. The read and write integrations both bind
`integrationUri` to `Function.arn` on the captured baseline.

## Remediation

Both integrations now use `Function.invokeArn`. Pulumi mocks give each property
a distinct value and assert that the emitted API integrations select the
invocation ARN.

This is local source and mock proof only. No Pulumi deployment is claimed by
this packet; external deployment evidence is required before hosted closure.
