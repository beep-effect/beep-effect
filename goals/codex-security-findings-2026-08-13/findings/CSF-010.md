# CSF-010: Agent configs disable sandbox and approval safeguards

- Severity: Medium
- Codex ID: `dfdc1765ff48819183742283aec1b66c`

## Public Summary

Repository agent defaults grant unrestricted Codex filesystem authority without
approvals and allow Claude Code to invoke the entire GitHub CLI command family.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`. Both permissive defaults are active in tracked
configuration on the captured baseline.

## Remediation

Codex now defaults to workspace-scoped writes with on-request approval. Claude
settings remove broad GitHub CLI and Codex execution auto-allow rules. AI-sync
pins Codex exactly to `on-request`/`workspace-write`, requires Claude
`permissions.defaultMode` to be explicitly `default`, and admits only the exact
47 checked-in Bash grants;
regressions reject broad families, wrappers, absolute executables, environment
prefixes, shell indirection, and approval-mode drift. Its Turbo package config
includes both governed root configs in the `check` task hash. The worktree
standard clarifies that direct GitHub CLI mutations require approval while
intentional `git push` and Yeet publication grants remain available. AI-sync
documentation now records the plural validation APIs and both-config safety
check.
