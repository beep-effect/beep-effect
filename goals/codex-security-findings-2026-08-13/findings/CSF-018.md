# CSF-018: Legacy registry migration trusts one matching digest

- Severity: Low
- Codex ID: `91a45adf70408191972ff02c56b9e54c`
- Source commit: `2fe7a8e688060da89489d0bcff43957a6d042e72`
- Owner: AI metrics identity registry
- Status: remediated locally; combined publication pending

## Public Summary

A legacy identity registry without a salt fingerprint was promoted when any
one root or source digest matched the active namespace. Mixed-salt or locally
modified rows could therefore inherit a namespace identity they had not
proved.

## Current-HEAD Validation

Verdict: confirmed vulnerable. Disposition: remediate. The fallback predicate
used existential matching, then preserved and relabeled the complete registry.

## Remediation

Legacy promotion now requires every existing root identity and every source
instance to match the active salted namespace. A mixed-registry regression
proves one valid row cannot promote unrelated identities.
