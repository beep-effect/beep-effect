# CSF-007: Yeet PR footer leaks local paths and AI session IDs

- Severity: Medium
- Codex ID: `14981c9702288191a821494c38525185`
- Source commit: `4ec4cd15cd0002530066780efe6e47328a8df6d4`
- Owner: Repo CLI Yeet provenance
- Status: confirmed; remediate; fixed locally

## Public Summary

The public Yeet footer and its machine block expose local clone and worktree
structure, an agent resume command, and an AI session identifier. Home-prefix
tokenization alone does not make those fields public-safe.

## Current-HEAD Validation

Verdict: `confirmed-vulnerable`. Both the visible footer and embedded JSON
include local-only resume provenance on the captured baseline.

## Remediation

Rendering now projects local provenance into a schema-backed public model that
contains only schema version, branch, and harness. Local paths, resume commands,
and session identifiers remain available only to local resume detection.
