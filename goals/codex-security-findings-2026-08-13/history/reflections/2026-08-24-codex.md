# Reflection — codex-security-findings-2026-08-13 (2026-08-24, codex)

The packet is complete and retained for repository-local work. PR #712 merged
CSF-012 and CSF-015 through CSF-019 after the earlier remediation PRs landed.
Six runner findings remain assigned to the runner-admission and
workload-identity arc, with no claim that its external proof or dashboard
closure has occurred.

## Tooling experience

- **Worked:** Local Git history resolved every cited repository merge without
  network access, including the final PR #712 merge timestamp and tree.
- **Didn't:** Packet status text, triage summaries, and finding prose froze at
  different pre-merge moments. The whole-document sanitation check also
  treated each required YAML delimiter as a spreadsheet formula.
- **Frustrating:** The six runner findings had clear prose blockers but no
  machine-readable receiving owner or external-evidence contract.
- **Wished existed:** A packet audit command that compares cited PRs with local
  main history, detects stale publication language, and emits a closeout-ready
  evidence summary.

## Implementation improvement opportunities

- Store merge evidence once in the manifest and derive README, PLAN, and index
  status from it.
- Model external evidence as a typed handoff instead of leaving the source
  packet blocked after all repository-local work has shipped.

## Goal & prompt critique

Split the completion rule into two explicit outcomes. Use full scanner closure
when the packet owns every finding, or allow `completed-retained` with an
exact-ID handoff when another arc owns controls that cannot be proved from the
repository. Require the final note to name the receiving owner and missing
evidence.

## TODOs worth codifying

- Add typed external-evidence handoffs to Codex triage and goal manifests.
- Make stale cited-PR state a goal-doctor finding when local main contains the
  merge.
- Add a frontmatter-aware mode to packet sanitation.

## Lessons (confidence-tiered)

- **HIGH — Critical:** Do not claim external runner safety or scanner closure
  from repository history. The local merge proves code state, not organization
  policy or deployment state.
- **HIGH — Best practice:** Close the source packet once its work is terminal
  and the receiving security owner is explicit.
- **MEDIUM — Consideration:** Derive human status text from one structured
  evidence record to prevent active and merged claims from coexisting.
