# Box driver provisioning-surface receipt

Date: 2026-08-30

## Provenance and generation

The root catalog, lockfile, and installed manifest agree on
`box-node-sdk@10.14.0`. The trace version constant and its unit assertions now
use that authoritative installed version.

`bun run generate` discovered 86 SDK managers and emitted a demand-scoped
surface spanning 19 managers, 69 JSON operations, and 479 transitive model
schemas. The accepted manifest combines whole managers with individual
`manager.method` entries:

- whole collaboration-list, collaboration-mutation, and webhook managers;
- metadata and retention discovery operations only, because the ratified
  Business posture blocks their mutations by entitlement;
- the complete Box Sign request and template surfaces required by the packet.

No Box API call or tenant mutation was used to generate or test this surface.

## Type-instantiation budget

Compiler: `tsgo 7.0.2+effect-tsgo.0.35.0`.

The measurement recipe followed
`goals/box-typecheck-cost/research/measurements.md`: a schema-import floor probe,
the generated models file, and the package `src` graph were each checked with
`--extendedDiagnostics` and no incremental state.

| Measurement | Instantiations | Budget result |
| --- | ---: | --- |
| Schema-import floor | 1,543,714 | Baseline |
| `Box.models.gen.ts` total | 2,166,833 | 623,119 marginal; pass against 750K |
| Package-wide `src` graph | 2,914,305 | Pass against 3M |

The whole-manager candidate did not fit even though its generated model file
did: 2,258,591 model instantiations (714,877 marginal) and 3,092,315
package-wide. Removing the Sign request manager still measured 3,038,426.
Removing both Sign managers measured 2,994,772, leaving only 5,228
instantiations of headroom and omitting required behavior. Individual-operation
admission preserved the required surface with 85,695 package-wide
instantiations of headroom.

## Verification

The focused service test passes 23 cases. It decodes one representative read
through every newly admitted provisioning manager and checks that the required
collaboration, webhook, and Sign mutation entry points are exposed. The full
unit suite passes 24 cases; the integration suite passes its credential-free
case; source, test, and script typechecks pass; and lint is clean.

`bun run beep quality package-verify @beep/box` passed both the package audit
and docgen on the accepted surface. Its first attempt hit the known
nondeterministic, locationless native-compiler TS2589 during declaration build.
The exact same generated bytes then passed a direct declaration build and a
second canonical package verification, so the first failure is attributed to
the native flake class rather than hidden or described as an introduced schema
failure. The armed P0 inbox row carries that attribution receipt.
