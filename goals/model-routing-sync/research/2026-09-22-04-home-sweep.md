   `xhigh`, and `~/.config/JetBrains/Air/.codex/config.toml` says `high` /

2. **Codex model: gpt-6-astra vs gpt-5.6-sol.** `~/.codex/config.toml` = `gpt-6-astra`;
   both `CodexLauncher.xml` files and `Air/.codex/config.toml` = `gpt-5.6-sol`;
   `~/.config/semantica/runtime.env` heavy lane = `gpt-5.6-sol`.
3. **Two live Codex configs.** `~/.codex/config.toml` and
   `~/.config/JetBrains/Air/.codex/config.toml` both set `model`/`model_reasoning_effort`
   and disagree. A sync tool that writes only the first leaves the JetBrains Air lane stale.
4. **Grok effort.** `~/.grok/config.toml` pins `default_reasoning_effort = "xhigh"` while
   repo doctrine routes Grok lanes as research-class with no effort pin — the CLI default
   and the doctrine are not expressed in the same place.

   `ANTHROPIC_DEFAULT_HAIKU_MODEL='gpt-5.6-luna'`; the RustRover `DefaultAgentRollout.xml`
   rollout list also leads with `gpt-5.6-luna` — consistent today, but two independent
   copies with no shared source.
