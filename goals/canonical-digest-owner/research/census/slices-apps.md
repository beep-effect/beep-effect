# Census: domain slices, apps, infra, scripts

Partition detail for [`../encoder-census.md`](../encoder-census.md), which holds the classes and dispositions this goal acts on. The class column below is the sweep's first reading; where the two differ, the top-level census decides.

Partition: every `packages/*` except `tooling`, `foundation` and `drivers` (that is `agents`, `architecture-lab`, `documents`, `ecosystem`, `epistemic`, `execution-authority`, `_internal`, `law-practice`, `ontology`, `party`, `shared`, `workspace`), plus `apps/**`, `infra/**` and `scripts/**`. Top-level `scripts/` holds only `scripts/cloud/bootstrap.sh`, so it has no rows. `agents`, `architecture-lab`, `ecosystem`, `_internal`, `shared` and `workspace` also have no rows: their only hashing is over raw bytes, and none of them has a key-sorting encoder.

The scan covered source only (`*.ts`/`*.tsx`/`*.js`/`*.mjs`/`*.cjs`, excluding `test/`, `*.test.*`, `dist/`, `node_modules/`, `*.d.ts`, `generated/`, `*.gen.ts`). I read each function body before classifying it. Line numbers are from committed `HEAD` `4f1ef2168f9`.
