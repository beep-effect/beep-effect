The main table counts aggregate rows (one per helper or preimage family). The nine hashing callers of `canonicalJsonText` are counted as `replace` preimage rows, and the PacketDigest section lists them one per line.

Shared scalar semantics used in the table:

- **JSON.stringify (schema)** means `S.encode*(S.fromJsonString(Schema))` / `JsonStringCodec(Schema).encode` (`lib/repo-cli-kit/src/schema/JsonCodec.ts`). The output is compact. Keys follow the schema field declaration order for structs and insertion order for records and rest records. The schema validates first, so bigint, functions and other values it rejects cause a `SchemaError`. `undefined` members are dropped. NaN and Infinity become `null` when the schema admits them. A Date is encoded by the schema, usually to an ISO string. Lone surrogates are escaped as `\udXXX` (ES2019 well-formed `JSON.stringify`).
- **JSON.stringify (Unknown)** means `S.fromJsonString(S.Unknown)`, which is raw `JSON.stringify` behind a schema getter (`effect/SchemaGetter.ts:1505`). `undefined` members are dropped, `undefined` array elements become `null`, NaN and Infinity become `null`, and bigint throws a `SchemaError`. A Date becomes its `toJSON` ISO string, lone surrogates become `\udXXX`, and a top-level `undefined` is a `SchemaError`.
- **template** means `${x}` interpolation (`String(x)`) with no escaping, so a delimiter inside a field can collide with the next field. `undefined` becomes `"undefined"` and numbers use JS `ToString`.

- **Y4** (`ProofState.ts:377`) and **Y7** (`HeadInstallReceipt.ts:200`). The preimages are git output re-rendered from parsed entries and framed with NULs or newlines. They are listed as `other` but are close to "raw bytes" skips.

If protobuf export bodies count as structured preimages, they form one more `other` row.
- **LB7** (`revisionPreimage`) could be argued as `pinned`. `goals/agent-memory-store/SPEC.md:447` names `revisionPreimage` as the preimage and says ids are never recomputed, but it does not fix a byte form. It is classed `other`.
