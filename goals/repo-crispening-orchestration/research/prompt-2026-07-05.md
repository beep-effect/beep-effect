## 3. The crispening thesis

**The schema is truth; behavior precipitates.** Win condition: *the first ~200 lines of any
business-logic module read as pure intent* — no decode/guard helper wall, no `*Defaults` spreads, no
`?? {}` fallbacks, no imperative `let`/`for`/`push`, no `as`. Every invariant the *type* can enforce
is a helper you never write; every piece of pure node behavior lives *on the schema* (statics,
`.behavior.ts`, `.policy.ts`), not scattered across call sites.

Follow the **crispening ladder** (`.claude/skills/crispen/SKILL.md`) — climb before writing a helper,
stop at the first rung that removes the noise, but only after you understand the module and trace the
real flow. **Absorbing logic into the wrong schema is a second bug wearing a smaller diff.** Rungs:
(1) schema carries the invariant; (2) a combinator already exists; (3) absence → `Option` in the
schema; (4) constant/bool default → schema; (5) decode/guard wall → colocated statics; (6) repeated
literal/variant family → one node + a kit; (7) branching → a fold, passthrough → point-free;
(8) split roles.

### S1 — Schema-as-truth & exotic-type elimination  *(heading 1)*

**Why.** `ARCHITECTURE.md` Principle 5: "For pure data models, `Schema` is the source of truth."
`04-rich-domain-model.md` L25: "A schema is not a fancier interface. It is executable domain
evidence… Types can lie; schemas have to check." Almost every `type X = { … }` / `interface X {}` for
a data payload — and even function / Promise / Effect *shapes* — should be a schema.

**Smells.** `export type X = { … }` / `export interface X { … }` describing wire/persisted/config/
domain payloads; a `type Fn = (a: A) => B` function alias; fields typed `Promise<…>` / `Effect<…>`
with no schema.

**Targets.**
- Data payloads → `S.Class` (default) / `S.Struct` (boundary shape only), then `type X = typeof X.Type`.
- **Function contracts → `Fn`** (`@beep/schema`):
  ```ts
  import { Fn } from "@beep/schema";
  export const Formatter = Fn({ input: FormatterInput, output: S.String })
    .pipe($I.annoteSchema("Formatter", { description: "Colorizes a formatter input to a string." }));
  export type Formatter = typeof Formatter.Type;                 // (input: FormatterInput["Type"]) => string
  const fmtSync = Formatter.implementSync((input) => renderPlain(input));   // ← plain synchronous fn
  const fmtEff  = Formatter.implement((input) => renderPlain(input));       // ← returns Effect<…, Issue, …>
  ```
  Exemplars: `capability/colors/src/internal/ColorsSchema.ts:66`; `schema/src/ParserOptions/ParserOptions.types.ts:61`.
- **Effect-typed values → `EffectSchema()`** (factory — call it):
  `const p: EffectSchema<string, never, never> = S.decodeUnknownSync(EffectSchema<string, never, never>())(Effect.succeed("done"));`
- **Promise-typed values → `PromiseSchema`** (value — no call): `S.decodeUnknownSync(PromiseSchema)(task)`.

**Carve-out (the #1 predicted violation).** Keep `interface`/type-aliases for **service contracts,
`Context.Service` shapes, type-level utilities, overload surfaces, and port interfaces**
(`04` L45-48; Principle 5 L116-118). `DrizzleClient`/`DrizzleShape` and `MembershipRepository` are
deliberately interfaces — leave them. Do not schema-ify `Graph`/`MutableHashMap`/`MutableHashSet`.

**Novel lint cards.** `SFV4-type-alias`, `SFV4-fn-schema`.

### S2 — Defaults, normalization & absence→Option  *(headings 2, 3, 5, 6)*

**Why.** schema-first Law 4/5: defaults + normalization belong in the schema; nullish/optional data
becomes `Option`. A `??`, a `const somethingDefault`, an `O.getOrElse(…, () => x)` fallback, or a
`.trim()` in a body all mean an invariant leaked out of the schema.

**Smells.** `?? {}` / `?? value`; `const *Default | *Initial | *Empty`; `O.getOrElse(x, () => d)` as
a default; `v ? v : undefined`; `x === "" | === 0 | .length === 0`; `.trim()` / `.toUpperCase()` /
`.toLowerCase()` / `.capitalize()` in bodies; functions returning `null`/`undefined`.

**Targets.**
- Constant/bool defaults → schema (constructor-only, wire contract unchanged):
  ```ts
  version:  LexicalNodeVersion.pipe(SchemaUtils.withConstantDefault(1)),
  format:   ElementFormat.pipe(SchemaUtils.withConstantDefault<ElementFormat>("")),  // branded → explicit type arg
  checked:  SchemaUtils.BoolKeyDefaultFalse.annotateKey({ description: "…" }),
  children: S.Array(Node).pipe(SchemaUtils.withEmptyArrayDefaults),
  ```
  Use `SchemaUtils.withKeyDefaults(v)` when a missing key on **decode** should also default; call
  site collapses to `Node.makeEffect({ children })`. Exemplars: `lexical/src/Lexical.model.ts:681,772`;
  `md/src/Md.model.ts:1101,1468`; `commands/Graphiti/internal/ProxyConfig.ts`.
- Absence → `Option` in the schema + `withNoneDefault` to erase the `O.none()` at each `make`:
  `backgroundColor: S.OptionFromNullOr(S.String).pipe(SchemaUtils.withNoneDefault)`. Pick the codec
  by boundary: `OptionFromNullOr` / `OptionFromNullishOr` / `OptionFromOptionalKey` / `OptionFromOptional`.
- String→parts & normalization → a **transformation schema**: `S.decodeTo(Target,
  SchemaTransformation.transform/transformOrFail)`; `SchemaGetter` for optional/default/omit/forbidden
  property transforms; trim/case normalization becomes part of the schema.
- Functions return **`Option` / `Result` / `Effect` / `Exit`**, never `null`/`undefined` (except at
  3rd-party/react boundaries).

**Carve-out.** `ARCHITECTURE.md` L134: **SQL row absence must ENCODE as `null`.** Model nullish as
`Option` on the decoded/domain side; the encoded/persistence side stays `null`.

**Lint cards.** Reuse `SFV4-defaults`; add `SFV4-normalization` (trim/case in a body), `SFV4-null-return`.

### S3 — Discrimination, exhaustiveness & no-`as`  *(heading 4)*

**Why.** schema-first Law 7/9 + DECISIONS 2026-05-09: model finite variants as discriminated unions,
derive guards/matchers *from* the schema, and let a `never` return type prove exhaustiveness. An `as`
is almost always a failure to narrow with the primitives that exist for exactly that.

**Smells.** `as X` / `as unknown as X`; `switch`; hand-rolled `_tag` guards; a literal-union field
that isn't a tagged union; non-disjoint state modeled as one struct of optional flags;
`R.getSomes({…})` struct-spread; exhaustive handlers that never reach `never`.

**Targets.**
- Finite variant family → **tagged union**: `S.toTaggedUnion("<field>")` (any discriminator) or
  `S.TaggedUnion({...})` (`_tag`). Repo build order: `LiteralKit` → member `S.Class`es →
  `.mapMembers(...)`/`Tuple.evolve` → `.toTaggedUnion("field")`. Branch with `.match`/`.cases`/
  `.guards`/`.isAnyOf`:
  ```ts
  const Shape = S.Union([Circle, Rectangle]).pipe(S.toTaggedUnion("kind"));
  const area  = Shape.match(shape, { Circle: (c) => …, Rectangle: (r) => … });
  // LiteralKit form: IndexHintKind.toTaggedUnion("kind")({ … })   (EntitySchema.persist.ts:176)
  ```
- Literal domains → `LiteralKit([...])` (`.Enum`/`.Options`/`.is`/`.$match`) or `MappedLiteralKit`
  (`.From`/`.To`). Numeric/boolean keys stringify: `LiteralKit([1..6]).Enum.number1`; no `as const`.
- Runtime union dispatch → `Match.type<U>().pipe(Match.tagsExhaustive({...}))` /
  `Match.discriminatorsExhaustive("field")({...})` / `Match.valueTags({...})`.
- Narrow without `as` → `P.isTagged("Tag")`, `P.chainRefinements` (`@beep/utils`),
  `P.and/or/every/some/Struct/not`, `O.liftPredicate`, `S.is`/`S.decodeOption`/`S.decodeResult`.
- Option-struct spread → `O.getSomesStruct({...})` (Decision 5 amends the law first):
  `new Node({ ...O.getSomesStruct({ reason: O.fromUndefinedOr(x), color: cell.color }), children })`.

**Carve-outs.** `as` is already repo-banned (only `as const`). Do **not** collapse distinct
action/port/driver error tags callers branch on (`09` L37). Respect the `REQUIRED_TAGGED_UNIONS` lint
law — some `S.Class` families must stay separate.

**Lint cards.** Reuse `SFV4-static-api`; add `SFV4-getsomes-struct` (post-amendment).

### S4 — Colocation via `withStatics` & pipe-ability via `dual`/`flow`  *(headings 7, 8)*

**Why.** The helper-soup wall — `const isX = S.is(X)` / `const decodeX = …` across the file top, and

**Targets.**
- Attach statics: `SchemaUtils.withCodecStatics` on branded/union consts (→ `{ is, fromUnknown,

- Pipe-ability: `dual(2, (self, that) => …)`; `flow(a, b, c)` for passthrough `pipe` callbacks; direct
  helper refs over trivial lambdas (`.repos/effect-v4/.../Function.ts`).

**Lint/laws.** Reuse `SFV4-class-statics` + `SFV4-static-api`; verify with

## 5. Cross-cutting execution disciplines

These make the goal *durable, safe, and cheap* rather than a decaying manual sweep. Bake each into
the packet.

### 5.1 Baseline, burndown & Definition of Done
"Crispen the entire repo" is unbounded until it is measured. The **P1 discovery inventories ARE the
repo-wide baseline** — a count per S1-S5 per package. Record it in `standards/schema-first.inventory.jsonc`
and a burndown table in `PLAN.md`; each wave reports its delta. **Definition of Done** = every package
family reaches **zero actionable S1-S5 findings (or a documented exception)**, the novel lint cards
are live + hard-fail on crispened families, the Law 20/47 amendment merged, and the annotation catalog
is generated. This is the `schema-first-zero-actionables` model applied to all five domains.

### 5.2 Mechanization triage & codemods (phase P1.5) — the biggest cost lever
Much of this is mechanical and high-count. For **each S1-S5 smell**, classify inventory items as:
*pure-codemod* / *codemod-assisted + agent review* / *judgment-only*. **Author ts-morph codemods**
(in `ops/codemods/`, built on `repo-utils/src/TSMorph/`) for the mechanical, high-count transforms —
e.g. `R.getSomes`→`O.getSomesStruct` (~113 sites), `?? d` → schema constructor default, the
guard/decode wall → `withCodecStatics`, `switch` on a discriminator → `Match`. Agents then spend
tokens only on judgment calls + reviewing codemod output. Every codemod ships with a **golden-diff
dry-run test** before it touches a wave.

### 5.3 Behavior-parity proofs (the safety net)
Every move is *behavior-preserving*, so the strongest guarantee is **encode-form parity**: for each
remediated schema, snapshot the **encoded/wire shape** (and the SQL row shape for persisted entities)
*before*, and assert it is **byte-identical after**. This directly protects the two riskiest
carve-outs — constructor-only defaults must keep the wire required (§4 S2), and SQL absence must stay
`null` (§4 S2 carve-out). Required in the remediation template, alongside one `S.toArbitrary`
round-trip law per absorption.

### 5.4 Breaking-change ripple protocol
Some absorptions change a schema's *public form*: value → `EffectSchema()` factory, adding a brand,
tightening a primitive, value → function. Per the crispen skill's move #8 lesson, these break every
consumer. Rule: **if a proposed change alters `.Type`/`.Encoded` or value-vs-factory, the remediation
sweeps all consumers in the SAME PR** (cross-package `rg`), or the specialist marks it `judgment-only`
+ `breaking` and it is deferred to a dedicated scoped sub-task. Never land a public-form change with
dangling call sites.

### 5.5 False-positive audit & exception ledger
`??`, `.trim()`, `as`, broad primitives all have legitimate uses (boundaries, tests, 3rd-party, wire
contracts). Each specialist runs a **detector-first false-positive pass** (à la
`schema-first-zero-actionables`) and every inventory record carries: `ruleId`, `file`, `line`,

### 5.7 Anti-regression ratchet (what makes it durable)
Novel lint cards land **advisory** in P0. Once a package family is crispened + `yeet verify`-green,
**flip its cards advisory→hard-fail for that family's path scope** (per-path severity, like
`fallow-advisory-ratchets` / `lint-advisory-hardening`). New code then cannot re-introduce the smell.
Without the ratchet the repo re-accretes every smell and the sweep decays — the ratchet is the
difference between a one-time cleanup and a permanent property.
