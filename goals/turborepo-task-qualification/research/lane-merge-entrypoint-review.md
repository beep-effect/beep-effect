# Entrypoint review after quality-lane integration

This review binds the integrated Cache observer, census and planner sources.
It provides source identity and a review of the generated plans. Native task
outcomes, expanded hosted workflows and signed transport evidence retain
their separate proof authorities.

The population has 142 workspaces, 2,840 configured nodes and 1,474 executable
nodes. Six removed property-test wrappers remain graph-only. The reviewed
baseline delta attributes the inherited graph and complete-script changes;
no common cache flag changes and no new executable computation appears.

Regenerated local and hosted snapshots each cover 69 CI plans, nine Quality
modes, 15 partition plans and four local-dispatch shapes. Quality's cheap-gate
plan changes from 15 lanes to 13, and pre-push changes from 30 to 29. Lane ids
now name commands and carry their tier in a separate field. The Cache audit
is preserved as `quality:cache-policy` in both cheap-gates and pre-push.
Those two contexts remain distinguishable by tier, stage and plan ownership.

Each local/hosted Yeet snapshot retains 30 illustrative branch/mode scenarios;
14 change because they embed the new lane plans. These are calls to the real
pure planners, not execution, publication or hosted proof. The ten complete
local workflow/action documents are unchanged. Exact command groups change
with the six wrapper removals, added test-typechecking scripts, root-script
changes and the fresh census digest.

The source-binding recipe includes the current census's complete source list,
the existing planner-review dependencies and every Cache source role. The
census now includes the newly introduced Quality `CheckCensus` source.
The pilot validates the current identity task closure, including the absence
of the old dependency-lint edge. If types lint is present in a reviewed
closure, it must still execute fresh; unexpected or missing tasks fail the
graph comparison. The real computation's command and file/configuration
inputs are checked against the fresh census in each isolated worktree.

Remaining obligations include the complete native control matrix, semantic
read/write traces and capture adversaries, accepted signed sibling receipts,
dynamic interpreter coverage and fresh external verdicts. The local mode of
a planner or fixture does not establish the runtime state of an external
service. No tuple promotion or live cache activation follows from this review.
