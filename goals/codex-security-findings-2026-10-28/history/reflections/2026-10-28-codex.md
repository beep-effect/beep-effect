# Reflection — supplemental Security Cloud findings

## Result and limits

The seven reports were captured through the supported importer, validated using
full Cloud details and current source, and given focused control repairs.
Historical #1930 closure was independently revalidated. This reflection records
implementation and qualification work; merge and exact-ID external closure
remain separate acceptance requirements.

## Evidence that changed the approach

The export contained seven new identities and none of the original eight.
The authenticated inventory matched it exactly. A separate linked capture
preserved both catalogs without synthesizing a full historical export.

The original completion provider verified only in the owning clone, where its
retained job and status paths satisfy containment. GitHub also distinguished a
withdrawn alert from a fixed one: #431 returned an explicit HTTP 410. No broader
authentication grant was needed, despite generic CLI scope guidance.

Source tests alone missed two introduced typing issues: an inferred array
callback and service requirements leaking from a captured publisher. Scoped
source checks exposed them; package-owned test receipts separately established
that the changed tests compile. These are different forms of evidence.

## Security and compatibility

The fixes reuse canonical containment and existing ownership checks. The link
scanner consumes malformed candidates without overlapping retries and preserves
valid link behavior. Worktree settling remains available before capture, while
any walker observed after capture forces preservation. Bridge reconnect uses
the same validated immutable endpoint as its initial connection.

Windows parsing is weaker evidence than Windows runtime behavior. The focused
CI test uses synthetic bytes, a valid owner and a distinct kernel owner SID.
It does not provision another account or prove the state of any deployed device.

## Process correction

I overlapped local proof runs for the same checkout, creating an avoidable wait.
The default run was interrupted after ten minutes. Scoped lint/check and
package-owned test receipts were retained, and hosted checks supply the
remaining proof under the repository's constrained-compute rule. Optional
repository-wide terse-helper candidates were kept out of the security diff.
