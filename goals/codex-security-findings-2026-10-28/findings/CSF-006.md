# CSF-006: Underscore\-containing keys bypass new stderr redaction

- Severity: Informational
- Codex ID: `commit:e2b089fb69188191b8b5a8eb96c19fca`
- Source commit: `f8a35b7d1339e2a70093d40b2df65d74b6314ff5`
- Owner: ACP stderr sanitization
- Status: validated; implemented; qualification and closure pending

## Public Summary

The standalone provider-key pattern omits underscores, leaving complete tokens or reconstructable secret-bearing suffixes in excerpts.

## Current-HEAD Validation

Disposition: remediate. Baseline source at `2c59e073c8` contains the defect. The branch implements the control described below; external closure remains pending.

### Cloud Validation, Evidence and Attack-path analysis

Cloud validation executes the exact regex table with synthetic underscore-containing provider keys and nine controls. Collector and publication paths were source-traced because dependencies were absent. The attack-path analysis confirms the control defect while leaving unauthorized diagnostic access unestablished.

Full report sections were read in the authenticated Cloud UI on 2026-10-28. Captured severity and identity remain unchanged. Cloud suppression is not evidence that the defect is false positive.

## Remediation

Include underscores in the standalone provider credential alphabet. Assert the entire value is redacted for four provider prefixes, including the complete secret-bearing suffix.

- `packages/drivers/acp/src/AcpStderr.models.ts`
- `packages/drivers/acp/test/stderr.test.ts`
