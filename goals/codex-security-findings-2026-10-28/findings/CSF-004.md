## Public Summary

Malformed repeated link openers without a fragment cause overlapping suffix scans in the link regex. Tracked text reaches the synchronous scanner after a literal prefilter.

## Current-HEAD Validation

Disposition: remediate. Baseline source at `2c59e073c8` contains the defect. The branch implements the control described below; external closure was verified on 2026-10-31.

### Cloud Validation, Evidence and Attack-path analysis

Cloud validation measures roughly quadratic growth for the exact regex with independent baseline controls; the production-module import was blocked. The attack-path analysis limits impact to admitted local/CI lint work and does not establish a product privilege boundary.

Full report sections were read in the authenticated Cloud UI on 2026-10-28. Captured severity and identity remain unchanged. Cloud suppression is not evidence that the defect is false positive.

## Remediation

Consume malformed fragment candidates as disjoint spans instead of retrying the same suffix from each opener. Drop candidates without a fragment; retain valid IPv6 link syntax. Repeated opener and missing-fragment controls exercise the exported scanner.
